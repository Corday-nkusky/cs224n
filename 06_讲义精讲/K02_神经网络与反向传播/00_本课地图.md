## §3 知识清单

每条一句话结论 + 出处。**扫一遍，看有没有哪条你讲不出来。**

### A. 为什么需要它（4 条）

1. 【slides】p13：典型 ML/统计的 **softmax 分类器**只学 $W$，输入表示 $x$ 是**固定的稀疏符号特征**（如 one-hot）；它给出的是**线性决策边界**，这是限制（"which can be limiting"）。
2. 【slides】p13：神经网络分类器的区别有两条：**(a) 同时学 $W$ 和词的分布式表示**；**(b) 用更多层反复"重新表示"数据，得到非线性分类器**。
3. 【slides】p17：**没有非线性，深度网络不比单个线性变换多任何东西**——多层会塌成一层：$W_1W_2x = Wx$。
4. 【slides】p13：embedding 层概念上是 $x = Le$（$e$ 是 one-hot），把词"搬到"一个中间向量空间里，好让（线性的）softmax 分类器去切；**但分类器只在最后一层之前是线性的**（"typically, it is linear relative to the pre-final layer representation"）。

### B. 非线性（激活函数）（3 条）

5. 【slides】p15：logistic（sigmoid）、tanh、ReLU 三家。$\tanh(z)=2\,\text{logistic}(2z)-1$（**tanh 只是被缩放和平移过的 sigmoid**，陡 2 倍、值域 $[-1,1]$）；$\text{ReLU}(z)=\max(z,0)$。
6. 【slides】p15：深度网络**第一个该试的是 ReLU**——训练快、梯度回流好；代价是负半轴有"死区"，后续提出 Leaky ReLU / Parametric ReLU 缓解。
7. 【slides】p16：更新的激活：**GELU**（Transformer 常用，$\text{GELU}(x)=x\cdot P(X\le x),\,X\sim N(0,1)\approx x\cdot\text{logistic}(1.702x)$）、**SiLU / Swish**（$x\cdot\sigma(x)$ / $x\cdot\sigma(\beta x)$）、**GLU / SwiGLU**（带门控，Llama3/Qwen3 常用）。

### C. 目标函数与优化（3 条）

8. 【slides】p18：**交叉熵损失** $H(p,q)=-\sum_i p_i\log q_i$；当真实分布 $p$ 是 one-hot 时，只剩一项：$-\log p(y_i\mid x_i)$ —— **就是"正确类的负对数概率"**。PyTorch 里就用它。
9. 【slides】p19：SGD 更新 $\theta_j^{new}=\theta_j^{old}-\alpha\,\dfrac{\partial J(\theta)}{\partial\theta_j}$。**关键一句：$\theta$ 里也包含数据表示（词向量）**——词向量不是固定输入，是参数。
10. 【slides】p19：怎么算 $\nabla_\theta J(\theta)$？**两条路：① 手算；② 算法化——反向传播**。

### D. 矩阵微积分（5 条）

11. 【slides】p21–22：梯度回答"**输入动一点，输出动多少**"。1 输出 1 输入 → 导数（标量）；1 输出 $n$ 输入 → **$n$ 个偏导组成的向量**。
12. 【slides】p23：$m$ 输出 $n$ 输入 → **Jacobian 是 $m\times n$ 的偏导矩阵**。
13. 【slides】p24：**链式法则**：一元函数复合 → 导数相乘；多元函数复合 → **Jacobian 相乘**。
14. 【slides】p25–29：**逐元素激活函数的 Jacobian 是对角矩阵**，对角元是 $f'(z_i)$。
15. 【slides】p32/p54–55：**Jacobian 形式（好算）与形状约定（好实现）会冲突**——形状约定 = **梯度的形状等于参数的形状**；作业答案按形状约定给，但用 Jacobian 形式来推。

### E. 反向传播（7 条）

16. 【slides】p57–60：软件把网络方程表示成**计算图**：源节点=输入，内部节点=运算，边传结果。前向 = 沿图正向算；反向 = 沿边倒着传梯度。
17. 【slides】p61–64：单节点三件套——**上游梯度（upstream）**、**局部梯度（local）**、**下游梯度（downstream）**。规则一句话：**[下游梯度] = [上游梯度] × [局部梯度]**（就是链式法则）。
18. 【slides】p65–66：**多输入节点有多个局部梯度**（每个输入一个）。
19. 【slides】p67–68：**梯度在分叉处相加**（一个节点被多处用到时，回头传的梯度要累加）。
20. 【slides】p69–71：节点直觉——`+` **分发**上游梯度给每个加数；`max` **路由**上游梯度到最大的那一路；`*` **交换**上游梯度（与另一输入相乘）。
21. 【slides】p72–74：**正确做法是一次把所有梯度一起算**（复用中间结果）；错误做法是逐个参数独立求导——**重复计算**。
22. 【slides】p75：通用计算图上——**前向按拓扑序、反向按反序**；**做对了，前向和反向的大 O 复杂度相同**。

### F. 手算梯度与实现细节（4 条）

23. 【slides】p46–48：**误差信号 $\delta$ = 上游梯度**，逐层往里传，被复用（"Let's avoid duplicated computation"）。
24. 【slides】p51：对 $s=Wx+b$：$\dfrac{\partial s}{\partial W}=\delta\,x^{\mathsf T}$（**外积**），$\dfrac{\partial s}{\partial b}=\delta$，$\dfrac{\partial s}{\partial x}=W^{\mathsf T}\delta$。
25. 【slides】p53：为什么 $\partial z_i/\partial W_{ij}=x_j$ —— 因为 $W_{ij}$ **只**参与算 $z_i$（例如 $W_{23}$ 只用于算 $z_2$，不用算 $z_1$）。$z_i=W_{i\cdot}x+b_i=\sum_k W_{ik}x_k$，对 $W_{ij}$ 求导只剩 $x_j$。
26. 【slides】p78：**数值梯度检查**：$\dfrac{f(\theta+h)-f(\theta-h)}{2h}$，$h\approx10^{-4}$；易写对但**很慢且只是近似**，用来核对实现，不是训练手段。

### G. 自动微分与调试（2 条）

27. 【slides】p76：**自动微分**——梯度可以从 fprop 的符号表达式里自动推出来；每个节点类型只需知道"怎么算输出"和"给定输出梯度、怎么算输入梯度"。框架替你做了 backprop，但节点/层的局部导数还得人来写。
28. 【slides】p80：**为什么要学这些细节**——backprop 不总是能开箱即用；理解它才能 debug 和改进模型（slides 点名 Karpathy 那篇 *Yes you should understand backprop*，以及后续课的梯度爆炸/消失）。

## §7 下一课预告：K03 语言模型与 RNN

会复用本课的东西：**"写损失 → 求梯度 → SGD"这套流程完全一样**，反向传播仍然是"沿计算图反序传梯度"。

会变的两样：

1. **计算图会"展开"** —— 同一个层被重复用在时间轴上，梯度要沿时间反传并在每一步累加（本课 p67 的"分叉处相加"会变成"每个时刻相加"）
2. **梯度会消失/爆炸** —— 反传路径上乘了太多 Jacobian（$\prod W$ 的谱范数），本课 p80 埋的伏笔在这里兑现

**本课的收益在 T2 立刻兑现**：A2 的书面题考的就是本课 `04` §6–§7 那套动作；A2 的代码（依存句法分析器）用本课的网络结构（embedding → 隐藏层 → ReLU → dropout → logits）。
