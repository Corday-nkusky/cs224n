## §2 验证一：没有非线性，多层塌成一层

**断言**（`01` §3.1、【slides】p17）：$W_2(W_1x)=(W_2W_1)x$，多层线性叠加等价于单个矩阵。

**你的预期**：填一下——两者差值应该是多少？（提示：浮点运算的精度是多少）

**【实测】** 随机 $W_1\in\mathbb{R}^{4\times3}$、$W_2\in\mathbb{R}^{2\times4}$、$x\in\mathbb{R}^3$：

```
两层分别算 W2@(W1@x) : [0.201359 0.560198]
合成单矩阵 (W2@W1)@x : [0.201359 0.560198]
max|差| = 3.3306690738754696e-16
```

**对账**：差值 $3.3\times10^{-16}$，**就是双精度浮点的舍入误差**，不是"近似相等"，是**代数上恒等**。

**对照**：中间插入 ReLU 之后：

```
中间插 ReLU:            [-1.986808  0.656412]
与 (W2@W1)@x 的差     : [-2.188168  0.096214]
```

**这一屏意味着什么**：$W_1W_2x=Wx$ **不是修辞**，是矩阵乘法结合律的直接后果。所以 `01` §3.3 那句话可以钉死了：

> **非线性是"深度"唯一的来源。** 去掉 $f$，网络再深也只是一次矩阵乘法。

## §3 验证二：手算算例 + 手推梯度 vs 数值梯度

**断言**（`02` §5）：$x=[1,2]$、$W_1=\begin{bmatrix}1&0\\0&-1\end{bmatrix}$、$W_2=[1,1]$，前向得 $z_1=[1,-2]$、$h=[1,0]$、$s=1$。

**你的预期**：$h$ 的第 2 个分量是多少？为什么？

**【实测】** 前向：

```
z1 = W1@x + b1 = [ 1. -2.]
h  = ReLU(z1)  = [1. 0.]   <- 第2个单元被 ReLU 压成 0（死区）
s  = W2@h + b2 = 1.0
```

**对账**：与 `02` §5 手算表逐位一致 ✅。

### 3.1 手推梯度 vs 数值梯度（中心差分）

**你的预期**：$\partial s/\partial W_1$ 的第 2 行应该是多少？（提示：第 2 个单元已经死了）

**【实测】** 用 `02` §4.1 的单节点规则手推，与中心差分对比（$h=10^{-4}$）：

| 梯度 | 解析 | 数值 | max\|差\| |
|------|------|------|-----------|
| $\partial s/\partial W_2$ | `[[1. 0.]]` | `[[1. 0.]]` | $1.1\times10^{-13}$ |
| $\partial s/\partial W_1$ | `[[1. 2.], [0. 0.]]` | 同 | $2.2\times10^{-13}$ |
| $\partial s/\partial b_1$ | `[1. 0.]` | `[1. 0.]` | $1.1\times10^{-13}$ |
| $\partial s/\partial b_2$ | `[1.]` | `[1.]` | $1.1\times10^{-13}$ |
| $\partial s/\partial x$ | `[1. 0.]` | `[1. 0.]` | $1.1\times10^{-13}$ |

**对账**：全部吻合到 $10^{-13}$（数值梯度的固有误差量级）。

**两处细节值得停下来看**：

1. **$\partial s/\partial W_1$ 的第 2 行全 0** —— 第 2 个 ReLU 单元 $z_1^{(2)}=-2<0$，它的局部导数是 0，梯度到这就断了。**这就是 ReLU 死区的代价**（【slides】p15 提到的 "negative dead zone"）：**一个单元一旦长期落在负半轴，它就永远收不到梯度，也就永远学不回来。**
2. **$\partial s/\partial W_2=[1,0]$ 而不是 $[1,1]$** —— 因为 $\partial s/\partial h=W_2=[1,1]$，但传过 ReLU 时第 2 路被置零。**同一个"梯度在 max 节点被路由"的规则，在 `03` 里变成了可见的数字。**

> **这条对 A2 有直接意义**：parser 的隐藏层用 ReLU，**训练中若大量单元死掉，dev UAS 会卡住**。这是 `05` §3 排查表里的一条。

## §4 验证三：softmax + 交叉熵的梯度 = ŷ − y

**断言**（`02` §6、`04` §6）：对 logits $z$，$\dfrac{\partial J}{\partial z}=\hat y - y$。

**你的预期**：三个分量 $\hat y-y$ 加起来应该是多少？（提示：$\hat y$ 是概率分布，$y$ 是 one-hot）

**【实测】** $z=[2,1,-1]$，正确类 $y=0$：

```
ŷ=softmax= [0.705385 0.259496 0.035119]
J = -log p_y = 0.34901221676818633
∂J/∂z 解析 (ŷ−y) = [-0.294615  0.259496  0.035119]
∂J/∂z 数值       = [-0.294615  0.259496  0.035119]  max|差| = 1.538588145777453e-10
```

**对账**：吻合到 $1.5\times10^{-10}$ ✅。

**两个可直接验的性质**：

- **三分量之和 = 0**（$-0.294615+0.259496+0.035119=0$）。因为 $\sum\hat y=1$、$\sum y=1$，差值必为 0。**这叫"梯度正交于全 1 方向"**——softmax 输出对整体平移不变，所以梯度不许有"整体加一点"的分量。
- **符号**：正确类那一位是负的（$\hat y_y-1<0$），其余是正的。**梯度下降要 $z\leftarrow z-\alpha\cdot\text{grad}$**，所以正确类的 logit **被抬高**、错的**被压低**——正是想要的。

> ⚠️ **一个必须说的区别**：$\hat y - y$ 这个简洁形式**依赖"损失是交叉熵"这个前提**。换成 MSE，输出层梯度就不是这个形状了。**"softmax 天然配交叉熵"不是审美，是这条式子给的。**

## §5 验证四：分叉处梯度相加

**断言**（`02` §4.2、【slides】p67–68）：一个变量被下游用两次，梯度是两路之和。

**你的预期**：$y=a^2+a$，在 $a=3$ 处 $\mathrm{d}y/\mathrm{d}a=?$

**【实测】**：

```
a = 3.0
y = a*a + a = 12.0
dy/da 解析 (2a+1) = 7.0
dy/da 数值        = [7.]
```

**对账**：$2a+1=7$ ✅。

**这一屏意味着什么**：`a` 在计算图里有**两条出边**（一条进 `*`、一条进 `+`）。反向时两路各传来 `2a=6` 和 `1`，**相加得 7**。若只取其中一条（6 或 1）就错。

> **这是手写反向传播最常见的 bug**：漏了累加。在 A2 里它不会以 `a*a+a` 这种形式出现，而是**同一个中间变量被下游用了两次**——例如 `h` 既进了 `W2` 又参加了别的运算，或者 RNN 里 `h_t` 同时喂给输出层和下一个时刻（K03）。**漏累加不会报错，只会让 loss 下不去。**

## §6 验证五：两层 MLP 的 $\partial L/\partial W_1$（T2 闸门 1 的演练）

**断言**：把 `02` §2 的 MLP（3→4→3，ReLU + softmax 交叉熵）的整条链手推，梯度应能被**三种独立方法**对上。

**你的预期**：解析梯度与数值梯度的差，应该和 §3 的 $10^{-13}$ 同量级吗？

**【实测】** 三条来源对账：

```
L = 1.6500279853758044
∂L/∂W2  max|解析-数值| = 7.59436957764592e-12
∂L/∂W1  max|解析-数值| = 9.47427691855296e-11
∂L/∂b1  max|解析-数值| = 1.0042677800470301e-10
∂L/∂b2  max|解析-数值| = 1.6037260408552356e-10

[torch] ∂L/∂W1 max|autograd-解析| = 0.0
[torch] ∂L/∂W2 max|autograd-解析| = 1.734723475976807e-17
[torch] L 与 numpy 实现的 L 差 = 0.0
```

**对账**：

| 对比 | 结果 | 说明 |
|------|------|------|
| 解析 vs 数值 | $\sim10^{-10}$ | 数值梯度的固有误差 |
| 解析 vs torch.autograd | $0.0$ / $10^{-17}$ | **autograd 做的就是这件事，精确到浮点** |
| 损失值 | 差 $0.0$ | 两边前向完全一致 |

**这一屏是整课的落点**：

> **"反向传播"不是黑箱。** 你手推的那串链式法则（含 Hadamard 乘、外积、分叉累加），和 `autograd` 算出来的是**同一个东西**——差 0.0。
> 反过来，**没有你在 §3 学的那套规则，你读不懂 autograd 为什么对**；也没有能力在它给错答案时（梯度检查对不上）定位问题。

**还能看到的一件事**：$\partial L/\partial W_1$ 的第 3 行**全 0**

```
∂L/∂W1 (解析) =
 [[ 0.34261   0.701722  0.580039]
 [ 0.028573  0.058522  0.048374]
 [-0.       -0.       -0.      ]
 [-0.021106 -0.04323  -0.035733]]
```

**又一个死掉的 ReLU 单元**（该单元 $z_1^{(3)}<0$）。**4 个隐藏单元里死了 1 个**——这不是构造出来的特例，随机初始化 + ReLU 下很常见。
