## §3 知识清单

每条一句话结论 + 出处。**扫一遍，看有没有哪条你讲不出来。**

### A. 从 RNN 接过来的三处代价（6 条）

1. 【slides】p8：vanilla RNN 沿链式法则反传时，**若这些局部因子小，梯度信号越往回传越小**（来源 Pascanu et al. 2013）。
2. 【slides】p9：远端梯度被近端淹没 → **权重只按近端效应更新，学不到长期效应**。
3. 【slides】p10：具体后果——要学到 "tickets"（第 7 步）到句末目标词的依赖，梯度小就学不到；测试时也预测不了这类长距离依赖。
4. 【slides】p11：梯度爆炸 → SGD 更新步太大 → 走到"又怪又差"的参数点（"你以为找到一座山，结果人在爱荷华"），最坏 **Inf/NaN**。
5. 【slides】p12：**梯度剪裁**——梯度范数超阈值就按比例缩小再更新（"同方向、小步走"）；slides 原话："**exploding gradients are an easy problem to solve**"。
6. 【slides】p13：治消失的两条方向——① **LSTM**（独立、可"加"的记忆）；② 造**更直接、更线性的直通连接**：**attention、residual connections, etc.** ← 本课主题。

### B. seq2seq 与 bottleneck（4 条）

7. 【slides】p14–p15：MT = 把源语言句子 $x$ 翻成目标语言句子 $y$；NMT 从 2014 边缘尝试（Sutskever et al. 2014）到 2016 Google Translate 切换、2018 全员——**多年数百工程师的 SMT 被小团队几个月训的 NMT 超过**。
8. 【slides】p16：Encoder RNN 产出源句的**编码**，作为 Decoder RNN 的**初始隐藏状态**；Decoder 是**条件语言模型**（p18：LM 因为它预测目标下一词；conditional 因为它还条件于源句 $x$）。
9. 【slides】p17–p19：seq2seq 通用（摘要 / 对话 / 句法分析 / 代码生成）；单系统端到端训练，各时刻损失相加。
10. 【slides】p20、p21：Encoder 把整句压成**一个向量**——图上直接标注 "**Conditioning = Bottleneck**"；p21 发问 "**Problems with this architecture?**" ← 引向 attention 的钩子。

### C. 注意力是什么（6 条）

11. 【slides】p22：**核心思想**——解码器每一步用与编码器的**直接连接**，聚焦源句的某一部分；先给图（无公式），再给公式。
12. 【slides】p23：起点是 **mean-pooling**（对全部隐藏状态取逐元素 max 或 mean）。
13. 【slides】p24：**attention = 加权平均**；它像**查表**——查表时 query 命中一个 key、返回其 value；attention 里 query 对**所有 key 软匹配**，权重落在 $[0,1]$，value 按权重加权求和。**"if the weights are learned"** 才强大。
14. 【slides】p29–p31：流程 = 打分 → **softmax 变概率分布** → 对隐藏状态**加权求和**得 attention output → 与 decoder 隐藏状态**拼接**后再算 $\hat y_t$。p32：有时把上一步的 attention output 也喂回 decoder。
15. 【slides】p37：attention 的五大好处——提升 NMT；更像人（能**回看**源句而非全记住）；**解决 bottleneck**（直连源句，绕过瓶颈）；**缓解梯度消失**（给远端状态一条 shortcut）；**可解释**（看 attention 分布即得 **soft alignment，免费**）。唯一问题：**对序列长度是二次代价**。
16. 【slides】p38：**一般定义**——给定一组 value 向量与一个 query 向量，attention 计算与 query 相关的、value 的加权和；"**the query attends to the values**"。seq2seq 里每个 decoder 隐藏状态（query）对全部 encoder 隐藏状态（value）做注意力。

### D. Self-attention（4 条）

17. 【slides】p40：**cross attention** = 对输入 $x$ 做注意力来生成 $y_t$；**self attention** = 生成 $y_t$ 时对 $y_{<t}$ 做注意力。
18. 【slides】p42：三个投影 $Q,K,V\in\mathbb{R}^{d\times d}$；$q_i=Qx_i,\ k_i=Kx_i,\ v_i=Vx_i$；$e_{ij}=q_i^\top k_j$，$\alpha_{ij}=\dfrac{\exp(e_{ij})}{\sum_{j'}\exp(e_{ij'})}$；$o_i=\sum_j \alpha_{ij}v_j$。
19. 【slides】p43、p47–p52：self-attention 作为积木有三个"障碍"——**①没有内在顺序概念**；**②没有逐元素非线性**（叠更多层只是反复重新平均 value）；**③预测时不能看未来**。对应三个解法：加位置表示、每个输出过 FFN、把未来位置设 $-\infty$。
20. 【slides】p52：一个 self-attention 模块的**四件必备**——self-attention（基础）、位置表示（补顺序）、非线性（FFN）、masking（并行化且不泄漏未来）。

### E. 位置编码（3 条）

21. 【slides】p44：把位置向量 $p_i\in\mathbb{R}^d$ **加到**输入上：$\tilde x_i=x_i+p_i$；深层网络**只在第一层做**；"concatenate 也行，但人们多数就是加"。
22. 【slides】p45：**正弦编码**——不同周期的 sin/cos 拼接。Pros：周期性暗示"绝对位置没那么重要"、或许能外推；Cons：**不可学习，且实际外推也不行**。
23. 【slides】p46：**可学习绝对位置** $p\in\mathbb{R}^{d\times n}$。Pros：灵活；Cons：**没法外推到 $1..n$ 以外**。**"Most systems use this!"** 另有相对线性位置（Shaw 2018）、依存句法位置（Wang 2019）。

### F. Transformer 组件（9 条）

24. 【slides】p56：**矩阵形式**——$X\in\mathbb{R}^{n\times d}$，$XQ,XK,XV\in\mathbb{R}^{n\times d}$，$\text{output}=\text{softmax}(XQ\,(XK)^\top)\,XV\in\mathbb{R}^{n\times d}$；其中分数矩阵 $XQK^\top X^\top\in\mathbb{R}^{n\times n}$ 是**所有 pair 的注意力分数**。
25. 【slides】p57：**多头**——$Q_\ell,K_\ell,V_\ell\in\mathbb{R}^{d\times d/h}$；$\text{output}_\ell=\text{softmax}(XQ_\ell K_\ell^\top X^\top)\,XV_\ell\in\mathbb{R}^{n\times d/h}$；再把各头输出拼起来过 $Y\in\mathbb{R}^{d\times d}$。每个头可以"看"不同东西、以不同方式构造 value。
26. 【slides】p58：**多头并不更贵**——算 $XQ\in\mathbb{R}^{n\times d}$，reshape 成 $\mathbb{R}^{n\times h\times d/h}$，转置成 $\mathbb{R}^{h\times n\times d/h}$，把 **head 轴当 batch 轴**；其余几乎照旧，矩阵尺寸不变。
27. 【slides】p59：**scaled dot product**（Vaswani et al. 2017）——$d$ 大时点积趋于变大 → softmax 输入大 → **梯度小**；于是把分数除以 $\sqrt{d/h}$（$d/h$ 即每个头的维度）。
28. 【slides】p61：**残差连接**——$X^{(i)}=X^{(i-1)}+\text{Layer}(X^{(i-1)})$，只需学"残差"；原话：**"Gradient is great through the residual connection; it's 1!"**、**"Bias towards the identity function!"**。
29. 【slides】p62：**LayerNorm**——对**单个词向量** $x\in\mathbb{R}^d$ 做：$\mu=\frac1d\sum_j x_j$，$\sigma^2=\frac1d\sum_j(x_j-\mu)^2$，$\text{output}=\frac{x-\mu}{\sigma+\epsilon}\gamma+\beta$，$\gamma,\beta$ 是**可学习** gain/bias（可省）；成功可能来自"**归一化梯度**"（Xu et al. 2019）。
30. 【slides】p63：**Decoder Block = Self-attention + Add&Norm + Feed-Forward + Add&Norm**（图示写作 "Add & Norm"）。
31. 【slides】p64：**Encoder = 去掉 mask 的 Decoder**（双向上下文，类比 biRNN），"No Masking!"。
32. 【slides】p65–p66：**Encoder-Decoder**：decoder 增加对 encoder 输出的 **cross-attention**——query 来自 decoder $q_i=Qz_i$，**key/value 来自 encoder（当 memory）** $k_i=Kh_i,\ v_i=Vh_i$。

### G. 结果、代价与变体（4 条）

33. 【slides】p67：原论文 MT（WMT14 En-De / En-Fr）不只 BLEU 更好，**训练也更高效**。
34. 【slides】p68：文档生成（Liu et al. 2018，WikiSum）；"**Transformers all the way down**"。
35. 【slides】p69：待修的——**二次复杂度**（所有 pair 交互随序列长度平方增长；$n\ge 50{,}000$ 的长文档怎么办？）；绝对位置是否最优（相对位置、依存位置）。
36. 【slides】p70：模型越大，**自注意力之外**的计算占比越大；实践中大 LM 几乎都还是用这套二次注意力，**更便宜的方法在大规模往往更差**；开放问题：若做对，能否用 >100k token 的长上下文解锁更好的模型。

## §5 术语索引

按首次出现的篇排。`01` 篇零前置，`02` 篇是本知识点核心概念，`04` 篇才需要推导背景。

| 术语 | 一句话解释 | 出处 |
|------|-----------|------|
| **NMT / seq2seq** | 神经机器翻译；编码器-解码器，输入输出都是序列 | `01` §1 |
| **bottleneck** | 整句被压成一个定长向量，成为信息传递的瓶颈 | `01` §2 |
| **conditional LM** | 预测目标下一词时还条件于源句 $x$ 的语言模型 | `01` §1 |
| **注意力 / attention** | 按 query 相关的权重，对一组 value 做加权平均（软查表） | `02` §1 |
| **query / key / value** | 查询向量 / 被匹配的键 / 被加权取回的值 | `02` §1 |
| **attention 权重 $\alpha$** | 打分经 softmax 后的概率分布，非负且和为 1 | `02` §3 |
| **注意力输出 $o_i$** | $\sum_j\alpha_{ij}v_j$，value 的加权和 | `02` §3 |
| **cross-attention** | query 与 key/value 来自**不同**序列 | `02` §2 |
| **self-attention** | query/key/value 都来自**同一**序列 | `02` §2 |
| **scaled dot-product** | 分数除以 $\sqrt{d_k}$，防止 softmax 饱和 | `02` §3、`04` §2 |
| **多头注意力 MHA** | 并行多组 $Q,K,V$，各自注意力后拼接 | `02` §6、`04` §3 |
| **$d_{head}$** | 每个头的维度 $=d_{model}/h$ | `04` §3 |
| **位置编码 PE** | 把位置信息注入输入（加或拼） | `02` §5、`04` §5 |
| **正弦位置编码** | 用不同周期的 sin/cos 生成固定位置向量 | `02` §5 |
| **可学习位置嵌入** | 把每个位置当参数学（A3、多数系统用） | `02` §5 |
| **FFN / MLP 块** | 逐位置的两层前馈 + 非线性，接在注意力后 | `02` §7 |
| **因果 mask** | 把未来位置分数设 $-\infty$，使位置 $i$ 只看 $j\le i$ | `02` §4、`04` §4 |
| **残差连接** | $X^{(i)}=X^{(i-1)}+\text{Layer}(X^{(i-1)})$，梯度直通 | `02` §7、`04` §7 |
| **LayerNorm** | 对单个词向量做零均值单位方差，再学 $\gamma,\beta$ | `02` §7、`04` §7 |
| **Dropout** | 训练时随机置零，防过拟合（**slides 未讲、A3 未用**） | `04` §8 |
| **Transformer Block** | 注意力 + Add&Norm + FFN + Add&Norm | `02` §7 |
| **$O(n^2)$** | 注意力分数矩阵随序列长度平方增长 | `02` §8、`04` §6 |

## §7 下一课预告：K05 预训练

本课交付的是**架构**（一个能并行、能长程、能双向/单向的骨架）。它本身**不产生能力**——随机初始化的 Transformer 只是函数。

K05 要回答的是：**这个骨架用什么目标、在什么数据上先"预训练"一遍，才能让它变成一个会说话的模型？**

会复用的东西：本课的 **self-attention、多头、位置编码、残差+LN、因果 mask** 原样保留——A3 写的那个 `Transformer` 类，就是 K05 里"GPT 系列"的同构版（`T4` 的 `from_pretrained()` 直接加载 GPT-2 权重就是这个意思）。会新增的：**预训练目标（续写 vs 填空）、数据规模、要不要双向（BERT 用 encoder，GPT 用 decoder）**。

**本课的收益在 A3 立刻兑现**：`T3` 的概念验收（默画结构、推 $\sqrt{d_k}$、手写单头注意力）与 `T4` 的作业验收（pytest 全绿 + 训练曲线 + 6 处填空问答），全部取自本课 `02`–`05`。
