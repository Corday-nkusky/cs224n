## §3 知识清单

每条一句话结论 + 出处。**扫一遍，看有没有哪条你讲不出来。**

### A. 预训练的动机（5 条）

1. 【slides】p3：预训练对 NLP 系统的效果有"重大、可感知"的提升（pretraining revolution）。
2. 【slides】p4：三条关键——**能处理大规模多样数据**、**不用标注数据**（否则没法 scale）、**compute-aware scaling**。
3. 【slides】p10：2017 年的做法是——用**预训练词向量（不带上下文）**，再在任务上训练 LSTM/Transformer 学上下文。两个问题：① 下游任务的数据要足够教会语言的**所有上下文面**；② 网络里**大多数参数是随机初始化的**。
4. 【slides】p11：现代做法——**几乎所有参数都由预训练初始化**；预训练的方法 = **把输入的一部分藏起来，让模型重建**。产出三样：强的语言表示、强的参数初始化、可采样的语言概率分布。
5. 【slides】p9：Firth 1935——"一个词完整的意思总是依赖上下文，脱离完整上下文的意义研究不可信"；`I record the record` 里两处 `record` 意思不同。

### B. 子词与 BPE（3 条）

6. 【slides】p5：固定词表假设——从训练集建几万词，测试时**所有新词都映射到同一个 UNK**（拼错、新词、变体、构词形全丢）。
7. 【slides】p6：**BPE 算法**三步：① 词表只含字符 + 词尾符号；② 在语料里找**最高频相邻字符对** $a,b$，把 $ab$ 加入词表；③ 用 $ab$ 替换所有该对，重复到目标词表大小。现在用类似方法（**WordPiece**）做预训练模型。
8. 【slides】p7：**常见词整块进词表，稀有词被切成子词**（有时直观有时不）；最坏情况下一个词被切成和字符一样多的子词。

### C. 上下文化与"整模型预训练"（2 条）

9. 【slides】p12–17：从"重建被藏起的输入"里能学到的东西，示例依次是：常识（Stanford 在哪）、句法（a fork）、指代（whose shoulder）、词汇语义/主题（fish, turtles…）、情感（movie was ___）、部分推理、基本算术。
10. 【slides】p54：上面这些被归纳成——**trivia / syntax / coreference / lexical semantics & topic / sentiment / 部分推理 / 基本算术**；同时模型也会学到并**放大偏见**（racism、sexism）。

### D. 预训练/微调范式（4 条）

11. 【slides】p18：**语言模型预训练**（Dai & Le 2015）——让神经网络在大量文本上做语言建模（建 $p_\theta(w_t\mid w_{1:t-1})$），把参数存下来。
12. 【slides】p19：**预训练/微调两阶段**——Step 1 **预训练**（语言建模，大量文本，学通用）；Step 2 **微调**（在你的任务上，少量标签，适配任务）。
13. 【slides】p20：训练数据来源表——**BERT** = BookCorpus + 英文 Wikipedia；**GPT-1** = BookCorpus；**GPT-3** = CommonCrawl + WebText + 英文 Wikipedia + Books1/Books2；**GPT-3.5+** = 未公开。
14. 【slides】p21–22：**BookCorpus = 从网上抓的电子书**，很有争议；牵涉 fair use。

### E. 三种架构的预训练目标（12 条）

15. 【slides】p24–25：**架构决定预训练目标和用途**。Decoder：就是语言模型，好生成，**不能看未来词**。Encoder：拿到**双向上下文**（能看未来），问题是"怎么训出强表示"。Encoder-Decoder：想要两者好处，"怎么最好地预训练"。
16. 【slides】p26：Encoder 不能做语言模型（它双向）；改用 **Masked LM**——把输入里一部分词换成 `[MASK]`，预测这些词；**只在被 mask 的位置算 loss**；学的是 $p_\theta(x\mid\tilde x)$。
17. 【slides】p27：**BERT 的 Masked LM 细节**——预测随机 **15%** 的 (sub)word token；**80%** 换 `[MASK]`、**10%** 换随机 token、**10%** 不变（但仍要预测）；理由：不让模型偷懒、逼它给非 mask 词也建强表示；**微调时没有 mask**。
18. 【slides】p28：BERT 预训练输入是**两段连续文本**，训练它预测第二段是否紧随第一段（**NSP**）；后来工作指出 **NSP 不必要**。
19. 【slides】p29：**BERT-base** = 12 层 / 768 维隐状态 / 12 头 / **110M** 参数；**BERT-large** = 24 层 / 1024 维 / 16 头 / **340M**；语料 = BooksCorpus（8 亿词）+ 英文 Wiki（25 亿词）；用 **64 块 TPU 训 4 天**；"**Pretrain once, finetune many times**"。
20. 【slides】p30：微调 BERT 在一批任务上刷新 SOTA（QQP/QNLI/SST-2/CoLA/STS-B/MRPC/RTE）。
21. 【slides】p31：**预训练 encoder 的局限**——要生成序列就得用 decoder；BERT 等 encoder **不天然产生逐词自回归生成**。
22. 【slides】p32–33：BERT 变体——**RoBERTa**（训得更久 + 去掉 NSP）；**SpanBERT**（掩**连续片段**，任务更难更有用）；教训：**更多算力 + 更多数据**就能改进预训练，即使不动 Transformer 结构。
23. 【slides】p35：**Encoder-Decoder 目标**——每个输入的一个**前缀**喂给 encoder 且**不被预测**；encoder 部享受双向上下文，decoder 部用语言模型训练整个模型。
24. 【slides】p36：**span corruption（T5）**——用**唯一占位符**替换不同长度的片段，再解码出被删片段。
25. 【slides】p37：Raffel et al. 发现——在其任务上 **encoder-decoder 优于 decoder**，**span corruption 优于语言建模**。
26. 【slides】p38：**T5** 规模 220M / 770M / 3B / 11B；可微调来回答广泛问题（从参数里取知识，NQ/WQ/TQA）。
27. 【slides】p39：**所有最大的预训练模型都是 Decoder**。
28. 【slides】p40：**decoder 当分类器微调**——在**最后一个词的隐状态**上接线性分类器 $y\sim Ah_T+b$；$A,b$ **随机初始化**；梯度回传整个网络。
29. 【slides】p41：**decoder 当生成器微调**——微调 $p_\theta(w_t\mid w_{1:t-1})$；$A,b$ **是预训练过的**；用于对话、摘要等"输出词表和预训练时相同"的任务。
30. 【slides】p42：**GPT（2018）**——12 层 transformer decoder，**117M** 参数；768 维隐状态、3072 维 FF；**BPE 40000 merges**；BooksCorpus **7000+ 本书**。
31. 【slides】p43：GPT 做 NLI 的输入格式 `[START] … [DELIM] … [EXTRACT]`；线性分类器作用在 **`[EXTRACT]` token 的表示**上。

### F. 大模型与 in-context learning（3 条）

32. 【slides】p45–46：**GPT-2 = 1.5B**，更多数据，生成较可信；**GPT-3 = 175B**，对比最大 T5 的 11B。
33. 【slides】p46–47：**in-context learning**——超大模型似乎能**不做梯度步**、仅凭上下文里的示例"学"任务；示例：`thanks→merci, hello→bonjour, mint→menthe, otter→?` 输出 `loutre`。
34. 【slides】p49–52：**scaling laws**——放大模型带来**困惑度的可靠下降**；现代做法是**训练一个没完全收敛的大模型**（大小-数据权衡）；**训练代价 ≈ 参数 × token**；GPT-3 是 175B 参数 / 300B token，OpenAI 没选到最优参数-token 比——**某 70B 模型比更大的模型还好**。

### G. 学到了什么与风险（2 条）

35. 【slides】p54–55：预训练学到多种语言统计性质（见 9、10）；有时**记忆受版权保护的材料**。
36. 【slides】p56：**membership inference** 能恢复训练数据的一部分；这些数据有时是**半私密**的（地址、邮箱）。

## §5 术语索引

按首次出现的篇排。`01` 篇零前置，`02` 篇是本知识点核心概念，`04` 篇才需要推导背景。

| 术语 | 一句话解释 | 出处 |
|------|-----------|------|
| **预训练（pretraining）** | 在大规模无标注文本上先学通用语言能力 | `01` §5、`02` §2 |
| **微调（finetuning）** | 用少量标注数据把预训练模型适配到具体任务 | `02` §2 |
| **子词（subword）** | 介于"整词"和"字符"之间的词片段 | `02` §1 |
| **BPE（byte-pair encoding）** | 从字符起步、反复合并最高频相邻对的子词构建法 | `02` §1、`04` §2 |
| **WordPiece** | 现代预训练模型用的、与 BPE 类似的子词方法 | `02` §1 |
| **词尾符号 `</w>`** | 标记一个词片段的结尾，让切分可逆 | `02` §1 |
| **UNK** | 词表外词（out-of-vocabulary）统一映射到的占位符号 | `01` §4 |
| **CLM（causal LM）** | 只看左边、预测下一个词的语言模型目标 | `02` §3 §4 |
| **MLM（masked LM）** | 遮住一部分词、用两侧上下文重建它们的目标（BERT） | `02` §4、`04` §5 |
| **mask 比例 / 80-10-10** | BERT 遮 15%，其中 80% 换 `[MASK]`、10% 随机、10% 不变 | `02` §4、`04` §5 |
| **NSP** | BERT 的"下一句预测"任务，后被 RoBERTa 去掉 | `02` §3 |
| **span corruption** | 用占位符替换连续片段、再解码出来的目标（T5） | `02` §3 |
| **困惑度（perplexity）** | $=\exp(\text{NLL})$，等价于"模型在多大一个词表上犹豫" | `03` §3、`04` §4 |
| **shift 一位** | CLM 里把输入和目标的 token 错开一位对齐 | `04` §3 |
| **上下文化表示** | 同一个词在不同句子里得到不同向量（预训练整体模型的产物） | `02` §5、`03` §4 |
| **in-context learning** | 超大模型仅凭上下文示例、无梯度步地做任务 | `02` §5、`04` §8 |
| **scaling law** | 模型/数据/算力放大与损失下降之间的经验规律 | `04` §8 |
| **特征提取 vs 微调** | 冻结预训练参数只用表示 vs 解冻全部参数继续训 | `04` §9 |

## §7 下一课预告：K06 后训练（SFT / RLHF / DPO）

会复用本课的东西：**预训练得到的那个"只学会续写"的模型**，是本课 p19 "Step 1" 的产物，也是 K06 的**起点**。

会变的一件事——**目标对齐**：

1. **预训练的目标是"续写"，不是"听话"** —— 模型擅长补全，但不一定遵守指令、不一定有用无害（本课 p46 只说"超大模型能从上下文里的示例学到任务"，没说它会**听你的话**）。
2. K06 要解决的就是把"续写器"变成"助手"：**SFT**（示范微调）→ **RLHF**（用人类偏好训奖励模型再优化）→ **DPO**（绕开奖励模型直接优化）。

**本课的收益落点**：p46–p47 的 in-context learning 和 p52 的"代价 ≈ 参数 × token"，是理解"为什么要后训练、为什么全参微调很贵（→ K07 LoRA）"的直接前提。

### 本课没能验证的部分

1. **PDF 内部标题写成 "Lecture 6: Pretraining"**（p1 与 p2 的 Lecture Plan）：文件名叫 `lecture07`，官网的 Lecture Plan 编号也写成 "Lecture 6"。原文如此，不是我抄错（与 K02 的 "Lecture 2: Neural Network Foundations" 同类印刷问题）。
2. **p22 / p44 / p48 / p51 等页的主体内容是图片**（表格、示意图、散点图），PDF 文字层提取为空白。本课凡涉及这些页只写"有一张图/表，讲的是 X"，没有编造图里的数字。
3. **本课实测的规模都是玩具级**：`03` 的受控对比是"768 句、词表 24、向量 16 维、792 个参数"，讲的是**机制**（方向 vs 监督密度），**不能外推到真实规模**。真实模型上"双向更强 / MLM 表示更好"是经验结论（本课没有复现）。
4. **受控语料是故意构造的**：`03` §3 为了让"单边看不清、双边看得清"显式成立，专门构造了"第 2 位由一个右侧词决定"的语料。**它是用来演示机制的，不代表自然语言必然如此**——`03` §3 末尾会明确说明这一点。
5. **"15% 与 80/10/10"是 BERT 的选择，不是理论最优**：slides 未给推导，`04` §5 只做"期望监督位数量"的推算，不证明 15% 最优。
6. **GPT-3 的 in-context learning 例子来自 slides**（p47），我**没有模型可复现**；"没有梯度步"是 slides 的口径。
7. **本课先于 K06 交付**：p19 的"预训练/微调"只讲到微调为止；SFT/RLHF/DPO 的完整内容在 K06，本课不展开。
