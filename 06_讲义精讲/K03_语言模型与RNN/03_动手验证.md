## §2 验证一：RNN 前向——权重共享 + 隐藏状态滚雪球

**断言**（`02` §4）：$h^{(t)}=f(W_{hh}h^{(t-1)}+W_{xh}x^{(t)}+b)$，同一组权重每个时刻都用一次，$h$ 把上一步的值卷进来。

**你的预期**：$h^{(0)}=0$ 时（全零初始状态），第 1 个时刻的 $h^{(1)}$ 还受上一状态影响吗？为什么？

**【实测】** 随机初始化 $W_{xh}\in\mathbb{R}^{4\times3}$、$W_{hh}\in\mathbb{R}^{4\times4}$、$W_{hy}\in\mathbb{R}^{3\times4}$，输入 4 个时刻：

```
h_0 = [0. 0. 0. 0.] （初始隐藏状态，全 0）
h_1 = [ 0.193988 -0.031849  0.822237 -0.954416]
h_2 = [-0.472134  0.075503 -0.866251  0.259975]
h_3 = [ 0.765382  0.561349 -0.388622 -0.117253]
h_4 = [-0.859946 -0.608181  0.74637  -0.047267]
每步交叉熵损失 = [1.285946 1.49795  0.772809 1.73005 ]
整段 loss（求和）= 5.286755
```

**对账**：$h^{(1)}$ **只**由 $x^{(1)}$ 决定（因为 $h^{(0)}=0$，$W_{hh}h^{(0)}$ 那一项是 0）；从 $h^{(2)}$ 起才受上一步影响。**同一个 `rnn_forward` 循环里，$W_{hh}/W_{xh}$ 在 4 次迭代中是同一组变量**——这就是"权重共享"最直白的实证。

**再对一次手算**（`02` §4.1 的最小 RNN：4 词表、隐藏维 1）：

```
输入 the  z = 1.00000   h = tanh(z) = 0.76159
输入 cat  z = 1.38080   h = tanh(z) = 0.88113
输入 sat  z = 2.44056   h = tanh(z) = 0.98494
t=3 的 logits（the/cat/dog/sat）= [ 0.984937  0.       -0.984937  0.984937]
t=3 的 softmax = [0.397941 0.148616 0.055503 0.397941]  和 = 1.0
```

**对账**：与 `02` §4.1 手算表**逐位一致** ✅。**手算能对上代码，说明 `02` 的隐藏状态机制没有理解偏差。**

## §3 验证二：BPTT = 按时刻反传 + 累加

**断言**（`02` §6、【slides】PAGE 33）：对重复出现的权重 $W_{hh}$，梯度是**各次出现处梯度之和**——即"沿时间反传、逐时刻累加"，不是"取最后一次"。

**你的预期**：如果我在反传时**忘了累加**（每步覆盖 `dh` 而不是相加），$\partial L/\partial W_{hh}$ 会比对的值偏大还是偏小？

**【实测】** 用 `02` §4 的同一网络（T=4），手推 BPTT 与中心差分（$h=10^{-5}$）对比：

| 梯度 | 手推 vs 数值 max\|差\| |
|------|------------------------|
| $\partial L/\partial W_{hh}$ | $5.9\times10^{-11}$ |
| $\partial L/\partial W_{xh}$ | $2.2\times10^{-10}$ |
| $\partial L/\partial b_h$ | $6.1\times10^{-11}$ |
| $\partial L/\partial W_{hy}$ | $4.4\times10^{-11}$ |
| $\partial L/\partial b_y$ | $4.3\times10^{-11}$ |

再与 `torch.autograd`（手动展开 T 步的同一计算）对比：

```
[torch] ∂L/∂W_hh max|autograd-手推| = 1.6653345369377348e-16
[torch] ∂L/∂W_xh max|autograd-手推| = 4.440892098500626e-16
[torch] ∂L/∂W_hy max|autograd-手推| = 3.3306690738754696e-16
[torch] loss 与 numpy 实现的 loss 差 = 0.0
```

**对账**：

| 对比 | 结果 | 说明 |
|------|------|------|
| 手推 vs 数值 | $\sim10^{-10}$ | 数值梯度的固有误差（K02 §8 的量级） |
| 手推 vs autograd | $\sim10^{-16}$ | **autograd 做的就是这件事，精确到浮点** |
| 损失值 | 差 $0.0$ | 两边前向完全一致 |

**回答那个预期**：**忘了累加会得到偏小的 $W_{hh}$ 梯度（丢掉更早时刻的贡献）**，而且是"**静默**"的——不报错、loss 只是学得慢。这正是 T2 文档第 3 条坑（"RNN 部分 forget `dh_prev` 的累加"）的原型。

**这一屏意味着什么**：

> **BPTT 不是新数学。** 它就是 K02 的链式法则 + `02` §6 那张展开图：从末端往回走，每个时刻把梯度加到同一块 $W_{hh}$ 上，$h^{(t)}$ 同时接收"输出那条边"和"下一时刻那条边"的梯度（分叉处相加）。

## §4 验证三：梯度消失 / 爆炸 = ∏ 雅可比的模长

**断言**（`02` §7、【slides】PAGE 41–46）：长程信息难取，是因为 $\partial h^{(T)}/\partial h^{(0)}$ 是**一长串雅可比连乘**；连乘的模长要么衰减到 0（消失）、要么放大到爆（爆炸）。

**你的预期**：把循环权重 $W$ 的**谱半径**记作 $r$（这里取 $W=r\times$正交矩阵，故 $\|W\|_2=r$ 精确成立）。$r=0.5$、步数 $T=20$ 时，$r^{20}$ 大概是多少个数量级？

### 4A. 先用线性 RNN 看清 ∏W（不含 tanh，$\partial h^{(T)}/\partial h^{(0)}=W^{20}$）

```
    r |        ‖W^20‖₂ |   与 r^20 比
  0.5 |   9.536743e-07 |   1.000000
  0.9 |   1.215767e-01 |   1.000000
  1.0 |   1.000000e+00 |   1.000000
  1.1 |   6.727500e+00 |   1.000000
  1.5 |   3.325257e+03 |   1.000000
  2.5 |   9.094947e+07 |   1.000000
```

**对账**：$\|W^{20}\|_2$ **精确等于** $r^{20}$（最后一列比值恒为 1.000000——因为正交矩阵的谱范数是 1）。逐个核：

- $0.5^{20}=9.5\times10^{-7}$（衰减 6 个数量级）
- $1.5^{20}=3.3\times10^{3}$、$2.5^{20}=9.1\times10^{7}$（放大 7–8 个数量级）

**一屏看懂连乘**：

> **谱半径 $r<1$ → 梯度消失**（远端信号被连乘抹平到 $10^{-7}$）；**$r>1$ → 梯度爆炸**（$10^{7}$）。**这就是 T2 验收 A4 说的"从 $\prod W$ 的谱范数说起"。**

### 4B. 加回 tanh（真实 vanilla RNN）

真实 RNN 的每步因子是 $r\cdot\tanh'(z)$，而 $\tanh'\le1$：

```
    r |     ‖∏ D_t W‖₂ |        ‖回传梯度‖₂
  0.5 |   9.439158e-07 |   1.695199e-06
  0.9 |   9.520156e-02 |   1.365554e-01
  1.0 |   5.044221e-01 |   6.642865e-01
  1.1 |   1.147632e+00 |   1.613501e+00
  1.5 |   3.683295e+00 |   5.554319e+00
  2.5 |   1.836761e-01 |   2.726932e-01
```

**对账**，两个必须停下来看的点：

1. **$r=1$ 也在衰减**（$\|J\|_2=0.504$，不是 1）。因为每步因子 $\approx r\cdot\tanh'$，$\tanh'\le1$ 且多数位置 $<1$。**这是"消失"比"爆炸"更常见的原因**——不是只有 $r<1$ 才消失。
2. **$r=2.5$ 反而比 $r=1.5$ 小**（$1.84\times10^{-1}$ vs $3.68$）。这不是错：状态被 $\tanh$ 推进**饱和区**，$D_t=\text{diag}(1-h^2)\to0$，连乘被"自动刹车"。**真实的 tanh RNN 因此更偏消失、而非爆炸**——这与【slides】PAGE 50 的判断一致（"爆炸好解决，消失难"）。

> ⚠️ **诚实边界**：这一节是**构造网络上的机制演示**，讲的是"连乘导致衰减/爆炸"这一**机制**，**不能外推到真实规模**——真实 RNN 还受初始化、每层尺度、梯度剪裁等共同影响。

## §5 验证四：梯度剪裁治爆炸、不治消失

**断言**（【slides】PAGE 49）：若梯度范数超阈值，就**按比例缩小**再更新——"同方向、小步走"。

**你的预期**：剪裁后梯度的**方向**变不变？如果梯度是"太小"（消失）那一侧，剪裁能帮上忙吗？

**【实测】** 取 4A 中 $r=2.5$ 的回传梯度（一个真实的大梯度向量），阈值 $1.0$、学习率 $0.1$：

```
原始梯度范数 ‖g‖₂ = 1.818989e+08
剪裁后范数        = 1.0000000000
方向余弦 cos(g, g_clipped) = 1.000000000000（=1 表示方向没变）
剪裁前一步 ‖Δθ‖ = lr·‖g‖      = 1.818989e+07（'一下跳到 Iowa'）
剪裁后一步 ‖Δθ‖ = lr·‖g_clip‖ = 0.100000（同方向、小步走）
```

**对账**：

| 量 | 结果 | 含义 |
|----|------|------|
| 剪裁后范数 | $=1.000000$（等于阈值） | 超阈就压到阈值 |
| 方向余弦 | $=1.000000$ | **方向完全不变**（只是缩放） |
| 步长 | $1.8\times10^{7}\to0.1$ | 一步从"跳出盆地"变成"走一小步" |

**回答那个预期**：

> **剪裁只动"长度"，不动"方向"**。所以它专门治**爆炸**（把过大的步长压回来）。
> 对**消失**——梯度本来就**小于**阈值，剪裁条件根本不触发，**一点作用都没有**。
> **这就是 T2 验收 A5 的答案**：剪裁治爆炸不治消失；消失要靠 LSTM / attention / residual 这类**改变连乘结构**的手段（`04` §6）。

## §6 验证五：perplexity = exp(交叉熵)

**断言**（【slides】PAGE 39）：LM 的标准指标是 **perplexity = 交叉熵的指数**，越小越好。

**你的预期**：交叉熵 = 0 时 perplexity 是多少？一个在 $V=1000$ 个词上**均匀瞎猜**的模型，perplexity 是多少？

**【实测】**：

```
交叉熵 CE = 0.000000  →  perplexity = 1.000000
交叉熵 CE = 0.693147  →  perplexity = 2.000000
交叉熵 CE = 1.000000  →  perplexity = 2.718282
交叉熵 CE = 2.302585  →  perplexity = 9.999999
交叉熵 CE = 6.907755  →  perplexity = 999.999721

均匀分布模型：词表 V = 1000
  CE_uniform = log(V) = 6.907755
  ppl_uniform = exp(log V) = V = 1000.000000
```

**对账**：

- **$\text{ppl}=\exp(\text{CE})$ 逐点成立**（$\ln2=0.693147\to2$、$\ln10=2.302585\to10$）。
- **均匀瞎猜时 $\text{ppl}=V$**：在 1000 个词上均匀猜，perplexity 就是 1000——**这就是"完全没学到"的基线**。perplexity 越低，模型越"不困惑"。
- **CE=0 → ppl=1**：完美预测的极限（每步都以概率 1 押中），实战到不了。

> **为什么用指数、不用交叉熵本身**：交叉熵是对数的、单位不直观；取指数后它变成"**模型实际在多少个词之间犹豫**"，可读。`05` §1 会把它和具体词表规模对照。
