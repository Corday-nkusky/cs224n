## §3 知识清单

每条一句话结论 + 出处。**扫一遍，看有没有哪条你讲不出来。**

### A. 语言建模任务（4 条）

1. 【slides】PAGE 3：语言建模 = **预测下一个词**（"the students opened their ______"）；形式化：给定词序列 $w^{(1)},\dots,w^{(t)}$，算下一个词 $w^{(t+1)}$ 的**概率分布**，候选是**整个词表**里任意词。
2. 【slides】PAGE 4：换个角度，语言模型是**给一段文本打概率**：$P(w^{(1)},\dots,w^{(T)})=\prod_t P(w^{(t)}\mid w^{(1)},\dots,w^{(t-1)})$——"这是我们的 LM 提供的东西"。
3. 【slides】PAGE 7：LM 是衡量"语言使用预测"进度的**基准任务**，也是很多生成/打分任务的**子部件**；"Everything else in NLP has been rebuilt upon Language Modeling: **ChatGPT is an LM!**"
4. 【slides】PAGE 8：足够强的下一个词预测器**顺带会做很多事**——事实问答、句法、指代、主题、情感，甚至一点推理和算术（slides 给了一串填空例子）。

### B. n-gram 语言模型及其死穴（6 条）

5. 【slides】PAGE 9：**n-gram = n 个连续词组成的片段**（unigram/bigram/trigram/four-gram）；做法是**统计各 n-gram 的频率**来预测下一个词。
6. 【slides】PAGE 10：先做 **Markov 假设**：$x^{(t+1)}$ 只依赖前 $n-1$ 个词（统计近似）；于是 $P(x^{(t+1)}\mid x^{(t)},\dots,x^{(1)})\approx \dfrac{\text{prob}(n\text{-gram})}{\text{prob}((n-1)\text{-gram})}$，分子分母都**靠在大语料里计数**得到。
7. 【slides】PAGE 11：实例——4-gram 下 $P(\text{books}\mid\text{students opened their})=400/1000=0.4$、$P(\text{exams}\mid\dots)=100/1000=0.1$（条件是 "students opened their"，前文 "as the proctor started the clock" 被**丢弃**）。
8. 【slides】PAGE 12：**稀疏问题 1**——"students opened their" 在语料里没出现过，则对**任何** $w$ 都算不出概率；**部分解法 = backoff**（退一步只条件于 "opened their"）。**稀疏问题 2**——"students opened their $w$" 没出现过，则 $w$ 概率为 0；**部分解法 = smoothing**（给每个 $w\in V$ 的计数加一个小 $\delta$）。
9. 【slides】PAGE 12–13：**n 越大稀疏越严重**，通常 **$n\le 5$**；**存储问题**——要存语料里见过的所有 n-gram 计数，**n 或语料变大，模型就变大**。
10. 【slides】PAGE 14–18：真实 trigram（Reuters 170 万词，笔记本几秒建好）**分布没有粒度**（company 0.153、bank 0.153…）；生成文本"**Surprisingly grammatical! … but incoherent**"——要建模好语言必须看超过三个词，可**增大 n 又加剧稀疏、撑大模型**。

### C. 固定窗口神经语言模型（3 条）

11. 【slides】PAGE 20–21：把前 $n-1$ 个词**固定窗口**内的词向量**拼接**，过一个隐藏层，再 softmax 出下一个词分布（近似 **Bengio et al. 2000/2003** 的 Neural Probabilistic Language Model）。
12. 【slides】PAGE 22：**相对 n-gram 的改进**——① 没有稀疏问题；② 不必存所有观测到的 n-gram。
13. 【slides】PAGE 22：**剩余问题**——① 固定窗口太小，**放大窗口就放大 $W$**，而且**窗口永远不够大**；② $x^{(1)}$ 和 $x^{(2)}$ 在 $W$ 里被**完全不同的权重**相乘，**输入处理没有对称性**。→ 需要一个**能处理任意长度输入**的架构。

### D. RNN 语言模型（6 条）

14. 【slides】PAGE 23：RNN **核心思想：同一组权重 $W$ 被反复使用**（"Apply the same weights $W$ repeatedly"）；是一类能处理**任意长度输入序列**的架构，输出可选。
15. 【slides】PAGE 24：RNN-LM 的每个时刻 $t$ 用**词的 one-hot/embedding** + **上一时刻的隐藏状态** $h^{(t-1)}$ 算出新的 $h^{(t)}$；$h^{(0)}$ 是**初始隐藏状态**；输出分布由 $h^{(t)}$ 得到。
16. 【slides】PAGE 25：**RNN 优势**——① 可处理任意长度输入；② 理论上第 $t$ 步的计算能用到很多步之前的信息；③ 模型大小**不随上下文长度增长**；④ 每个时刻用同一组权重，**输入处理有对称性**。**RNN 劣势**——① 循环计算**慢**（不能并行）；② 实践中**很难取到很多步之前的信息**。
17. 【slides】PAGE 26：训练目标——每个时刻 $t$ 的损失是**预测分布 $\hat y^{(t)}$ 与真实下一词 $y^{(t)}$（one-hot）的交叉熵**，整段/整集取平均。
18. 【slides】PAGE 31：**Teacher forcing**——训练时把**真实**的上一词（而非模型自己采样出的词）喂进下一步，各时刻损失相加得总损失。
19. 【slides】PAGE 32：**一次在整个语料上算损失/梯度太贵（内存）**；实践中把 $x^{(1)},\dots,x^{(T)}$ 当作**一句话（或一个文档）**，按 SGD 一小批一小批算损失、更新、换新批。

### E. BPTT 与梯度问题（8 条）

20. 【slides】PAGE 33：**对重复权重求梯度 = 各次出现处梯度之和**（"The gradient w.r.t. a repeated weight is the sum of the gradient w.r.t. each time it appears"）。
21. 【slides】PAGE 35：**BPTT（backpropagation through time）**——沿时刻 $i=t,\dots,0$ **反传、边传边求和**（Werbos 1988）；实践中常 **truncated 到约 20 步**以省算力。
22. 【slides】PAGE 41–45：用链式法则一层层往回乘；**当这些局部因子很小时，梯度信号越往回传越小**——这就是**梯度消失**（来源：Pascanu et al. 2013）。
23. 【slides】PAGE 46：远端梯度信号因**远小于近端**而丢失 → 权重只按**近端效应**更新，学不到**长期效应**。
24. 【slides】PAGE 47：具体后果——要学到 "tickets"（第 7 步）和句末目标词的依赖，但梯度小时学不到，测试时也**预测不了这类长距离依赖**。
25. 【slides】PAGE 48：**梯度爆炸**——梯度太大使 SGD 步长太大，走到"又怪又差"的参数点（"你以为找到一座山，结果人在爱荷华"），最坏产生 **Inf/NaN**，只能从早期 checkpoint 重来。
26. 【slides】PAGE 49：**梯度剪裁**——若梯度范数超过阈值就**先按比例缩小**再更新；直觉是"**同方向、小步走**"。实践中**记得剪裁很重要，但爆炸是好解决的**。
27. 【slides】PAGE 50：**缓解消失的方向**——根因是 vanilla RNN 的隐藏状态**不断被重写**、难以跨多步保留信息；① 用**带独立记忆、往里"加"** 的结构（**LSTM**）；② 造**更直接、更线性的直通连接**（**attention、residual connections** 等）。

### F. 评测与机器翻译（4 条）

28. 【slides】PAGE 39：LM 的标准评测指标是 **perplexity**，**等于交叉熵损失的指数**（$=\left(\prod_t \frac{1}{P(w^{(t)}\mid\dots)}\right)^{1/T}$），**越小越好**。
29. 【slides】PAGE 51–52：**机器翻译（MT）** 把源语言句子 $x$ 翻成目标语言 $y$；**NMT** 从 2014 边缘尝试变成 2016 主流，**2016 谷歌翻译从 SMT 切到 NMT**——多年、数百工程师搭的 SMT 被小团队几个月训的 NMT 超过。
30. 【slides】PAGE 53–55：**Encoder–Decoder（seq2seq）**——Encoder RNN 把源句压成一个**编码**（作为 Decoder 的初始隐藏状态）；Decoder RNN 是**条件语言模型**（"Language Model because 预测目标句子下一词；Conditional because 条件于源句 $x$"），直接算 $P(y^{(t)}\mid y^{(1)},\dots,y^{(t-1)},x)$。
31. 【slides】PAGE 54：**seq2seq 通用**——输入/输出都是序列就能套：摘要、对话、句法分析、代码生成。PAGE 56–57：seq2seq **端到端单系统训练**，反向传播贯穿 encoder+decoder；可堆成**多层深度 encoder-decoder**。

### G. Bottleneck（1 条，K04 的钩子）

32. 【slides】PAGE 57–58：Encoder 把整句压成**一个向量**，Decoder 只靠它生成——"Conditioning = **Bottleneck**"。slides 直接在 PAGE 58 发问 "Problems with this architecture?"——**这就是引向下节课 attention 的钩子**。

## §5 术语索引

按首次出现的篇排。`01` 篇零前置，`02` 篇是本知识点核心概念，`04` 篇才需要推导背景。

| 术语 | 一句话解释 | 出处 |
|------|-----------|------|
| **语言模型（LM）** | 预测下一个词 / 给文本打概率的系统 | `01` §2 |
| **n-gram** | n 个连续词组成的片段 | `01` §3 |
| **Markov 假设** | 下一词只依赖前 $n-1$ 个词的统计近似 | `01` §3 |
| **稀疏问题** | 语料里没见过的 n-gram 使概率算不出或为 0 | `01` §4 |
| **backoff** | 退一步用更短的上文条件 | `01` §4 |
| **smoothing** | 给每个词的计数加小 $\delta$，避免概率为 0 | `01` §4 |
| **固定窗口神经 LM** | 拼接窗口内词向量 → 隐藏层 → softmax | `02` §2 |
| **隐藏状态 $h^{(t)}$** | RNN 在时刻 $t$ 的"记忆"，由当前输入与上一步状态算出 | `02` §3 |
| **权重共享** | 每个时刻用同一组 $W$，输入处理有对称性 | `02` §3 |
| **RNN 语言模型** | 用 $h^{(t)}$ 产生下一词分布的语言模型 | `02` §4 |
| **teacher forcing** | 训练时喂真实的上一词，而不是模型自己的输出 | `02` §5 |
| **展开计算图** | 把 RNN 沿时间摊开成一张深网络 | `02` §6、`04` §2 |
| **BPTT** | 沿时间反传、逐时刻累加梯度的反向传播 | `03` §3、`04` §2 |
| **梯度消失** | 局部因子连乘 <1，远端梯度信号衰减到 0 | `03` §4、`04` §3 |
| **梯度爆炸** | 局部因子连乘 >1，梯度指数放大 → Inf/NaN | `03` §4、`04` §3 |

| **梯度剪裁** | 梯度范数超阈值时按比例缩小，方向不变 | `03` §5、`04` §5 |
| **LSTM** | 带独立记忆单元、可"加"入信息的 RNN 变体 | `04` §6 |
| **perplexity** | 交叉熵的指数，越小越好；均匀模型下 = 词表大小 | `03` §6、`04` §4 |
| **seq2seq** | 编码器-解码器，输入输出都是序列 | `04` §7 |
| **条件语言模型** | 预测目标下一词时还条件于源句 $x$ 的 LM | `04` §7 |
| **bottleneck** | 整句被压成一个向量，成为信息传递的瓶颈 | `04` §8 |

## §7 下一课预告：K04 注意力与 Transformer

本课留下的两个口子，正是 K04 要堵的：

1. **RNN 不能并行、长程记不住**（PAGE 25）：每步依赖上一步 → 训练串行；梯度连乘 → 远端信号衰减。**K04 的注意力用"任意两位置直连"同时解决这两点**——这正是 PAGE 50 点名的 "attention, residual connections, etc."。
2. **bottleneck**（PAGE 57–58）：seq2seq 把整句压成一个向量，长句信息装不下。**注意力让解码器每步直接回看源句的每个位置**，不再依赖单个编码向量。

会复用的东西：**"写损失 → 求梯度 → SGD"完全一样**；本课 PAGE 33 的"重复权重梯度 = 各次出现处之和"在 K04 里变成"同一个权重被所有位置使用 → 梯度在所有位置求和"。会新增的：**O(n²) 复杂度、位置编码、多头、海量数据**（K04 的新代价）。

**本课的收益在 T2 立刻兑现**：验收 A4（∏W 谱范数 + 三种缓解手段代价）与 A5（剪裁治爆炸不治消失）的问答，全部取自本课 `03` §4–§5、`04` §3 §5–§6。
