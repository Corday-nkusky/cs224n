# K03 · 02 它到底是什么

> **进这一篇之前你能说出什么**：① 上一代 n-gram 死在三处——没见过就为零、存不下、看不了超过几个词；② 这些是计数法的硬伤，不是调参能救；③ 出路是"表示随语境变 + 能读任意长度"。
> **这一篇回答什么**：固定窗口神经 LM 长什么样、还剩什么问题？"同一组权重反复用"是什么意思？隐藏状态怎么更新？训练时数据怎么喂？
> **读完你应该能说出什么**：
> 1. 固定窗口神经 LM = **拼接窗口内词向量 → 隐藏层 → softmax**；它没稀疏问题，但**窗口固定 + 输入处理不对称**
> 2. RNN 的隐藏状态 $h^{(t)}=f\big(W_{hh}h^{(t-1)}+W_{xh}x^{(t)}+b\big)$，**同一组权重每个时刻都复用**
> 3. 训练用**交叉熵**（每步都算），**teacher forcing** 喂真实的上一词；按**句子/batch** 喂
> 4. 把 RNN 沿时间**展开**成深的计算图 → K02 的"分叉处相加"变成"**每个时刻相加**"

**这一篇几乎不推公式、不跑代码。** 会给几个定义式（隐藏状态、损失），但只是把话说成符号，**不往下推任何结论**——真正需要推导的都在 `04`。所有例子都小到能手算。
**这一篇的目的是让你在 `03` 里看见那些数字时，知道每个数字是什么、该不该长那样。**

## §1 语言模型，用符号说一遍

`01` 的行为描述，写成符号：

**预测下一词**：给定序列 $x^{(1)},\dots,x^{(t)}$，算

$$
P\big(x^{(t+1)}\mid x^{(t)},\dots,x^{(1)}\big)
$$

其中 $x^{(t+1)}$ 可以是**词表 $V$ 里任意一个词**。

**给整段打分**（`01` §2 的连乘）：

$$
P(x^{(1)},\dots,x^{(T)})=\prod_{t=1}^{T}P\big(x^{(t)}\mid x^{(t-1)},\dots,x^{(1)}\big)
$$

> **记号约定**（沿用 K01/K02）：$x^{(t)}$ 是时刻 $t$ 的输入词（**上标是时间，不是次方**——这一点和 K02 的 $h^{(l)}$ 层号写法一致，读的时候别混）；$V$ 是词表大小；$h^{(t)}$ 是隐藏状态。

**注意和 K01/K02 的区别**：K01 里 $x$ 是一个**固定的**窗口表示，与位置无关；这里 $x^{(t)}$ 是**第 $t$ 个位置**的输入，模型要**随位置变化**地处理它。

## §2 第一条路：固定窗口神经语言模型

最直接的改法：**别数数了，用一个神经网络**。取前面若干词（固定个数的**窗口**），预测下一个：

```
     the students opened their | ______
     └──────── 固定窗口 ───────┘   ↑ 要预测
```

【slides】PAGE 20–22 的架构是四步（和你 K02 §2 手算过的 NER 窗口模型**同构**）：

$$
[x^{(t-n+1)};\dots;x^{(t)}]
\;\to\; \text{拼接词向量}
\;\to\; a=Wx+b
\;\to\; h=f(a)
\;\to\; \hat y=\text{softmax}(Uh+c)
$$

| 步 | 在干什么 |
|----|---------|
| **拼接** | 把窗口里每个词的**稠密词向量**首尾接成一个长向量（K01/K02 的表示学习：这些词向量**也是参数**，一起训） |
| **隐藏层** | 一个仿射变换 + 非线性（K02 的神经元） |
| **softmax** | 输出**词表上**的概率分布 $\hat y\in\mathbb{R}^{V}$ |

【slides】PAGE 22 的两句总结，一句都不能漏：

> **Improvements over n-gram LM:** "No sparsity problem" + "Don't need to store all observed n-grams."
> **Remaining problems:** "Fixed window is too small" ；"Enlarging window enlarges $W$" ；"Window can never be large enough!" ；"$x^{(1)}$ and $x^{(2)}$ are multiplied by **completely different weights** in $W$. **No symmetry** in how the inputs are processed."

**翻译成人话**：

| 类别 | 内容 |
|------|------|
| **赢在哪** | 表示是**稠密的**——没见过的组合也能算出**非零**概率（稀疏问题解除）；参数是**固定的权重**，不随语料里见过多少 n-gram 膨胀（存储问题解除） |
| **输在哪** | ① **窗口固定**：看不了比窗口更远的东西；② **想看得更远就得放大窗口 → $W$ 变大**，而且**窗口永远不够大**；③ **对称性缺失**：窗口里第 1 个词和第 2 个词用的是 $W$ 里**不同的权重**，**同样一个词出现在不同位置，处理方式完全不同** |

> **【直觉】问题③ 用 408 打比方**：好的硬件抽象里，"同一件事在不同位置"应当走**同一条数据通路**；固定窗口模型却给每个位置**单独布线**（$W$ 的每一列各管一个位置）。**没有对称性 = 换个位置就要重新学一遍。**

**结论**（【slides】PAGE 22 原话）：**"We need a neural architecture that can process any length input."**

## §3 核心思想：同一组权重，每个时刻都用一次

RNN 的想法就一句话（【slides】PAGE 23）：

> **Core idea: Apply the same weights $W$ repeatedly.**

**把固定窗口里"每个位置一套权重"改成"所有位置共用同一套权重"，然后让输出**再喂回**给下一步——于是序列可以无限长下去：

- 位置不再有专属权重 → **对称性**回来了（同一个词在任何位置都走同一套 $W$）；
- 参数量不随序列长度涨 → **模型大小固定**；
- 序列有多长就喂多长 → **任意长度输入**。

【slides】PAGE 23 把 RNN 定义成"**a family of neural architectures**"：输入序列任意长、有隐藏状态、输出可选。

> **【直觉】对照你 408 里的东西**：固定窗口像**给每个通道单独拉一根线**；RNN 像**一个带反馈的时序电路**——每一步的输出存进寄存器，下一步连本步输入带**那个寄存器**一起算，再写回寄存器。**同一套组合逻辑，时钟每拍复用一次。**

## §4 隐藏状态怎么更新（RNN 的心脏）

RNN 在每个时刻记着一份"到目前为止读过什么的摘要"，叫**隐藏状态** $h^{(t)}$。它由**上一步的状态**和**当前输入**共同算出：

$$
\boxed{\;h^{(t)}=f\big(W_{hh}\,h^{(t-1)}+W_{xh}\,x^{(t)}+b\big)\;}
$$

| 符号 | 含义 |
|------|------|
| $x^{(t)}$ | 第 $t$ 个词的**词向量**（dense embedding，和 K01/K02 一样，是参数） |
| $h^{(t-1)}$ | 上一步的隐藏状态（"记忆"） |
| $W_{hh}$ | 处理**上一步状态**的权重 |
| $W_{xh}$ | 处理**当前输入**的权重 |
| $b$ | 偏置 |
| $f$ | 非线性（slides 用 $\tanh$） |
| $h^{(0)}$ | **初始隐藏状态**（【slides】PAGE 24，通常取 0） |

然后**用 $h^{(t)}$ 产生这一步的输出分布**（预测下一个词）：

$$
\boxed{\;\hat y^{(t)}=\text{softmax}\big(W_{hy}\,h^{(t)}+c\big)\;}
$$

**关键**：$W_{hh},W_{xh},W_{hy}$ **在所有时刻都是同一组**。这就是 §3 说的"同一组权重反复用"。

> **【直觉】信息像"滚雪球"**：$h^{(t)}$ 把上一部的摘要卷进来再加工。**理论上**第 $t$ 步能用上很早就出现的信息（它一路卷过来了）；但**实践中**每加工一次都会**覆盖/稀释**旧信息（【slides】PAGE 25 与 PAGE 50："the hidden state is constantly being rewritten"）——这就是 `03`/`04` 梯度问题的根。

### 4.1 手算一个最小 RNN（3 句话语料、4 个词的量级）

语料就一句：`the cat sat`；词表 $V=\{\text{the},\text{cat},\text{dog},\text{sat}\}$（**4 个词**，够小）。

给词**手工**指派 2 维词向量：

| 词 | 向量 |
|----|------|
| the | $[1,0]$ |
| cat | $[0,1]$ |
| dog | $[0,-1]$ |
| sat | $[1,1]$ |

参数：$W_{xh}=[1,1]$（1×2）、$W_{hh}=0.5$（1×1）、$b=0$、$h^{(0)}=0$。**隐藏维取 1**，好手算。

**逐时刻更新**（$h^{(t)}=\tanh(W_{xh}x^{(t)}+0.5\,h^{(t-1)})$）：

| $t$ | 输入 $x^{(t)}$ | $W_{xh}x^{(t)}$ | $0.5\,h^{(t-1)}$ | $z^{(t)}$ | $h^{(t)}=\tanh z^{(t)}$ |
|-----|----------------|-----------------|------------------|-----------|--------------------------|
| 1 | the $[1,0]$ | 1 | 0（$h^{(0)}=0$） | 1.00000 | **0.76159** |
| 2 | cat $[0,1]$ | 1 | 0.38080 | 1.38080 | **0.88113** |
| 3 | sat $[1,1]$ | 2 | 0.44057 | 2.44056 | **0.98494** |

**看到两件事**：

1. **同一个 $W_{xh}=[1,1]$ 在 3 个时刻用了 3 次**——权重共享不是口号，是这 3 行的同一个数。
2. $h$ 在**滚雪球**：从 0.76159 涨到 0.88113 再涨到 0.98494，**每一步都掺进了上一步的值**（$0.5\,h^{(t-1)}$ 那一列）。

**取 $t=3$ 的输出来预测"sat 之后的下一个词"**。设 $W_{hy}=[[1],[0],[-1],[1]]$（对应 the/cat/dog/sat）：

| 词 | logit $=W_{hy}h^{(3)}$ | softmax |
|----|------------------------|---------|
| the | 0.98494 | 0.39794 |
| cat | 0 | 0.14862 |
| dog | −0.98494 | 0.05550 |
| sat | 0.98494 | 0.39794 |

（四者之和 $=1$。）**模型此刻更看好 the / sat**——因为我们**没有训练**它，向量和权重都是我手填的，这堆数字只是演示"前向怎么算"。**训练之后它会学出有意义的分布。**（`03` 会用真代码把同样的前向跑一遍。）

## §5 怎么训练：每步一个交叉熵 + teacher forcing

### 5.1 每个时刻都要预测，都要算损失

【slides】PAGE 26：每个时刻 $t$，损失是**预测分布 $\hat y^{(t)}$ 与真实下一词 $y^{(t)}$（one-hot）的交叉熵**（K02 §6 的老朋友）：

$$
J^{(t)}=-\log P\big(x^{(t+1)}\mid x^{(t)},\dots,x^{(1)}\big)
$$

整段/整集再**取平均**得总损失：

$$
J=\frac{1}{T}\sum_{t=1}^{T}J^{(t)}
$$

【slides】PAGE 27–30 一页一页展示：一步的损失就是"**真实下一个词的负对数概率**"——"the" 后面该接 "students"、就给 $- \log P(\text{students})$，以此类推。

### 5.2 Teacher forcing：训练时喂**真实**的上一词

【slides】PAGE 31 给了这个名字。**训练时**把语料里**真实的**上一个词当输入喂进下一步（而不是模型自己采样出来的词）——"the" 之后喂真的 "students"，而不是模型猜的那个词。这样每一步的输入都是干净的、并行的，训练更稳。

> **术语预告**：这叫 **teacher forcing**。"老师逼着"模型每步都从正确答案出发。**生成（测试）时**就不行了——那时没有真实答案，只能把**模型自己的输出**再喂回去（【slides】PAGE 36）。

### 5.3 按句 / 按 batch 喂，不是一次喂整个语料

【slides】PAGE 32：一次在整个语料上算损失和梯度**太贵（内存）**。做法：

- 把 $x^{(1)},\dots,x^{(T)}$ 当作**一句话**（或一个文档）→ 算这句话的损失、梯度、更新；
- **重复**：换**新的一批句子**（batch）再算。

这就是 K02 的 SGD（小批数据 → 算损失 → 更新），**只是"一个样本"从"一个窗口"变成了"一句话"。**

## §6 把 RNN 沿时间**展开**：K02 的计算图长长了

这是本课和 K02 的**接口**。

K02 的计算图是一张**有向无环图**，反向按拓扑反序传梯度。RNN 看起来**有环**（$h^{(t)}$ 依赖 $h^{(t-1)}$）——但只要把**时间轴摊开**，环就展开成一条**很深的链**：

```
x^(1)      x^(2)      x^(3)          x^(T)
  │          │          │              │
h^(0) → h^(1) → h^(2) → h^(3) → … → h^(T)
          │        │        │            │
        ŷ^(1)    ŷ^(2)    ŷ^(3)        ŷ^(T)
          │        │        │            │
        J^(1)    J^(2)    J^(3)        J^(T)
```

一旦展开，**K02 的规则原封不动适用**：

- $h^{(t)}$ 有**两条出边**：一条给输出 $\hat y^{(t)}$，一条给**下一个时刻** $h^{(t+1)}$；
- 所以 $h^{(t)}$ 收到的梯度是**两条路之和**——这正是 K02 §4.2 的"**分叉处相加**"，在这里变成"**每个时刻相加**"。

> **术语预告**：把 RNN 展开成这张链、再沿时间反传求梯度的算法叫 **BPTT（backpropagation through time）**。`03` §3 会让你亲眼看到它跑出来的数，`04` §2 给出完整推导。**这里只要记住：BPTT 不是新数学，就是 K02 的链式法则 + 这张展开图。**

## §7 一句话对比三种模型

| | n-gram（`01`） | 固定窗口神经 LM（§2） | RNN（§3–§5） |
|---|---|---|---|
| 表示 | 无（就是计数） | 稠密词向量（**固定窗口拼接**） | 稠密词向量 + **随时刻变化的隐藏状态** |
| 上下文长度 | $\le 5$ | 固定为窗口大小 | **任意长** |
| 稀疏问题 | 有（致命） | 无 | 无 |
| 存储/参数量 | 随语料/n 膨胀 | 随窗口膨胀 | **与序列长度无关** |
| 位置对称性 | — | **无**（每位置一套权重） | **有**（共用一组权重） |
| 代价 | — | 窗口太小、不对称 | **循环计算慢；长程信息难取**（`04` 展开） |

【slides】PAGE 25 把 RNN 的账算得很清楚：

> **Advantages:** 任意长度输入；理论上能用到很多步之前的信息；模型大小不随上下文增长；每个时刻用同一组权重，**处理有对称性**。
> **Disadvantages:** **循环计算慢**（不能并行）；**实践中很难取到很多步之前的信息**。

**最后那条劣势是本课的"下半场"**：它从哪来？为什么"理论上能用"变成"实践中用不到"？——`03` §4 实测、`04` §3 推导。
