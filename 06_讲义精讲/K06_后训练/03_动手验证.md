## §2 验证一：DPO 训练让 chosen 相对 rejected 的 log-prob 差上升

**断言**（`02` §8）：DPO 损失
$J_{\text{DPO}}=-\mathbb{E}\log\sigma\big(\beta[\log\frac{p_\theta(y_w)}{p_{\text{PT}}(y_w)}-\log\frac{p_\theta(y_l)}{p_{\text{PT}}(y_l)}]\big)$
会推着模型**抬高 chosen、压低 rejected**。

**你的预期**：一个"人类偏好与参考模型相反"的偏好对，训练后 `log p(w) − log p(l)` 应该变正还是变负？初始 loss 应该是多少？

**【实测】起手的玩具设置**（3 个 prompt × 4 条候选回答；chosen 取成参考模型**最不看好**的那条）：

```
偏好对 (chosen w, rejected l) = [(2, 0), (3, 1), (0, 2)]
初始 log p_ref(w) - log p_ref(l) = [-2.0, -1.6, -2.0]
β = 0.5  初始 DPO loss = 0.6931471805599453 （= ln 2，因 u=0）
初始 u（σ 的输入）= [0. 0. 0.]  → σ(u) = [0.5 0.5 0.5]
```

**训练轨迹**（Adam，300 步）：

```
step    loss      margin(logp_w-logp_l)   β·margin    KL(p||p_ref)
   0   0.693147   -1.866667                 -0.933333    0.000000
   1   0.644397   -1.666667                 -0.833333    0.002009
   5   0.475181   -0.872510                 -0.436255    0.053681
  20   0.150076   +1.774602                 +0.887301    0.742380
 100   0.015837   +6.408305                 +3.204153    2.136168
 300   0.003664   +9.348163                 +4.674081    2.444558
```

**对账**：

| 观察 | 值 | 说明 |
|------|-----|------|
| 初始 loss | $0.693147$ | $=\ln 2$；因初始 $u=0\Rightarrow\sigma(0)=0.5$ |
| margin | $-1.8667\to+9.3482$ | **符号翻转**：chosen 从"更不被看好"变成"被看好" |
| KL | $0\to2.4446$ | 策略**确实离开了参考模型** |

**这一屏意味着什么**：DPO 的损失就是 `02` §2 那条 $\sigma(\text{分数差})$ 的负对数——margin 为负时 loss 高、推着它变正；到 margin 很大后 loss 趋近 0（饱和）。**最终策略把 chosen 的概率推到 0.979（`p_θ` 输出），几乎完全照偏好对办事。**

> **可自查的一条恒等式**：$\beta\cdot\text{margin}$ 就是 DPO 损失里 $\sigma$ 的输入 $u$。表里第 0 行 $u=-0.933333$，正是 $\beta=0.5$ 乘初始 margin $-1.866667$。**loss $=\ln(1+e^{-u})=0.693147$**（$u=0$ 时）。

## §3 验证二：$\beta$ 与参考模型的作用

**断言**（`02` §6）：$\beta$ 是 KL 惩罚强度；**$\beta$ 越小，允许离参考模型越远**。

**你的预期**：$\beta=0.1$ 与 $\beta=2.0$ 相比，哪个训练后的 KL 更大？margin 呢？

**【实测】**（各训 300 步，其余设置相同）：

```
β       最终 margin    β·margin      KL(p_θ||p_ref)
0.1     +29.013748     +2.901375     2.580815
0.5     +9.348163      +4.674081     2.444558
2.0     +2.037774      +4.075548     0.840001
```

**对账**：$\beta$ 从 $2.0$ 降到 $0.1$，**margin 从 $+2.04$ 涨到 $+29.01$、KL 从 $0.840$ 涨到 $2.581$** —— 完全单调。✅

**这一屏意味着什么**：

- **$\beta$ 小 → 损失对 log-ratio 的"要求"更高**：$\sigma$ 的输入是 $\beta\cdot(\text{log-ratio 差})$，$\beta$ 小就得让 log-ratio 差更大才饱和，于是**策略漂得更远**（KL 更大）。
- **$\beta$ 大 → 策略被拴在参考模型附近**：$\beta=2.0$ 时 KL 只有 $0.840$。
- 这正对应 `02` §6：**$\beta$ 是"离参考模型远一分付一分钱"的单价**。

> ⚠️ **一个容易看错的点**：$\beta\cdot\text{margin}$ 那一列**不是单调的**（$2.90/4.67/4.08$）。它衡量"隐式奖励之差"（DPO 真正优化的量），而 margin 是"原始 log-prob 差"。**$\beta$ 控制的是"log-ratio 差 vs 漂移"的换算，不是让 $\beta\cdot\text{margin}$ 单调。** 判据看 **KL**，不看 $\beta\cdot\text{margin}$。

## §4 验证三：reward hacking —— 表面奖励升、真实目标崩

**断言**（`02` §6、`04` §2）：**只朝代理奖励优化会跑偏**——代理分数升，真实目标反而崩；KL 惩罚（对参考模型）能挡住。

**你的预期**：6 个动作，`proxy` 奖励偏爱 5 号（分数 1.0），但真实奖励的最优点在 3 号（0.9）、且 5 号的真实奖励是 0.0。**不设惩罚时，真实奖励会一路升、还是一条先升后崩的曲线？**

**【实测】** 玩具：策略就是 6 个 logits 的 softmax，梯度上升最大化 $\mathbb{E}_p[\text{proxy}]-\beta_{\text{KL}}\,\text{KL}(p\|\text{uniform})$。

```
r_proxy = [0.0, 0.2, 0.4, 0.6, 0.7, 1.0]  argmax = 5
r_true  = [0.1, 0.2, 0.3, 0.9, 0.75, 0.0]  argmax = 3
均匀分布下：proxy 期望 = 0.483333  真实期望 = 0.375
```

**[无 KL 惩罚]**：

```
 step   proxy奖励   真实奖励   KL(对均匀)
    0   0.483333   0.375000   0.000000
    1   0.539256   0.409541   0.019607
    2   0.590893   0.440560   0.073463
    3   0.635639   0.463122   0.148157
    5   0.708457   0.463269   0.309127
   10   0.856136   0.281004   0.766103
   20   0.989359   0.019825   1.637911
   50   0.999349   0.000996   1.778664
  400   0.999870   0.000170   1.788861
   真实奖励峰值 0.470972 @step 4；末值 0.000170
```

**[KL 惩罚 β=0.5]**：

```
 step   proxy奖励   真实奖励   KL(对均匀)
    0   0.483333   0.375000   0.000000
    2   0.588793   0.429351   0.065376
   10   0.743884   0.323071   0.337660
  100   0.688203   0.364295   0.198690
  400   0.688252   0.364215   0.198786
   真实奖励峰值 0.429351 @step 2；末值 0.364215
```

**[KL 惩罚 β=2.0]**：真实奖励峰值 $0.409541$ @step 1；末值 $0.383076$；末 KL $0.013502$。

**对账**：

| 设置 | proxy 末值 | 真实奖励峰值 | 真实奖励末值 | 末 KL |
|------|-----------|-------------|-------------|-------|
| 无 KL | $0.999870$ | $0.470972$ @step4 | $\mathbf{0.000170}$ | $1.788861$ |
| $\beta{=}0.5$ | $0.688252$ | $0.429351$ @step2 | $0.364215$ | $0.198786$ |
| $\beta{=}2.0$ | $0.537379$ | $0.409541$ @step1 | $0.383076$ | $0.013502$ |

**这一屏是整课的落点之一**：

> **无 KL 时是一条典型的"先升后崩"**：真实奖励从 $0.375$ 升到峰值 $0.471$（@step4），然后**崩到 $0.00017$**——因为策略把全部质量压到 5 号（proxy 满分、真实 $0.0$）。**代理分数却一路升到 $0.99987$。** 这就是 reward hacking 的字面含义：**你在优化一个"越优化越错"的代理。**
> **KL 惩罚把它按住了**：$\beta=0.5$ 时真实奖励稳定在 $0.364$（不再崩）；$\beta=2.0$ 时几乎不动（KL 仅 $0.0135$）。**惩罚越重，越不敢乱跑。**

> **对 RLHF 的直接意义**：`02` §6 的 $-\beta\log(p_\theta/p_{\text{PT}})$ **不是可有可无的正则**，它是让"代理奖励"和"真实目标"不脱钩的那根绳。**没有它，reward model 学得再准也会被优化坏。**

## §5 验证四：DPO 对 logits 的梯度 —— 手推 = autograd

**断言**（`02` §8、"只看奖励之差"）：**DPO 损失对 logits $\theta$ 的梯度，每行只有 chosen/rejected 两个位置非零**，且可以手推。

**你的预期**：若 loss 只依赖"两个 log-prob 之差"，那对**第三个**候选回答的 logit 求导，应该是多少？

**【实测】**（理论值也给出，见 `04` §6）：

```
autograd ∂loss/∂Z =
 [[ 0.083333  0.000000 -0.083333  0.000000]
  [ 0.000000  0.083333  0.000000 -0.083333]
  [-0.083333  0.000000  0.083333  0.000000]]
手推     ∂loss/∂Z = （同上）
max|autograd - 手推| = 0.0
```

**对账**：**逐位一致，差 $0.0$** ✅。

**这一屏意味着什么**：

- 每行只有 **chosen / rejected 两个位置非零**，其余为 0 —— 因为 $\partial\log p_\theta(y)/\partial\theta_j=\delta_{jy}-p_\theta(j)$，两个 log-prob 相减时**归一化项 $p_\theta(j)$ 全部抵消**，只剩 $\delta_{jw}-\delta_{jl}$。
- **$\theta_w$ 的梯度为负 → 梯度下降抬高它；$\theta_l$ 的梯度为正 → 压低它。** 正好"抬高 chosen、压低 rejected"，与 §2 实测的 margin 上升一致。
- 这里 **autograd 与手推差 $0.0$**（对比 K02 §6 是 $10^{-17}$ 量级），因为我们用的是 float64 + 解析式与 autograd 都对同一闭式表达式求导。

> **推导见 `04` §6**：$\dfrac{\partial \ell}{\partial \theta_j}=\beta(\sigma(u)-1)(\delta_{jw}-\delta_{jl})$。
