| 符号 | 含义 | 形状 / 说明 |

## §2 公式速查

**RLHF 目标**（带 KL 惩罚）：

$$\max_\theta\ \mathbb{E}_{\hat y\sim p_\theta}\Big[RM_\phi(x,\hat y)-\beta\log\frac{p_\theta(\hat y\mid x)}{p_{\text{PT}}(\hat y\mid x)}\Big]=\max_\theta\ \mathbb{E}_{p_\theta}[RM_\phi]-\beta\,\text{KL}(p_\theta\|p_{\text{PT}})$$

**闭式最优解**（`04` §3）：

$$p^*(y\mid x)=\frac{1}{Z(x)}p_{\text{PT}}(y\mid x)\exp\!\Big(\frac{1}{\beta}RM(x,y)\Big),\qquad Z(x)=\sum_y p_{\text{PT}}(y\mid x)e^{RM(x,y)/\beta}$$

**隐式奖励**（`04` §4）：

$$RM_\theta(x,y)=\beta\log\frac{p_\theta(y\mid x)}{p_{\text{PT}}(y\mid x)}+\beta\log Z(x)$$

**Bradley-Terry / reward model 损失**：

$$J_{RM}(\phi)=-\mathbb{E}_{(x,y_w,y_l)\sim D}\log\sigma\big(RM_\phi(x,y_w)-RM_\phi(x,y_l)\big)$$

**DPO 损失**（`04` §5）：

$$\boxed{J_{\text{DPO}}(\theta)=-\mathbb{E}_{(x,y_w,y_l)\sim D}\ \log\sigma\Big(\beta\log\frac{p_\theta(y_w\mid x)}{p_{\text{PT}}(y_w\mid x)}-\beta\log\frac{p_\theta(y_l\mid x)}{p_{\text{PT}}(y_l\mid x)}\Big)}$$

**DPO 对 logits 的梯度**（`04` §6，玩具 categorical）：

$$\frac{\partial\ell}{\partial\theta_j}=\beta\big(\sigma(u)-1\big)\big(\delta_{jw}-\delta_{jl}\big)$$

**REINFORCE 更新**（【slides】p29）：

$$\theta_{t+1}:=\theta_t+\alpha\,\frac{1}{m}\sum_{i=1}^m R(s_i)\,\nabla_\theta\log p_\theta(s_i)$$

**PPO clipped 目标**（【slides】p30）：

$$L^{\text{CLIP}}(\theta)=\mathbb{E}\big[\min(r_t(\theta)A,\ \text{clip}(r_t(\theta),1-\epsilon,1+\epsilon)A)\big],\quad r_t(\theta)=\frac{p_\theta}{p_\theta^{\text{old}}}$$

## §3 踩坑点

| # | 坑 | 怎么认出来 | 怎么修 |
|---|----|-----------|--------|
| 1 | **$\beta$ 调太小** | DPO 训练 margin 爆涨、KL 很大，输出塌成一句 | $\beta$ 是 KL 强度；`03` §3 实测 $\beta{=}0.1$ 的 KL $=2.58$、$\beta{=}2.0$ 只有 $0.84$。**调大 $\beta$** |
| 2 | **DPO loss 迅速到 0 就以为训好了** | loss $\to0$、但模型输出单一 | loss 到 0 只是偏好对**饱和**，不等于泛化好；配合**留出偏好集 / 人评**一起看 |
| 3 | **reward hacking** | 代理奖励一直涨、真实指标先升后崩 | `03` §4 实测：真实奖励峰值 $0.471$ 后崩到 $0.00017$。**加 KL 惩罚 / 早停 / 改进 reward model** |
| 4 | **reward model 被优化过头** | 优化后期 RM 分数涨、人评反降 | slides p51 的 reward model over-optimization；**在 RM 上留验证集、别过度优化** |
| 5 | **用绝对打分代替成对比较** | 标注员之间分数基线不一致 | slides p32：绝对分噪声大、标定差；**改成"哪个更好"** |
| 6 | **忘了参考模型/把它一起更新** | DPO 的 log-ratio 恒为 0、loss 不动 | $p_{\text{PT}}$ 必须**冻结**；只更新 $p_\theta$ |
| 7 | **以为 DPO 梯度"只有两个坐标非零"是普遍的** | 在真实 LM 上期望梯度稀疏 | 那是**玩具 categorical 模型**的性质（`04` §6.3）；真实 LM 上是**两条序列梯度的差**，不稀疏 |
| 8 | **以为 DPO 需要 $\log Z(x)$** | 纠结 $Z$ 怎么算 | DPO 里 $\log Z$ **相消**（`04` §5），不需要算它；需要单独给回答打分时才会碰到 $Z$ |
| 9 | **把"策略"当成别的东西** | 看到 $p_\theta$ 以为是另一个模型 | 这里的**策略就是 LM 本身**（`02` §1）；RL 术语而已 |
| 10 | **忽略标注者偏见** | 模型输出带有偏好数据的隐含倾向 | slides p60–p62：标注来自谁、偏见会渗进去；**审计偏好数据** |

3. 为什么偏好数据用**成对比较**而不是**绝对打分**？
4. Bradley-Terry 损失在要求什么？它只依赖奖励的什么？
5. RLHF 目标里的 KL 惩罚/参考模型在防什么？$\beta$ 是什么？
6. REINFORCE 为什么叫"强化"？PPO 在它基础上加了什么？
7. **reward hacking** 是什么？举一个"表面指标升、真实目标崩"的例子。
8. DPO 为什么**不需要 reward model**？它把 reward model "藏"到哪了？

### B. 公式（白纸）

11. **从 RLHF 目标推出闭式最优解** $p^*=\frac{1}{Z}p_{\text{PT}}e^{RM/\beta}$。
12. **反解出隐式奖励** $RM_\theta=\beta\log\frac{p_\theta}{p_{\text{PT}}}+\beta\log Z$。
13. 写出 DPO 损失，并说明 **$\log Z$ 为什么相消**。
14. **推导 DPO 损失对 logits 的梯度**，说明为什么只动 chosen/rejected 两个位置。**——本课最重要的一题**
15. 写出 REINFORCE 更新式与 PPO clipped 目标。

### C. 判断（给理由）

16. DPO 训练后，模型对**所有** prompt 都回同一句话。**先调什么？**
17. RLHF 训练中 reward 一路涨，但人工评估越来越差。**最可能是什么？**
18. reward model 在留出偏好上准确率 $50\%$（随机水平）。**先查什么？**
19. 偏好对里 chosen/rejected 被写反了一半。**DPO 训练会怎样？**
20. 有人问"DPO 里 $Z(x)$ 怎么估计"。**你该怎么回？**
21. 同一个模型，$\beta$ 从 $0.5$ 调到 $0.05$。**KL 会变大还是变小？**

### 答案要点

<details>
<summary>展开</summary>

1. SFT 让模型学会**照格式作答**（用 (instruction,output) 对微调，【slides】p12）。两个硬限制（【slides】p24）：① **开放式创作任务没有唯一正确答案**；② **语言建模对所有 token 级错误同等惩罚，但有些错更严重**。
2. 因为**人在回路里太贵**（【slides】p31）。解法是**把人类偏好建模成一个 NLP 问题**（Knox and Stone, 2009）：训 $RM_\phi$ 替代真标注。
3. 因为人的**绝对打分有噪声、标定不准**（同一摘要 4.1/6.6/3.2？【slides】p32）；**成对比较更可靠**（Phelps et al., 2015; Clark et al., 2018）。
4. 要求 $RM_\phi(s_w)>RM_\phi(s_l)$（**胜者得分高于败者**）；损失 $J_{RM}=-\mathbb{E}\log\sigma(RM_\phi(s_w)-RM_\phi(s_l))$。**只依赖奖励之差**（给所有奖励同加常数，损失不变）。
5. 防止策略为了讨好 $RM_\phi$ 而**跑离预训练模型太远**（reward hacking）。它在期望意义上就是 $\text{KL}(p_\theta^{\text{RL}}\|p_{\text{PT}})$；$\beta$ 是惩罚强度（【slides】p35）。
6. REINFORCE **把梯度移到期望里**（对数导数技巧），于是"奖励为正就抬高该样本概率、为负就压低"（【slides】p28–p29）——*reinforce good actions*。PPO 加了**限制每次更新幅度**的 clipping（ratio $r_t=p_\theta/p_\theta^{\text{old}}$，【slides】p30）。
7. 代理奖励被优化过头，**真实目标反而变差**（【slides】p49–p51）。`03` §4 实测：proxy 从 $0.483$ 升到 $0.99987$，真实奖励峰值 $0.471$ 后崩到 $0.00017$（策略全压到"proxy 满分、真实 0 分"的动作上）。
8. 因为 DPO **把 reward model 定义成了策略的函数**（`04` §4）：$RM_\theta=\beta\log(p_\theta/p_{\text{PT}})+\beta\log Z$。"reward model 没有消失，它被折叠进了 $p_\theta/p_{\text{PT}}$ 里。"（`04` §5）
9. $\max_\theta \mathbb{E}_{\hat y\sim p_\theta}[RM_\phi(x,\hat y)-\beta\log\frac{p_\theta(\hat y\mid x)}{p_{\text{PT}}(\hat y\mid x)}]$（【slides】p35/p54）。
10. $J_{RM}(\phi)=-\mathbb{E}_{(s_w,s_l)\sim D}\log\sigma(RM_\phi(s_w)-RM_\phi(s_l))$（【slides】p33）。
11. 见 `04` §3：对分布写拉格朗日、逐点求导 $\Rightarrow\log\frac{p}{p_{\text{PT}}}=\frac{RM+\lambda}{\beta}-1\Rightarrow p=\frac{1}{Z}p_{\text{PT}}e^{RM/\beta}$。
12. 见 `04` §4：对 $p^*$ 取对数后解出 $RM=\beta\log\frac{p^*}{p_{\text{PT}}}+\beta\log Z$；`02`/`04` 强调它**对任意 LM 都成立**。
13. $J_{\text{DPO}}=-\mathbb{E}\log\sigma(\beta\log\frac{p_\theta(y_w)}{p_{\text{PT}}(y_w)}-\beta\log\frac{p_\theta(y_l)}{p_{\text{PT}}(y_l)})$；差值里 $RM_\theta$ 的 $\beta\log Z(x)$ **两边相同、相减为零**（【slides】p55："Log Z term cancels"）。
14. 见 `04` §6：$\partial\ell/\partial u=\sigma(u)-1$，$\partial\log p_\theta(y)/\partial\theta_j=\delta_{jy}-p_\theta(j)$，两个 log-prob 相减时 $p_\theta(j)$ **相消** $\Rightarrow\partial\ell/\partial\theta_j=\beta(\sigma(u)-1)(\delta_{jw}-\delta_{jl})$。$j=w$ 为负（抬高）、$j=l$ 为正（压低）、其余为 0。`03` §5 实测的梯度值 $0.083333=\beta\times0.5/P$，与手推差 $0.0$。
15. REINFORCE：$\theta_{t+1}:=\theta_t+\alpha\frac{1}{m}\sum_i R(s_i)\nabla_\theta\log p_\theta(s_i)$。PPO：$L^{\text{CLIP}}=\mathbb{E}[\min(r_tA,\text{clip}(r_t,1-\epsilon,1+\epsilon)A)]$（【slides】p29–p30）。
16. **先把 $\beta$ 调大**（减弱漂移），或减小 lr/步数。全都回同一句话 = 策略漂太远、塌到极少数回答上（坑 1；`03` §3 的 $\beta{=}0.1$ 就是这种趋势）。
17. **reward hacking / reward model over-optimization**（【slides】p50–p51）：代理奖励被优化过头，真指标反降。加 KL 惩罚、早停、或改进 RM。
18. **先查偏好数据本身**：是不是标反了、噪声太大，或 RM 容量/训练不足（【slides】p34：先把 RM 验好再往下走）。$50\%$ = 没学到任何偏好。
19. 训练会**互相打架**：一半样本推着抬高 $w$、另一半推着抬高 $l$，净方向≈抵消，margin 学不动、loss 降不下来。**先检查标注一致性**（成对比较的可靠性依赖标注质量）。
20. **DPO 里 $Z(x)$ 不需要估计**——它在损失里相消了（`04` §5）。只有当你需要"给单个回答打绝对奖励"时，$Z$ 才会出现，那已不是 DPO 的优化路径。
21. **变大**。$\beta$ 是 KL 惩罚强度；$0.5\to0.05$ 是**减弱**惩罚 → 允许离参考模型更远 → KL 更大（`03` §3：$\beta$ 越小 KL 越大）。

</details>
