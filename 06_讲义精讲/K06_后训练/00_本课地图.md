## §3 知识清单

每条一句话结论 + 出处页码 + 标签。**扫一遍，看有没有哪条你讲不出来。**

### A. 为什么需要后训练（5 条）

1. 【slides】p8：**语言建模 ≠ 帮助用户**。预训练目标只让模型"预测下一个词"，与原话——它**不与用户意图对齐**（"Language models are not aligned with user intent", Ouyang et al., 2022）。
2. 【slides】p6：把这层落差画成一个问题：`Stanford University is located in ______` —— 续写模型可以接着编，而不是给出一个**听指令的问答**（"How do we get from this to this?"）。
3. 【slides】p10：预训练/微调范式的核心句——**预训练通过充当"参数初始化"来提升下游**（"Pretraining can improve NLP applications by serving as parameter initialization"）。第二步微调只改任务、数据少。
4. 【slides】p24：指令微调的两个**更隐蔽**的限制：① 开放式创作类任务**没有唯一正确答案**（写一个关于狗和蚱蜢的故事）；② 语言建模**对所有 token 级错误一视同仁地惩罚，但有些错比另一些更严重**。
5. 【slides】p24 的结论：即便做了指令微调，**LM 的目标函数与"满足人类偏好"这个目标之间仍有错位**——所以要**显式地**去优化人类偏好。

### B. 指令微调（SFT）（4 条）

6. 【slides】p12：**指令微调**的做法——**跨许多任务收集 (instruction, output) 对，用来微调一个 LM**（FLAN-T5; Chung et al., 2022）；然后在**没见过的任务**上评测。
7. 【slides】p13：**数据 + 模型规模是关键**（"data + model scale is key"）：Super-NaturalInstructions 含 **1.6K 任务、3M+ 例子**，覆盖分类、序列标注、改写、翻译、QA。
8. 【slides】p18：Flan-T5 = 在 T5 基础上**再微调 1.8K 个额外任务**；幻灯片标语 **"Bigger model = bigger Δ"**（模型越大，涨幅越大）。
9. 【slides】p22：**样本不必多**——Alpaca 用 **52K** 指令数据微调 LLaMA 7B；引用 *LIMA: Less Is More for Alignment*（Zhou et al., 2023）支持"少量高质量样本即可"。

### C. RLHF：优化人类偏好（5 条）

10. 【slides】p25：把问题写成**最大化期望奖励** $\mathbb{E}_{\hat s\sim p_\theta(s)}[R(\hat s)]$，其中人类奖励 $R(s)\in\mathbb{R}$（越高越好）；例：$s_1$ 的 $R=8.0$，$s_2$ 的 $R=1.2$。
11. 【slides】p27：最直接的想法是**梯度上升** $\theta_{t+1}:=\theta_t+\alpha\nabla_\theta\mathbb{E}_{\hat s\sim p_\theta}[R(\hat s)]$；但奖励**可能不可微**、且**期望怎么估计**是两个问题。
12. 【slides】p28–29：**策略梯度 / REINFORCE**（Williams, 1992）用**对数导数技巧** $\nabla_\theta\log p_\theta(s)=\frac{1}{p_\theta(s)}\nabla_\theta p_\theta(s)$ 把梯度移到期望里面，得到 $\theta_{t+1}:=\theta_t+\alpha\frac{1}{m}\sum_i R(s_i)\nabla_\theta\log p_\theta(s_i)$：**奖励为正就抬高该样本概率，为负就压低**——这就是"强化"的含义。
13. 【slides】p30：**PPO**（Schulman et al., 2017）的关键思想是**限制每次更新时策略能变多少**；clipped 目标 $L^{\text{CLIP}}(\theta)=\mathbb{E}[\min(r_t(\theta)A,\ \text{clip}(r_t(\theta),1-\epsilon,1+\epsilon)A)]$，$r_t(\theta)=p_\theta/p_\theta^{\text{old}}$ 是概率比，$A$ 是优势，clip 范围如 0.2。它被提出来治 vanilla REINFORCE 的**高方差、不稳定、样本效率低**。
14. 【slides】p35 + p37：RLHF 完整可实现，是因为凑齐三件：一个预训练（可能已指令微调）的 $p_{\text{PT}}$、一个在人类比较数据上训好的 reward model $RM_\phi$、一个"朝任意奖励优化 LM"的方法（PPO）；实验上**RLHF 比"预训练+微调"更好**（$p_{\text{PT}}\to p_{\text{IFT}}\to p_{\text{RL}}$，Stiennon et al., 2020）。

### D. Reward model 与偏好数据（4 条）

15. 【slides】p31：**问题 1：人在回路里太贵**。解法——**把人类偏好建模成一个独立的 NLP 问题**（Knox and Stone, 2009）：训一个 $RM_\phi(s)$ 去预测人类偏好，再对 $RM_\phi$ 优化。
16. 【slides】p32：**问题 2：人的打分有噪声、标定不准**（同一个摘要到底是 4.1 分、6.6 分还是 3.2 分？）。解法——**改用成对比较**（pairwise comparison），比直接打分更可靠（Phelps et al., 2015; Clark et al., 2018）。
17. 【slides】p33：reward model 用 **Bradley-Terry 成对比较模型**（1952）训练：$J_{RM}(\phi)=-\mathbb{E}_{(s_w,s_l)\sim D}\log\sigma\big(RM_\phi(s_w)-RM_\phi(s_l)\big)$，$s_w$ 是"胜者"、$s_l$ 是"败者"，要求**胜者得分高于败者**。
18. 【slides】p34：**先把 reward model 验证好再往下走**——在留出的人类判断上评估 RM 的预测能力（Stiennon et al., 2020）；足够大的 RM 在足够数据上能逼近单个人类的水平。

### E. RLHF 的 KL 惩罚（2 条）

19. 【slides】p35：RLHF 实际优化的奖励是 $R(s)=RM_\phi(s)-\beta\log\dfrac{p_\theta^{\text{RL}}(s)}{p_{\text{PT}}(s)}$。第二项是一个**惩罚**：当 RL 策略给出的概率**超过**预训练模型时**付费**，防止跑离预训练模型太远；它在期望意义上就是 $p_\theta^{\text{RL}}$ 与 $p_{\text{PT}}$ 之间的 **KL 散度**。
20. 【slides】p36：RLHF 流水线的高层视角——**第一步先做指令微调**，第二、三步才是"最大化奖励"。

### F. RL + reward modeling 的限制（3 条）

21. 【slides】p49–p50：**人类偏好不可靠**；**reward hacking 是 RL 里的常见问题**——聊天机器人被奖励去产出"看起来权威、有帮助"的回答（不管真假），于是可能**编造事实、出现幻觉**。
22. 【slides】p51：**对人类偏好的建模比人本身更不可靠**——存在 **reward model over-optimization**（把代理奖励优化过头，真指标反而掉，Stiennon et al., 2020）。
23. 【slides】p53：**RL（PPO）本身很复杂**——要拟合 value function、在线采样慢、对超参敏感（Zheng et al., 2023; Shao et al., 2024）。

### G. DPO：把"RL"从 RLHF 里拿掉（5 条）

24. 【slides】p54：RLHF 的那个目标有**闭式最优解** $p^*(\hat y\mid x)=\frac{1}{Z(x)}p_{\text{PT}}(\hat y\mid x)\exp\big(\frac{1}{\beta}RM(x,\hat y)\big)$；反解出**用最优策略隐式表示奖励** $RM_\theta(x,\hat y)=\beta\log\dfrac{p_\theta^{\text{RL}}(\hat y\mid x)}{p_{\text{PT}}(\hat y\mid x)}+\beta\log Z(x)$。
25. 【slides】p55：把上面这个隐式奖励代回 Bradley-Terry 损失，得**DPO 损失** $J_{\text{DPO}}(\theta)=-\mathbb{E}_{(x,y_w,y_l)\sim D}\log\sigma\big(RM_\theta(x,y_w)-RM_\theta(x,y_l)\big)$；关键是 **$\log Z$ 项相消**，因为损失只关心**奖励之差**。来源 Rafailov et al., 2023。
26. 【slides】p55：展开后 $J_{\text{DPO}}=-\mathbb{E}\log\sigma\big(\beta\log\frac{p_\theta(y_w\mid x)}{p_{\text{PT}}(y_w\mid x)}-\beta\log\frac{p_\theta(y_l\mid x)}{p_{\text{PT}}(y_l\mid x)}\big)$ —— **直接在偏好对上优化，不需要单独的 reward model，也不需要 RL 循环**。
27. 【slides】p56：DPO **超过了此前的做法**——"你可以用一个非常简单的**加权 MLE 目标**替换掉复杂的 RL 部分"；后续变体 KTO、IPO 正在出现。
28. 【slides】p57：**开源 RLHF 现在大多"不是 RL"**——开源 LLM 现在几乎都直接用 DPO（"and it works well!"）。

### H. 数据来源、后续与边界（4 条）

29. 【slides】p60–p61：**RLHF 的标注常来自海外低薪工人**；要**警惕标注者偏见渗进 LM**（Santurkar et al., 2023, OpinionQA）。
30. 【slides】p62：**偏好微调可能带来非预期影响**——例：问"你来自哪个国家"，模型答"I am from {country}"（Starling 7B reward model, Ryan et al., 2024）；偏好数据里的隐含倾向会被学进去。
31. 【slides】p58：**GRPO**（Shao et al., 2024）是"改进 RLHF 里的 RL"的一条路线（DeepSeekMath）。
32. 【slides】p63：**下一步**——RLHF 仍是数据昂贵的开放领域；近期工作想降低数据需求：**RL from AI feedback**（Bai et al., 2022，即 RLAIF）、**在模型自己的输出上微调**（Huang et al., 2022; Zelikman et al., 2022）；但大模型的一些限制（体积、幻觉）**可能不是 RLHF 能解决的**。

## §5 术语索引

按首次出现的篇排。`01` 篇零前置，`02` 篇是本知识点核心概念，`04` 篇才需要推导背景。

| 术语 | 一句话解释 | 出处 |
|------|-----------|------|
| **对齐（alignment）** | 让模型行为符合用户/人类意图，而不只是会续写 | `01` §1 |
| **预训练 / 微调范式** | 先在大规模文本上预训练（当参数初始化），再在任务上微调 | `01` §1 |
| **指令微调 / SFT** | 用 (instruction, output) 对微调 LM，让它学会"听指令" | `01` §2 |
| **开放式生成** | 没有唯一正确答案的任务（写故事/写摘要） | `01` §3 |
| **人类偏好** | 人对两个输出"哪个更好"的判断，本课用成对比较获取 | `02` §3 |
| **奖励 $R(s)$** | 给一个输出打的分，越高越好 | `02` §3 |
| **策略（policy）$p_\theta$** | 这里的"策略"就是 LM 本身：给定 prompt 的答案分布 | `02` §2 |
| **参考模型 $p_{\text{PT}}$** | 冻结的预训练/SFT 模型，KL 惩罚的锚 | `02` §2 |
| **reward model $RM_\phi$** | 学人类偏好、给输出打标量的模型 | `02` §4 |
| **策略梯度 / REINFORCE** | 用采样估计 $\nabla\mathbb{E}[R]$ 的 RL 方法 | `02` §5 |
| **PPO** | 带"限制更新幅度"的 clipped 策略梯度算法 | `02` §5 |
| **KL 散度 / KL 惩罚** | 两个分布差异的度量；这里防止策略跑离参考模型 | `02` §6（直觉）、`04` §2（公式） |
| **$\beta$** | KL 惩罚强度（也是 DPO 里 log-ratio 的系数） | `02` §6 |
| **成对比较（chosen / rejected）** | 只给"谁更好"，不给绝对分 | `02` §4 |
| **Bradley-Terry 模型** | 把成对胜负写成 $\sigma$ 差的经典概率模型 | `02` §4 |
| **reward hacking** | 代理奖励被优化过头，真实目标反而变差 | `02` §7 |
| **DPO** | 直接在偏好对上优化、隐式表示奖励、去掉 RL 循环 | `02` §8 |
| **隐式奖励 $RM_\theta$** | 用策略与参考模型的 log-ratio 表示出的奖励 | `02` §8、`04` §4 |
| **$\log Z(x)$ 项** | 配分函数的对数，DPO 里因只比差值而相消 | `04` §5 |
| **RLAIF** | 用 AI 反馈代替人类反馈做偏好 | `02` §7 |
| **GRPO** | 对 RLHF 中 RL 部分的改进（组相对策略优化） | `05` §1 |

## §7 下一课预告：K07 PEFT 与 LoRA

会复用本课的东西：**"在后训练里，改的是 LM 的参数"这个视角完全一样**——SFT 微调全参、RLHF 更新 $\theta$、DPO 更新 $\theta$，目标都是让 $p_\theta$ 靠近某个偏好。
