§1 参数量：全参微调 vs LoRA（以 Transformer 里一个方阵为例）
================================================================
一个 4096×4096 的权重矩阵 W0：
  全参微调可训练参数 = d·k = 16,777,216

   秩 r      LoRA 可训练 2·d·r         占全参比例
     1               8,192    0.048828%
     2              16,384    0.097656%
     4              32,768    0.195312%
     8              65,536    0.390625%
    16             131,072    0.781250%
    64             524,288    3.125000%

实测：LoRA(r=8) 包装 4096×4096 Linear
  总参数 = 16,846,848，可训练 = 65,536（占 0.389010%）
  即把可训练量从 16,777,216 降到 65,536，少 256 倍。

每任务存一份的成本（算术）：
  全参副本：GPT-3 175B 参数 × 2 字节(fp16) ≈ 350 GB
  一个 4096 矩阵的 LoRA(r=8)：65,536 参数 × 2 字节 ≈ 128.0 KB

§2 低秩拟合：目标 ΔW 是低秩时，LoRA 秩够就拟合、秩不够就欠拟合
================================================================
构造：W0 随机；目标更新 ΔW = B_true·A_true，真实秩 r_true = 4
样本：X (256, 64)，Y = X·W_targetᵀ

方法                                       可训练参数        相对误差 ‖W_eff−W_target‖/‖ΔW‖
LoRA r=8（≥ r_true）                     1,024                        0.000834
LoRA r=2（< r_true）                       256                        0.507081
全参微调（训整个 W）                            4,096                        0.000244
→ 目标 ΔW 秩为 4：LoRA r=8 误差趋近 0，r=2 无法表示、留下明显残差；
  全参微调当然也能拟合，但可训参数多得多。

================================================================
§3 秩 r 的作用：可训练参数线性增长，误差在 r ≥ r_true 后趋 0
================================================================
目标 ΔW 的真实秩 r_true = 4

   秩 r        可训练参数 2·r·64          相对误差
     1                 128      0.733148
     2                 256      0.507081
     4                 512      0.000064
     8               1,024      0.000834
    16               2,048      0.000006
    32               4,096      0.000373
→ r 从 1 增到 2、再到 4：误差在 r = r_true = 4 处塌到 ~0（够表示了）；
  r 再往上加只是浪费参数（这里 r=8/16/32 的误差都已触及训练下限）。

================================================================
§4 初始化：B 初始化为 0 ⇒ 训练起点就是预训练模型
================================================================
B=0 时，LoRA 前向 = 预训练前向，max|差| = 0.000e+00
对照：B 随机非零时，与预训练前向 max|差| = 1.672e-02
→ B=0 保证 ΔW=BA=0：训练从「预训练模型」出发，一上来不会破坏已有能力；
  若 A、B 都随机非零，起点就会给权重叠加一个随机扰动。

梯度视角（训练前 B=0）：‖∂L/∂A‖_F = 0.000000e+00，‖∂L/∂B‖_F = 4.150881e-01
→ B=0 时 A 的第一步梯度为 0，只有 B 先更新；B 一旦非零，A 才开始收到梯度。

================================================================
§5 merge：W0 + (α/r)·BA 合并后输出不变，可精确回退
================================================================
LoRA 前向 vs 合并后前向：max|差| = 1.421e-14
→ 合并只是把 (α/r)·BA 加进 W0，是恒等变形，差异只有浮点舍入。
回退：W_merged − (α/r)·BA = W0 ?  max|差| = 5.551e-17
→ 推理时无额外延迟；换任务就把这份 BA 减掉、换上另一份 B'A'（slides p49）。

================================================================
§6 缩放 α/r：ΔW 的有效尺度 = (α/r) 乘 BA
================================================================
固定 r=8，BA 的 Frobenius 范数 = 1.944751

    α     α/r    ‖(α/r)·BA‖_F
    8    1.00        1.944751
   16    2.00        3.889502
   32    4.00        7.779003
→ 保持 r、增大 α，等价于把同一份更新的强度按 (α/r) 线性放大。
  slides p48 把 α 说成预训练知识与任务知识的权衡；工程上常按 α/r 缩放。
