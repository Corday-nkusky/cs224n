## §1 参数与形状卡

| 符号 | 含义 | 形状 / 典型取值 |
|------|------|----------------|
| $W_0$ | 预训练权重（**冻结**） | $d\times k$；**实测**的例子 $4096\times4096$ |
| $x$ | 层输入 | $(k,)$ |
| $h$ | 层输出 | $(d,)$ |
| $A$ | LoRA 左/下矩阵（可训练） | $r\times k$ |
| $B$ | LoRA 右/上矩阵（可训练） | $d\times r$ |
| $r$ | 秩 | 常用 **4 / 8 / 16**；[slides] p54 提到 RL 里 **低到 1** |
| $\alpha$ | 缩放 | 常用取 $r$ 的倍数（如 $2r$）；本 demo $r=8$ 时用 $\alpha=16$ |
| $s=\alpha/r$ | 有效缩放 | hu2021 口径；demo §5 用 $s=2$ |
| $\Delta W=BA$ | 权重增量 | $d\times k$，**秩 $\le r$** |
| **LoRA 可训练参数** | $2dr$（方阵） | $d=4096,r=8$ → **65,536**，占 $W_0$ 的 **0.390625%** |
| **全参可训练参数** | $dk$ | $4096\times4096$ → **16,777,216** |
| **存储（算术）** | 参数量 × 2 字节(fp16) | GPT-3 全量 ≈ **350 GB**；单矩阵 LoRA($r=8$) ≈ **128 KB** |
| adapter 瓶颈 | $W_D\in\mathbb{R}^{k\times d}$、$W_U\in\mathbb{R}^{d\times k}$ | 中间夹非线性 |
| merge 权重 | $W_0+s\,BA$ | $d\times k$，推理只用它 |

**形状自查口诀**（`02` §4、`04` §0）：

| 对象 | 规则 |
|------|------|
| $\Delta W=BA$ | $B(d\times r)\cdot A(r\times k)\Rightarrow d\times k$，**中间维度 $r$ 必须最小** |
| 前向 $h$ | $W_0x+\frac{\alpha}{r}BAx$；$BAx$ 是 $d$ 维 |
| $\partial L/\partial B$ | $(d\times r)$，**与 $B$ 同形** |
| $\partial L/\partial A$ | $(r\times k)$，**与 $A$ 同形** |
| $r$ 与 $d,k$ | $r\ll\min(d,k)$；**$r>d$ 或 $r>k$ 没有意义**（还更费参数） |

## §2 公式速查

**低秩增量**（【slides】p48 用 $\alpha BA$；【论文】用 $\frac{\alpha}{r}BA$）：

$$W_0+\Delta W=W_0+\alpha BA,\qquad B\in\mathbb{R}^{d\times r},\ A\in\mathbb{R}^{r\times k},\ r\ll\min(d,k)$$

**前向**：

$$z=Ax,\qquad h=W_0x+\frac{\alpha}{r}Bz=(W_0+\tfrac{\alpha}{r}BA)\,x$$

**参数量**（方阵）：$|A|+|B|=2dr$，占 $W_0$ 的 $\dfrac{2r}{d}$。

**两个梯度**（$\delta=\partial L/\partial h$，$s=\alpha/r$）：

$$\frac{\partial L}{\partial B}=s\,\delta\,(Ax)^{\mathsf T}\ (d\times r),\qquad \frac{\partial L}{\partial A}=s\,(B^{\mathsf T}\delta)\,x^{\mathsf T}\ (r\times k)$$

**$B=0$ 初始化**：$BA=0\Rightarrow h=W_0x$（起点 = 原模型），且 $\partial L/\partial A=0$、$\partial L/\partial B\neq0$。

**秩 $r$ 的表达上限（Eckart–Young）**：

$$\min_{\text{rank}\le r}\|\Delta W^\star-\hat W\|_F=\sqrt{\sum_{i>r}\sigma_i^2}$$

**merge（恒等，分配律）**：

$$W_{\text{merged}}=W_0+\frac{\alpha}{r}BA\ \Longrightarrow\ h=W_{\text{merged}}x$$

**全参微调目标**（对照，【slides】p45）：

$$\max_{\phi}\sum_{(x,y)}\sum_{t=1}^{|y|}\log P_\phi(y_t\mid x,y_{<t})$$

## §3 踩坑点

| # | 坑 | 怎么认出来 | 怎么修 |
|---|----|-----------|--------|
| 1 | **$B$ 忘了设为可训练** | loss 完全不降；`A.grad` 恒为 0 | $B$ 初始为 0，但**必须 `requires_grad=True`**——0 只是初值，不是"冻住"（`04` §4.3） |
| 2 | **$A,B$ 形状搞反** | $B(d\times r)$、$A(r\times k)$ 混成 $A(r\times d)$ | 记住"$B$ 在右乘 $W_0$ 的**输出**侧、$A$ 在**输入**侧"；$\Delta W=BA$ 的中间维度是 $r$ |
| 3 | **$r>\min(d,k)$** | 参数反而比全参多、还训不动 | $r$ 必须远小于 $\min(d,k)$（`02` §5.1） |
| 4 | **缩放没对齐** | 换了 $r$、效果忽好忽坏 | 用论文口径 $s=\alpha/r$，或同步调 $\alpha$ 稳住强度（`04` §5） |
| 5 | **merge 后忘了回退/换任务** | 换了任务效果还是上一个 | merge 是"$W_0$ 加一份 $BA$"；换任务要**减旧加新**（`03` §6） |
| 6 | **以为 $B=0$ 起点"随机"** | 担心一上来破坏预训练能力 | $BA=0$，起点**逐位等于原模型**（实测差 0.0，`03` §5） |
| 7 | **指望 LoRA 注入新知识** | 让它记私有事实，怎么调都上不去 | 这是**容量上限**（`01` §5、`04` §3）；该走检索/外部知识（K08） |
| 8 | **把 $r$ 开很大当"更强"** | 参数暴涨、收益停在噪声里 | 跨过任务内在秩后加 $r$ 只浪费（实测 $r\ge4$ 后误差已在 $10^{-4}$ 抖动，`03` §4） |
| 9 | **拿 LoRA 的 $\Delta W$ 当"全参"用** | 假设它无约束 | LoRA 解被限制在**秩 $\le r$** 的子空间（`04` §6.2） |
| 10 | **adapter 指望"推理免费"** | 部署发现多了一层延迟 | adapter 有**非线性**，不能像 LoRA 那样完整折叠（`04` §9、`02` §8） |

### 答案要点

<details>
<summary>展开</summary>

1. 四毛病（【slides】p34）：**低效**（每次预测都重算提示）、**效果差**（不如微调）、**对措辞/顺序敏感**、**说不清学到什么**。**最致命的是第四条**——连**随机标签都能 work**，说明模型抓到的往往不是你要教的规律，**没法保证它真学会了任务**。
2. ① **显存**：参数+梯度+优化器状态一起爆；② **存储**：每任务一份与全量等大的权重（$|\Delta\phi|=|\phi_0|$，GPT-3 175B → fp16 ≈ 350 GB）；③ **部署**：换任务要换整机，成本随任务数线性上涨（`01` §3）。
3. 冗余越大，"只改一点点就够"的空间越大。类比：**大工程支持"改几个开关/加个小插件"就换新功能**，而不必重编译（`01` §4）。
4. **参数视角**（剪枝 / 低秩组合=LoRA）、**输入视角**（prefix-tuning / prompt-tuning）、**函数视角**（adapter）（【slides】p38–40、p55–61）。
5. 掩码 $\mathbf b\in\{0,1\}^{|\theta|}$ 逐连接决定留删（【slides】p40）；彩票假说：稠密随机网里含"中奖子网"，单训即达相当精度（p43）。麻烦：**子网结构不规则、因任务而异，不好共享/部署**（`02` §3.3）。
6. 只训 $A$（$r\times k$）与 $B$（$d\times r$）；$W_0$ **冻结**（【slides】p48）。
7. $r$：**表达力上限 + 参数量（线性）**；$\alpha$：**改动强度**（slides 说是"预训练知识与任务知识的权衡"）（`02` §5.1–§5.2）。
8. $B=0\Rightarrow BA=0$，起点前向**逐位等于原模型**（实测差 **0.000e+00**）；顺带 $\partial L/\partial A=0$，第一步只更新 $B$（`03` §5、`04` §4.3）。
9. merge 成 $W_0+\frac{\alpha}{r}BA$，前向只剩一次普通矩阵乘（**恒等变形**，实测差 1.4e-14）；换任务**减旧 $BA$、加新 $B'A'$**（【slides】p49、`04` §7）。
10. prefix/prompt tuning **改输入**（可学习虚拟 token，冻结模型）；adapter **加函数**（层间瓶颈 $W_U\sigma(W_Dx)$）。短板：prompt tuning **容量有限、弱**；adapter **性能好但参数更多、有推理延迟**（【slides】p56–p66）。
11. **改不动"知识"**——容量有限，擅长改风格/格式，不擅长注入新事实。**和低数据适配的关系**：低数据时它比全参更稳（要学的参数少、不易过拟合），但**任务若要求新知识，仍会撞容量墙**（`01` §5）。**该走检索（K08）**。
12. $W_0+\Delta W=W_0+\alpha BA$，$B\in\mathbb{R}^{d\times r}$、$A\in\mathbb{R}^{r\times k}$；$r\ll\min(d,k)$ 表示中间维度远小于两侧，于是参数量 $2dr\ll dk$（`02` §4.2）。
13. $2\times4096\times8=65,536$；占 $65536/16777216=\mathbf{0.390625\%}$（少 256 倍）（`03` §2）。
14. $h=W_0x+\frac{\alpha}{r}BAx$；merge 后 $W_{\text{merged}}=W_0+\frac{\alpha}{r}BA$（`02` §5.5、`04` §7）。
15. $\partial L/\partial B=s\,\delta(Ax)^{\mathsf T}$；$\partial L/\partial A=s(B^{\mathsf T}\delta)x^{\mathsf T}$。$B=0\Rightarrow\partial L/\partial A=s(0)x^{\mathsf T}=0$（`04` §4）。
16. $\min\|\Delta W^\star-\hat W\|_F=\sqrt{\sum_{i>r}\sigma_i^2}$。**它说明 $r$ 是硬上限**：目标需要的秩超过 $r$，残差无法消除——`03` §3 的 $r=2$ 误差 0.507 即此（`04` §3）。
17. $f_\phi(x)=W_U\,\sigma(W_D x)$（【slides】p60）。
18. **先怀疑 $B$ 有没有真的在训**：$B$ 初值为 0，但必须 `requires_grad=True`；若漏了，$B$ 永远 0，$\Delta W=0$、$A$ 也因 $\partial L/\partial A\propto B$ 而收不到梯度（坑 1、`04` §4.3）。
19. **不是 bug，是容量上限**。目标真实秩 4 > $r=2$，**数学上无法表示**（Eckart–Young），误差有下界（理论 ~0.707，实测 0.507）。要降误差得**把 $r$ 提到 ≥4**（`03` §3–§4）。
20. 目标的内在秩早就跨过了（≥4），$r\ge4$ 后误差已在训练下限附近抖动；**再加 $r$ 只涨参数量**，不涨表达力（`03` §4）。
21. **查 merge / 适配器有没有真的换掉**：换任务要"减旧 $BA$、加新 $B'A'$"；若沿用旧适配器或忘了回退，结果当然和上一任务一样（坑 5、`03` §6）。
22. **PEFT 装不下新知识**。LoRA 只能改"怎么用已有知识"，注入私有事实该走**检索增强/外部知识库（K08 RAG）**（`01` §5）。
23. **对**：$r\ge\operatorname{rank}(\Delta W^\star)$ 时 LoRA 能精确表示改变量，可达解与全参重合（【slides】p49，`03` §3 实测 $r\ge4$ 误差→0）。**错**：LoRA 解被**限制在秩 $\le r$ 的子空间**，真实任务若需要高秩改变，LoRA 就受限——**"等价"是条件等价，不是无条件**（`04` §6）。

</details>
