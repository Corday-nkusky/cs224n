## §1 参数与形状卡

| 符号 | 含义 | 典型取值 / 本课实跑 |
|------|------|-------------------|
| $N$ | 文档（或块）总数 | 真实：10⁴–2×10⁷（英文维基 ~21M，slides p19）；本课 toy：**12**（短文档）/ **24**（1 句块） |
| $|V|$ | 词表大小（稀疏向量维度） | 本课 toy：**150** |
| $\text{avgdl}$ | 平均文档长度（token） | 本课 toy：**14.4167** |
| $K$ | 检索器挑几篇 | slides p15：**100**（预先定）；**喂给生成器的建议更小**（10–20 篇即饱和，slides p24） |
| $k_1$ | BM25 的 TF 饱和系数 | 常取 **1.2–2**；本课 demo **1.5** |
| $b$ | BM25 的长度归一系数 | **0.75**（部分归一）；$b=0$ 不归一、$b=1$ 全归一 |
| chunk 句数 | 每块多少句 | 本课扫描 **1/2/3/6** |
| overlap | 相邻块重叠句数 | 本课扫描 **0/1/2** |
| top-$k$（评测） | 看前几个结果算命中 | 本课 **k=1 和 k=3** |
| rerank 的 $N\to K$ | 粗筛候选数 → 精排保留数 | 形式：$N\gg K$（如 100→5） |
| $d_{\text{emb}}$ | 稠密向量维度 | 真实：数百（BERT 768）；本课 LSA **K=4**、语义嵌入 **2**（便于看簇） |
| 余弦 / 点积 | 相似度 | 见 §2 |

**形状自查口诀**：

| 对象 | 规则 |
|------|------|
| 稀疏文档向量 | 与词表同长（$|V|$），**绝大多数是 0** |
| 稠密文档向量 | 固定短长度 $d_{\text{emb}}$，**每维都非 0** |
| 检索输出 | **一个排序**（下标列表），不是答案 |
| 归一化后 | 点积 = 余弦（$\lVert u\rVert=\lVert v\rVert=1$） |

## §2 公式速查

**BM25（稀疏检索的核心）**：

$$
\text{BM25}(Q,d)=\sum_{t\in Q}\text{IDF}(t)\cdot\frac{f(t,d)\,(k_1+1)}{f(t,d)+k_1\big(1-b+b\,\frac{|d|}{\text{avgdl}}\big)}
$$

**IDF（平滑，恒正）**：$\text{IDF}(t)=\ln\!\big(1+\frac{N-\text{df}(t)+0.5}{\text{df}(t)+0.5}\big)$；**经典形式** $\ln\frac{N}{\text{df}(t)}$。

**TF 饱和项**（$L=1$ 时）：$B(f)=\dfrac{f(k_1+1)}{f+k_1}$，**上界 $k_1+1$**（$k_1=1.5$ 时上界 2.5）。

**TF-IDF**：$\sum_{t\in Q}f(t,d)\cdot\ln\frac{N}{\text{df}(t)}$（= BM25 的简化版，无饱和、无长度归一）。

**点积 / 余弦**：

$$u^\mathsf{T}v \qquad\text{vs}\qquad \cos(u,v)=\frac{u^\mathsf{T}v}{\lVert u\rVert\lVert v\rVert}$$

**RAG 两段式**：$f(\mathcal D,Q)\to\{P_1..P_K\}$；$g(Q,\{P_i\})\to A$。

**ReAct 一步**：

$$
\text{thought}_t\sim\text{LLM}(s_t)\;\to\;a_t=\text{parse}(\text{thought}_t)\;\to\;o_t=\text{env}(a_t)
$$

**Self-Consistency**：$a^\*=\arg\max_a\sum_{\text{path}}\mathbb 1[\text{ans}(\text{path})=a]$。

**Toolformer 保留判据**：保留 API 调用 $c\iff$ 它**降低后续 token 损失**。

**误差归因**：oracle（喂金标）也错 → 生成问题；oracle 好而 RAG 差 → 检索问题。

## §3 踩坑点

| # | 坑 | 怎么认出来 | 怎么修 |
|---|----|-----------|--------|
| 1 | **稀疏检索对"换词"失手** | 用户查询与文档用词不同，BM25 打 0 分 / 返回空 | 加**稠密检索**或**混合**（`03` §3：`tall/peak` 查询 BM25=−1） |
| 2 | **以为"稠密总比稀疏好"** | 专名/编号/代码被"相近但不同"的文档挤掉 | **别替代，要混合**：稀疏保精确匹配（`04` §4.3） |
| 3 | **一次喂太多文档** | 加文档到一定数量后效果**不涨反降/饱和** | 只喂 **10–20 篇以内**；务必 **rerank** 精排（`03` §4、`02` §5.1） |
| 4 | **分块太小** | 命中率低；检索到的块"只有半句话" | 加大 chunk 句数（`03` §4：1 句块 hit@1 仅 0/4） |
| 5 | **分块太大** | 命中了，但每块带一堆无关内容、上下文爆长 | 减小块或加 rerank（`03` §4：6 句块 top-3 token 达 88.8，是 1 句块的 5.6 倍） |
| 6 | **重叠给太多** | 结果里全是近重复块，正确块被挤出 top-k | 控制重叠（`03` §4：3 句+重叠 2，hit@3 掉到 3/4） |
| 7 | **"检索到了"当成"检索对了"** | 检索分很高但答案仍错 | 看端到端，不只看打分（`03` §5 第 8 题：检索分 8.23 最高，答案却不在里面） |
| 8 | **字面撞车噪声**（停用词/多义词） | 无关文档只因撞了一个常见词就排前 | 停用词表、词干化、rerank（`03` §2：doc8 因 "use" 排到第 2） |
| 9 | **把模型的"引用"当证据** | 引用看起来很权威，但对不上来源 | 记住**引用也是模型生成的、会幻觉**（`02` §6 模式④，slides p27–28） |
| 10 | **无检索时硬答** | 参数里没有的事实被编出来 | 走检索；或训练"不知道就说不知道" |
| 11 | **只评内在指标就收工** | recall@k 漂亮，端到端仍差 | 内外分层；做 oracle 对照定位（`04` §9） |
| 12 | **Agent 循环没有终止条件** | 反复做同一个动作、停不下来 | 动作空间里必须含终止动作，且要有步数上限（`04` §6.1） |
| 13 | **把纯 CoT 当 Agent** | "想了半天"但没和世界交互、幻觉重 | CoT 无 $o_t$，不是 Agent；要用 ReAct 把**观察**接回来（`04` §6.2） |
| 14 | **有/无检索的对照没做** | 说不清错在检索还是生成 | 跑 oracle 对照（`04` §9） |

### 答案要点

<details>
<summary>展开</summary>

1. ① **知识有截止时间**（训练快照之后的事没有）；② **装不下私有/实时知识**（不该进公共训练语料）；③ **装不下时还硬编**（幻觉）。**第②样是重训也进不了的**——私有知识本就不该进公共训练集（`01` §2–§4）。
2. 检索器 $f(\mathcal D,Q)\to\{P_i\}$，生成器 $g(Q,\{P_i\})\to A$。**解耦的便宜**：换生成器不动检索器、反之亦然；更关键的是——**知识在检索器那边的文档里，不在生成器参数里**，所以"更新知识 = 改文档"（`02` §1.1）。
3. 稀疏靠**字面重叠 + 词稀罕度**（BM25/TF-IDF）；稠密靠**向量方向（学出来的语义）**。稀疏强在**精确匹配**（专名/数字/代码），稠密强在**换词/改写**。（`02` §3.3、`04` §4.3）
4. 因为 LM **无法把注意力公平分给长上下文**，而且候选里混入无关文档会拖累。slides 的两个数：**闭卷 ~56% vs 只喂相关文档（oracle）~88.5%**；**效果在 10–20 篇后就饱和**（`02` §5.1，slides p23–24）。
5. **太大**：引入大量噪声、上下文爆长；**太小**：答案被切碎、检索到也读不懂；**重叠太多**：近重复碎片互相挤，把正确块挤出 top-k（`03` §4、`02` §4）。
6. 两阶段因为"**快**"和"**准**"在同一套打分里难兼得。**bi-encoder**：查询、文档**各自**编码，能预计算（快、召回）；**cross-encoder**：$(Q,d)$ **拼一起**过模型（准、但不能预计算，只用于精排）（`04` §5.1）。
7. 组件：**LLM 核心 + 规划与推理 + 记忆 + 工具 + 环境**。ReAct 三步：**思考（Thought）→ 行动（Act）→ 观察（Obs）**，循环（`02` §7、`04` §6）。
8. **CoT 只有思考、没有环境交互（没有 $o_t$）**；ReAct 每步都用**观察**校正推理。正因如此，ReAct 不是"闭卷硬推"，能缓解 CoT 的幻觉（`02` §7.2、`04` §6.2，slides p37）。
9. **episodic** 存经历（写=只追加事件流，读=按启发式分数检索）；**semantic** 存知识（写=对事件做 LLM 推理，读=检索）；**procedural** 存技能（写=代码化技能，读=向量检索）（`02` §7.4、`04` §8，slides p45–50）。
10. 见 `04` §2：$\sum_{t\in Q}\text{IDF}(t)\cdot\dfrac{f(t,d)(k_1+1)}{f(t,d)+k_1(1-b+b|d|/\text{avgdl})}$。**$k_1$** 控 TF 饱和快慢（上界 $k_1+1$）；**$b$** 控长度归一（0=不归一，1=全归一）；**IDF** 让罕见词更值钱（`04` §2.1–§2.3）。
11. $\text{IDF}=\ln(1+\frac{N-\text{df}+0.5}{\text{df}+0.5})$。**平滑解决"IDF 可能为 0 或负"**：出现在所有文档里的词，经典式 $\ln(N/\text{df})=0$ 会让它消失，平滑式保证**恒正**（`04` §2.3）。
12. $\cos(u,v)=u^\mathsf{T}v/(\lVert u\rVert\lVert v\rVert)$。$u\cdot v=50$、$\cos(u,v)=1.0$；$u\cdot w=3$、$\cos(u,w)=0.6$。**$v$ 与 $u$ 同向（余弦 1 > 0.6 才对），但点积 50 是被"更长"抬出来的**——所以长短不一时该用余弦；**归一化后点积=余弦**（`04` §4.1）。
13. $s_t=(\text{task},(a_1,o_1),\dots)$；$\text{thought}_t\sim\text{LLM}(s_t)$；$a_t=\text{parse}(\text{thought}_t)$；$o_t=\text{env}(a_t)$。**终止条件**：$a_t$ 是终止动作（如 `Finish[…]`）则停，否则追加 $(a_t,o_t)$ 进入下一步（`04` §6.1）。
14. $a^\*=\arg\max_a\sum_{\text{path}}\mathbb 1[\text{ans}(\text{path})=a]$——走多条推理路径，取**最一致的答案**（`04` §6.2）。
15. **闭卷**（只给问题）→ 测纯参数记忆；**oracle**（喂金标文档）→ 测生成器上限；**RAG**（真实检索）→ 端到端。结论：**oracle 也错 → 生成问题；oracle 好、RAG 差 → 检索问题**（`04` §9、`03` §5）。
16. 先怀疑**查询与文档用词不重合**（字面不匹配）——这是稀疏检索的固有死穴，不是 bug。**修法**：加稠密/混合检索（`03` §3：BM25=−1）。
17. 先做**oracle 对照**：把金标段落直接喂进去。**oracle 对、RAG 错 → 是检索把对的淹没了**（噪声/没 rerank）；**oracle 也错 → 是生成的问题**（`04` §9）。
18. 因为**重叠制造近重复碎片**，这些碎片在 top-k 里互相挤，**把正确的那一块挤出前三**（`03` §4：3 句+重叠 2，hit@3→3/4）。
19. **"检索到了" ≠ "检索对了"**：高分只说明词面像，答案未必在那段里；也可能答案在 retriever 里但生成器没用上（`03` §5 第 8 题检索分 8.23、答案却不在段落里）。
20. **不能信。** 引用本身是 LLM 生成的，**一样会幻觉**——slides p27–28 明说实测里精确率与召回率都低（`02` §6 模式④）。
21. **缺终止条件或状态没更新**：Agent 没有把 $(a_t,o_t)$ 追加进状态、或动作空间里没有终止动作，导致策略反复选同一个动作。**修**：状态必须包含历史 + 设步数上限（`04` §6.1、`05` §3 #12）。

</details>
