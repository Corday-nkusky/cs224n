§5 Agent 循环（ReAct 风格）：观察 -> 思考 -> 行动
==================================================================
step 1: act=Search[apple remote]         obs=The Apple Remote was introduced in 2005 to control F
step 2: act=Search[front row]            obs=The Front Row media center program was discontinued.
step 3: act=Search[keyboard function keys] obs=Front Row can be controlled by keyboard function key

最终答案 = 'keyboard function keys'   用了 3 步
对比：单次检索（只 Search[apple remote] 1 步）拿不到 'keyboard function keys'
→ Agent 的价值在多步『观察-思考-行动』：前一步的输出决定下一步的行动
