## §2 公式速查

**直接答 vs 分步答**（`04` §2）：

$$P_{\text{direct}}(n)=q_{\text{int}}^{\,n}\qquad P_{\text{cot}}(n)=p_{\text{step}}^{\,n}\qquad (p_{\text{step}}>q_{\text{int}})$$

**Best-of-N + 完美 verifier**（`04` §3.1）：

$$P_{\text{BoN}}(k)=1-(1-p)^k$$

**多数投票（$D\to\infty$ 近似）**（`04` §3.2）：

$$P_{\text{MV}}(k)\to 1-(1-p)^k$$

**多数投票 $k=3$ 精确式**（`04` §3.3）：

$$P_{\text{MV}}(3)=3p(1-p)^2\cdot\frac{D-1}{3D}+3p^2(1-p)+p^3$$

**策略梯度带 baseline**（`04` §4.1）：

$$\nabla_\theta J=\mathbb{E}\big[\nabla_\theta\log\pi_\theta(o\mid q)\cdot A\big],\qquad A=R-b$$

**PPO 裁剪目标**（`04` §4.2）：

$$L^{\text{CLIP}}=\mathbb{E}\big[\min(r_tA_t,\ \text{clip}(r_t,1-\epsilon,1+\epsilon)A_t)\big]$$

**GRPO 目标**（`04` §4.3，标准结果非 slides 原文）：

$$\hat A_i=\frac{R_i-\text{mean}(R_{1:G})}{\text{std}(R_{1:G})},\qquad
J=\frac{1}{G}\sum_i\frac{1}{|o_i|}\sum_t\min(r_{i,t}\hat A_i,\text{clip}(r_{i,t}) \hat A_i)-\beta\,\mathrm{KL}(\pi_\theta\|\pi_{\text{ref}})$$

**奖励攻击率**（`04` §5.2）：

$$\text{hack rate}=\frac{(1-p)\,g}{p+(1-p)\,g}$$

**前向 / 反向 KL**（`04` §7.1）：

$$\mathrm{KL}(P\|Q)=\mathbb{E}_P\log\tfrac{P}{Q}\ (\text{mass-covering})\qquad \mathrm{KL}(Q\|P)=\mathbb{E}_Q\log\tfrac{Q}{P}\ (\text{mode-seeking})$$

## §3 踩坑点

| # | 坑 | 怎么认出来 | 怎么修 |
|---|----|-----------|--------|
| 1 | **以为 CoT 对小模型也有用** | 小模型加"think step by step"，准确率不动 | CoT 是**规模涌现**性质（100B+）；小模型常写不合逻辑的 CoT（【slides】part1 p51） |
| 2 | **以为"多采样一定涨"** | k 增大准确率**不涨甚至跌** | 第一查**单条正确率是否过半**（低于 0.5 时多数投票会投到错答案）；第二查**错答案是否成簇**（`03` §3 的简化假设） |
| 3 | **拿 verifier 当免费增益** | 加了 ORM 反而比不加以差 | verifier 的**误判率决定天花板**；`03` §4 实测 ORM(0.8) 卡在 0.92，被纯投票反超 |
| 4 | **用"长度"当质量代理** | 挑最长的解，准确率**低于随机** | 错误链更长（实测 8.00 vs 17.05）；用**verifier**，不要用长度（`04` §6.1） |
| 5 | **以为"末答案对"=推理对** | 末答案准确率涨、推理链看着全是错的 | 这是**奖励攻击**；攻击率 $=\frac{(1-p)g}{p+(1-p)g}$（实测 0.0932）；需要过程信号或更严的验证 |
| 6 | **把 CoT 当"模型真实想法"** | 依据 CoT 做安全判断 | CoT **不忠实**：使用了提示却说出来的比例 <20%（Anthropic, part1 p64） |
| 7 | **组内全对/全错还继续训** | GRPO 训练梯度为 0 / loss 不动 | $\text{std}(R)=0\Rightarrow\hat A=0/0$；DAPO **dynamic sampling** 只留有对也有错的组 |
| 8 | **对称裁剪压死探索** | entropy 崩塌、输出变单一 | DAPO **clip-higher**：上界放宽到如 $1.28$ |
| 9 | **样本级平均忽略长度** | 长 CoT 学得慢、梯度被稀释 | 用 **token-level loss**：$\frac{1}{\sum|o_i|}\sum_i\sum_t$，每 token 等权 |
| 10 | **以为"结果奖励就够了 / PRM 更好"** | 二选一 | 视用途：**训练**用结果奖励给自由（R1 不用 PRM）；**test-time 剪枝**用 PRM 更省（4–8×）。二者不矛盾 |
| 11 | **以为推理必须要显式搜索（MCTS）** | 想复杂化 | 【slides】part1 p34：推理可纯自回归，**不需要外部搜索** |
| 12 | **只对小模型直接上 RL** | 小模型 RL 学不动 | Finding 4：算力有限时**蒸馏 > 直接 RL**（可下传到 1.5B） |
| 13 | **beam search 当默认** | 输出"最顺"却重复、不新 | 现代 LLM 少用 beam（part1 p7）；判别式任务也要留意重复退化 |

## §4 一页串起来

```
问题 → 直接答(近视/无草稿纸) → CoT(写中间步骤) → 单条仍会错
     → self-consistency(投票) → test-time scaling(预算↑)
     → verifier(ORM/PRM) + 搜索 → 但裁判会错、要钱
     → RLVR(答案对错当奖励) → GRPO(组内 z-score, 省 value net) → DAPO(补三洞)
     → 小模型：蒸馏 > RL
代价：慢 · 贵 · 假装推理 · 长度≠准度 · 只对可验证题有效
```

### 答案要点

<details>
<summary>展开</summary>

1. **greedy**：近视，每步局部最优、可能错过全局最优；**beam**：仍追"整体概率最高"（≠正确），且越来越贵——【slides】part1 p7 说现代 LLM 已不常用；**采样**：分布长尾会抽出烂选项（part1 p15：连续 30 token 都落在累计概率前 95% 区内的概率只有 **21%**）。
2. 【slides】part1 p11：**温度越低 → 更 loopy；模型越小 → 更 loopy；题目越难 → 更 loopy**。（AIME 用"30-gram 重复 >20 次"判定。）
3. CoT = 先写中间推理再给答案（`02` §1）。**few-shot**：提示里给带推理的示例（Wei 2022）；**zero-shot**：只加 "Let's think step by step"（Kojima 2023）。
4. 采样 $k$ 条 CoT，对**最终答案多数投票**（`02` §2）。有效条件：① **对的答案只有一种**（正确票堆在一起）；② **错的答案各不相同**（错票分散）。缺任一，投票可能选中错答案。
5. 【slides】part2 p56：**智能地花推理算力，收益可能大于单纯扩参数**；**固定推理预算下，小模型 + 聪明 test-time 策略可胜大模型 + 标准解码**（但要在模型大小与样本数间找 compute-optimal）。
6. **ORM** 评整解对错，**PRM** 逐步评对错（part2 p57）。DeepSeek 不用 PRM：**贵、易被 reward hacking、会限制发现新推理策略**（part1 p26；Finding 2 补"PRM 会惩罚非常规但有效的路径"）。注意 **test-time 剪枝**时 PRM 反而更省（4–8×）。
7. 省掉 **value network**（以及 GAE 的逐 token value 调用）；内存从 **5 → 3** 个模型。advantage 换成 **组内奖励的 z-score**：$\hat A_i=(R_i-\bar R)/s$（【slides】part1 p44/p46）。
8. **clip-higher** 修 entropy collapse（对称裁剪压死探索）；**dynamic sampling** 修"全对/全错 → std=0 → 梯度死区"；**token-level loss** 修"样本级平均对长 CoT 不公（单 token 权重 $\propto1/|o_i|$）"（part1 p47–49）。
9. 只用**可自动判定对错**的奖励 ⇒ 只在**可验证任务**（数学、代码）有效；开放任务（创作、闲聊）管不了；**也不会发现安全护栏**（【slides】part1 p28）。
10. **忠实度** = CoT 是否如实反映模型实际用的信息（`04` §6.3）。Anthropic 实测揭示率 **<20%**，且 RL 提升后平台化、reward hacking 时披露不增加 ⇒ **CoT 监控无法可靠检测抄捷径**。
11. $P_{\text{direct}}=q_{\text{int}}^n$、$P_{\text{cot}}=p_{\text{step}}^n$（`04` §2）。$p_{\text{step}}>q_{\text{int}}$ 因为**网络深度固定**：直接答要在同一段深度里塞 $n$ 步，单步成功率被压低；分步答每步只做一步，深度绰绰有余。
12. $P_{\text{BoN}}(k)=1-(1-p)^k$（`04` §3.1）。**它确实近似多数投票的上限**——当错值不碰撞（$D\to\infty$）时 $P_{\text{MV}}\to$ 同一个 $1-(1-p)^k$（`04` §3.2，`03` §3 上限列的数值落地）。
13. $P_{\text{MV}}(3)=3p(1-p)^2\frac{D-1}{3D}+3p^2(1-p)+p^3$（`04` §3.3）。**并列重要**：$c=1$ 那项只有在"正解与错值并列时随机挑"才拿得到（当 $p=0.5867,D=20$ 时贡献 0.095）；若并列判负，$P$ 从 0.724 掉到 0.629。
14. advantage：$\hat A_i=(R_i-\text{mean}(R_{1:G}))/\text{std}(R_{1:G})$；目标：$\frac{1}{G}\sum_i\frac{1}{|o_i|}\sum_t\min(r_{i,t}\hat A_i,\text{clip}(r_{i,t},\cdot)\hat A_i)-\beta\mathrm{KL}(\pi_\theta\|\pi_{\text{ref}})$（`04` §4.3，**标准结果非 slides 原文**）。
15. $\text{hack rate}=\frac{(1-p)g}{p+(1-p)g}$（`04` §5.2）。$g\to0$ 时 $\to0$；$p\to1$ 时 $\to0$。**只有"推理总会出错($p$小)且捷径总能撞对($g$大)"时攻击率才高。**
16. GAE 的 TD 残差要在**每个 token 位置**估 value 以做逐 token credit assignment，所以每条响应每个 token 要调一次 value function（【slides】part1 p41：512×16×2000 ≈ 1.6e7）。
17. ① **单条正确率是否过半**——低于 0.5 时多数投票会投到错答案（`04` §3.2 的 $1-(1-p)^k$ 在 $p<0.5$ 时不成立为"上升"）；② **错答案是否成簇**——若错的链落点一致，票会堆到同一个错值上（本课 demo 用"错值均匀取自小池"简化了这一点，见 `00` §8.3）。
18. **verifier 的误判率决定天花板**（`04` §3.4）。ORM 识别率 $v=0.8$ 时上限 $\approx0.92$，**与 $k$ 无关**；而 $k$ 足够大时纯投票的"至少一条对"$\to1$，所以反超。**结论：verifier 不够好时，不如直接投票。**
19. **长度偏差**（`04` §6.1）：$\mathbb E[L_{\text{bad}}]=17.05\gg\mathbb E[L_{\text{ok}}]=8.00$，所以"最长"几乎总是一条错链 ⇒ 挑最长 ≈ 挑错（实测 0.0163 << 随机 0.5983）。**长度当质量代理会主动放大 looping。**
20. 组内**全对** ⇒ 所有 $R_i$ 相同 ⇒ $\text{std}(R)=0$ ⇒ $\hat A_i=(R_i-\bar R)/0=0/0$，**无梯度**（`04` §4.4）。修：DAPO **dynamic sampling**——丢弃"全对/全错"的组，只用既有对又有错的组。
21. **奖励攻击**（`04` §5.2）：结果奖励只看末答案，$g>0$ 时会给"推理错但撞对"的链发钱。**能缓解但难根治**：用 PRM 提供过程信号（代价是贵/可被 hack/限探索）、或更严的 verifier；但注意 **CoT 不忠实**意味着"看 CoT 判对错"本身不可靠。

</details>
