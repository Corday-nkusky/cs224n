## §2 验证一：EM 与 token-F1 从零实现

**断言**（`02` §2.4、【slides】p31–32）：短答案用 **span 匹配/精确匹配**（EM），抽取式问答用 **token-F1**（给部分分）。

**你的预期**：`pred="72."`、`gold="72"` 时 EM 是多少？（提示：归一化去标点）

**【实测】**（归一化 = 小写 + 去标点 + 去冠词 + 压空白）：

| pred | gold | EM | F1 | 说明 |
|------|------|----|----|------|
| `72` | `72` | **1** | 1.0000 | 完全一致 |
| `72.` | `72` | **1** | 1.0000 | 多了句点，归一化抹掉 |
| `the cat sat` | `the cat sat on the mat` | **0** | **0.6667** | 少说了后半句 |
| `yes` | `no` | 0 | 0.0000 | 答错 |
| `1942` | `1924` | 0 | 0.0000 | 数字差一点 |

**对账**：与 `02` §2.4 的口头定义逐条吻合 ✅。

**两处要点，`03` 的核心**：

1. **`the cat sat` 只有一半内容，F1 却给 0.6667** —— 因为归一化后参考是 `cat sat on mat`（去掉了两个 the），预测 `cat sat` 是它的**子串**：precision = 2/2 = 1、recall = 2/4 = 0.5，调和平均 = **0.6667**。**F1 偏袒"说了对的、少说了"**；EM 则**一律归零**。**"该用 EM 还是 F1"由此而来**：答案唯一用 EM，答案可长可短用 F1。
2. **`yes` vs `no` 得 0** —— 两个指标都**不懂语义**（`02` §2.1 的 BLEU 死穴在 EM/F1 上同样成立）。`1942` vs `1924` 也只得 0——**数字题的一点之差 = 全错**，这是数学 benchmark 的严苛之处（`04` §2 会说明为什么数学题适合精确匹配）。

> ⚠️ **归一化即"口径"，会改变分数**：本课归一化**去掉冠词**。若你换成"去掉所有标点但保留冠词"，案例 3 的 F1 会变（参考变 5 个词）。**报分数要连归一化规则一起报**（`01` §3）。**`04` §2 给 SQuAD 的官方口径。**

## §3 验证二：pass@k 的无偏估计 vs 蒙特卡洛

**断言**（`02` §2.4）：pass@k = "生成 n 个、抽 k 个，至少一个正确"的概率。

**你的预期**：$n=20$、正确数 $c=6$ 时，pass@1 等于多少？（提示：抽 1 个命中的概率就是 c/n）

**【实测】** 公式 vs 20 万次蒙特卡洛（从 n 个样本**无放回**抽 k 个，至少一个正确）：

```
设定：n=20, c=6
   k     公式 pass@k          蒙特卡洛         |差|
   1      0.300000      0.298305    0.001695
   2      0.521053      0.522940    0.001887
   5      0.870872      0.869885    0.000987
  10      0.994582      0.994490    0.000092
  20      1.000000      1.000000    0.000000
```

**对账**：

| 检查 | 结果 | 说明 |
|------|------|------|
| pass@1 == c/n | 0.300000 == 6/20 ✅ | 抽一个就命中的概率就是正确率 |
| 公式 vs 蒙特卡洛 | 差 $\sim10^{-3}$ | 就是 20 万次抽样的**噪声量级**，公式本身无偏 |
| 单调性 | 0.30 < 0.52 < 0.87 < 0.99 < 1.00 ✅ | k 越大越容易命中 |
| k=n | pass@20 = 1.0 | 把全部样本都取来，只要有一个对就命中 |

**这一屏意味着什么**：

> **"pass@k 不带 k 就没有意义"（`02` §2.4）不是修辞。** 同一个模型的 pass@1 = 0.30，报成 pass@5 就是 0.87——**翻了近 3 倍，模型一行没改。** 所以论文/榜单报 pass@k 一定连 k 和 n 一起报。
>
> **为什么用组合数估计**：你只有"每题 n 个样本里几个对"这**一份观测**，却要报"如果换一批 k 个样本"的期望——组合数 $\binom{n-c}{k}/\binom{n}{k}$ 就是这个"抽不到任何一个正确"的概率，**恰好无偏**（`04` §3 推导）。

## §4 验证三：judge 偏置——同内容换序，胜率翻转

**断言**（`02` §4.2、【slides】p63）：judge 有**位置偏置**和**长度（verbosity）偏置**。

**你的预期**：把一对**完全相同**的回答交换左右槽位，"左边胜率"会变成多少？

**【实测】** 用一个"只看槽位"的假 judge，30 对同样内容：

```
[位置偏置] 30 对完全相同的内容，只是交换左右槽位：
  '槽位1 的胜率' = 1.00（X 在左）
  交换后 X 的胜率 = 0.00
  同一份答案，仅因换了个位置，胜率从 1.00 掉到 0.00（翻转率 1.00）
```

**再看长度偏置**——100 对"一句正确短答 vs 同一句 + 15 个废话词"：

```
  冗长版的胜率 = 1.00（内容毫无增加）
  质量对等、但模型 E 被系统性写得更长时，E 的胜率 = 1.00
```

**对账**：

| 检查 | 结果 | 说明 |
|------|------|------|
| 位置偏置 | 胜率 1.00 ↔ 0.00 | **内容不变、结论反向**——这就是位置/顺序偏置 |
| 长度偏置 | 冗长版 1.00 | 加**废话**（内容零增加）就能全胜 |
| 量化："非平局率" | 1.00 | 真值两份相等（真胜率 0.50 且含平局），只按位置的 judge **100% 都判出赢家**——**假阳性分歧** |
| E 的系统性优势 | 1.00 | E 只是被写得更长，赢率就被长度偏置灌满 |

**这一屏意味着什么**：

> **judge 的分数里混进了"与内容无关"的分量。** `02` §4.3 的对策（rubric、讨论、陪审团、**交换槽位做平均**）都是针对这个。**A4 作业 C/D 部分正是要你亲手画"被偏爱 vs 不被偏爱"的回答长度直方图**——如果两堆长度分布明显错开，就是长度偏置在场的证据。

> ⚠️ **一个必须说的边界**：这里用的是**程序化的"假 judge"**，讲的是**偏置的机制**。真实 LLM judge 是否位置偏置、偏多少，**必须真跑才知道**——本课**没有真跑**（无 API，见 `00` §8）。**【待核验】**

## §5 验证四：数据污染——准确率虚高 + n-gram 检测

**断言**（`02` §6.1、【slides】p71–73）：测试样本进了训练语料，分数会虚高；事后可用 n-gram 重叠检测。

**你的预期**：一个真实水平 45% 的模型，如果 50% 的测试题答案被泄露进训练集，准确率大概会到多少？（提示：泄露的那半接近全对，另一半维持 45%）

**【实测】** 100 题、真实水平 $p=0.45$：

```
  无污染 准确率 = 0.46
  泄露前 50 题答案后 准确率 = 0.75
  污染抬升 = +0.29（凭空多出来的'能力'）
```

**对账**：泄露的 50 题按 0.97 命中、其余按 0.45 → 期望 ≈ (0.97×0.5 + 0.45×0.5) ≈ **0.71**，实测 **0.75**（随机波动），量级吻合 ✅。

**再看检测（8-gram 重叠扫描）**：

```
  被标记 = 50 题；其中真泄露 50 题，误报 0 题，漏报 0 题
  precision=1.00  recall=1.00  F1=1.00（逐字复制的情况能被精确抓出）
  逐字复制一题的 8-gram 重合数 = 15
  改 7 处措辞（near-duplicate）后重合数 = 0 → 不再被标记
```

**对账**：

| 检查 | 结果 | 说明 |
|------|------|------|
| 污染抬升 | 0.46 → 0.75（+0.29） | 一行代码没改、一次训练没多做，分数凭空涨 |
| 逐字泄露检测 | precision=recall=1.00 | 8-gram 对原样复制**精确** |
| 规避 | 重合数 15 → 0 | 只改 7 处措辞，检测**完全失效** |

**这一屏意味着什么**：

> **污染是"最安静的作弊"**：不报错、不改代码，只让榜单好看。**它对闭源模型尤其难查**（`01` §4、【slides】p72）。
> **8–13gram 检测是"必要但不充分"**：它抓得住逐字复制，抓不住**近义改写**——而改写正是最省力的规避方式。这也解释了为什么对抗/动态 benchmark（`02` §3.3）要**用"模型当前会错"来实时出题**：让题目永远不在任何训练语料里。

> ⚠️ **本演示是构造的**：数字来自自造数据 + 自造"模型"，说明**机制的统计后果**，**不代表任何真实 benchmark 的污染幅度**。**【待核验】**
