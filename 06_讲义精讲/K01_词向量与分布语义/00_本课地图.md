## §3 知识清单

每条一句话结论 + 出处。**扫一遍，看有没有哪条你讲不出来。**

### A. 为什么需要词向量（4 条）

1. 【slides】语言学里"意思"的标准解法是 **指称语义**：词（能指）⟺ 概念/事物（所指）。→ Lec2 p4
2. 【slides】WordNet 这条路有四个硬问题：缺语境细微差别（"proficient" 被列为 "good" 的同义词，只在部分语境成立）、收录冒犯性同义词却不带褒贬标注、追不上新词义（wicked / badass / nifty / ninja 的"好"义）、主观 + 需要人工维护。→ Lec2 p6
3. 【slides】**最要命的是第四条**：WordNet 的结构**算不出词与词的相似度**。→ Lec2 p6
4. 【定义】**one-hot / 局部表示**：每个词一个长度为 |V| 的向量，只有一位是 1。任意两个不同词的向量**正交**（内积恒为 0），所以"similarity"这个概念根本不存在。→ Lec2 p7–8

### B. 分布语义（3 条）

5. 【slides】**分布语义假说**：一个词的意思由**经常出现在它附近的词**给出。原文 "You shall know a word by the company it keeps"（J. R. Firth, 1957）。→ Lec2 p9
6. 【slides】做法：固定窗口大小，收集词 w 的所有上下文，用这些上下文构建 w 的表示。→ Lec2 p9
7. 【定义】**词向量 / 词嵌入 / 分布式表示**：给每个词一个**稠密**向量，使得出现在相似上下文中的词，向量也相似（相似度用**点积**衡量）。→ Lec2 p10

### C. word2vec 模型（6 条）

8. 【slides】word2vec 是一个学习词向量的**框架**（Mikolov et al. 2013）：遍历语料每个位置 t，取中心词 c 和上下文词 o，用两者的向量相似度算 P(o|c)，不断调整向量让这个概率最大化。→ Lec2 p11
9. 【定义】**目标函数**（负对数似然的平均）：
   $$J(\theta) = -\frac{1}{T}\sum_{t=1}^{T}\sum_{-m\le j\le m,\ j\ne 0}\log P(w_{t+j}\mid w_t;\theta)$$
   **最小化目标函数 ⟺ 最大化预测准确率。** → Lec2 p14
10. 【slides】每个词有**两套向量**：`v_w`（作中心词时）和 `u_w`（作上下文词时）。打分用点积，套 softmax：
    $$P(o\mid c)=\frac{\exp(u_o^{\mathsf T} v_c)}{\sum_{w\in V}\exp(u_w^{\mathsf T} v_c)}$$ → Lec2 p15
11. 【slides】**为什么用两个**：优化更容易（easier optimization），最后可以把两套平均；只用一套也能跑，而且"稍微好一点"（slides 原话：*it helps a bit*）。→ Lec2 p25
12. 【slides】softmax 的三步：① 点积比较相似度 ② 取指数变正 ③ 在整个词表上归一化成概率分布。→ Lec2 p17
13. 【slides】参数量：d 维向量 × V 个词 × 2 套 = **2dV**，全部塞进一个长向量 θ 里一起优化。→ Lec2 p18

### D. 优化（3 条）

14. 【slides】J(θ) 是**全体窗口**的函数，一次梯度要扫几十亿个窗口 → 必须用 **SGD**：采样窗口，每个窗口更新一次。→ Lec2 p22
15. 【slides】**注意**：slides 明说这个目标**可能不是凸的**（"our objectives may not be convex... But life turns out to be okay"）。→ Lec2 p20
16. 【slides】**负采样的梯度是稀疏的**：一个窗口里最多只有 2m+1 个真实词 + 2mK 个负样本，所以只更新这些词对应的行（需要稀疏更新或哈希）。→ Lec2 p28–29

### E. 三条优化路线：负采样 / 层次 softmax / 子采样（7 条）

17. 【slides】naive softmax 贵的根源是**分母那个对整个词表的大求和**。→ Lec2 p26
18. 【定义】**负采样损失**（SGNS）：把"从 V 个词里选 1 个"的多选题，拆成 K+1 道二分类判断题：
    $$J_{\text{neg}}=-\log\sigma(u_o^{\mathsf T}v_c)-\sum_{k\in\text{sampled}}\log\sigma(-u_k^{\mathsf T}v_c)$$
    其中 $\sigma(x)=1/(1+e^{-x})$。→ Lec2 p27
19. 【slides】负样本按 $P(w)=U(w)^{3/4}/Z$ 采样 —— **给 unigram 分布开 3/4 次方，让低频词被采到的机会变大**。→ Lec2 p27
20. 【定义 ⭐】**softmax 的分母带来三类不同的问题，别混为一谈**：① 前向算得慢（O(V) 点积）；② 反向写得多（$\partial J/\partial u_{w\neq o}=P(w|c)v_c$ 对 V−1 个词都非零，梯度被强行变稠密）；③ 目标函数错配（强制概率竞争，但我们要的是向量）。→ `04` §2.6
21. 【论文原文】word2vec 的卖点就是 *"does not involve dense matrix multiplications"*（arXiv:1310.4546 §1）—— 而第 ② 类问题正好把这句话毁掉了。→ `04` §2.6
22. 【论文原文】**为什么可以随便简化目标**：*"the Skip-gram model is only concerned with learning high-quality vector representations, so we are free to simplify NCE..."*（§2.2）。这是负采样的合法性来源。→ `04` §4
23. 【论文原文】**层次 softmax**：二叉树表示输出层，W 个词是叶子，**只评估约 $\log_2 W$ 个节点**；用**二叉哈夫曼树**是因为 *"it assigns short codes to the frequent words"*；路径概率 $p(w|w_I)=\prod_{j=1}^{L(w)-1}\sigma\big([\![n(w,j{+}1)=\mathrm{ch}(n(w,j))]\!]\cdot{v'_{n(w,j)}}^{\mathsf T}v_{w_I}\big)$；$v_w$ 属于**词**（W 个），$v'_n$ 属于**内部节点**（W−1 个）。→ `04` §5.2–§5.3
24. 【论文原文】**高频词子采样**是并列于上面两者的第三件事：*"results in a significant speedup (around 2x - 10x), and improves accuracy of the representations of less frequent words"*（§1）。**它治的是罕见词，不是 softmax 的问题。**→ `04` §2.6

### F. 计数法：共现矩阵 + SVD（5 条）

25. 【slides】共现矩阵 X 有两种口径：**窗口**（抓句法+语义，"word space"）和**全文档**（抓主题，"document space"，即 LSA）。→ Lec2 p30
26. 【slides】窗口口径下 X 是**对称**的（不分左右）。→ Lec2 p31
27. 【slides】直接拿共现向量用的三个问题：维度随词表增长、极其稀疏、下游分类模型对稀疏很敏感（不够稳健）。所以要降维到 **25–1000 维**的稠密向量。→ Lec2 p32
28. 【定义】**SVD**：把 X 分解成 $U\Sigma V^{\mathsf T}$，只保留前 k 个奇异值 → $\hat X$ 是 X 的**最优秩 k 近似**（最小二乘意义下）。经典线性代数结论，**大矩阵上算起来很贵**。→ Lec2 p33
29. 【slides】**对原始计数直接跑 SVD 效果不好**，需要对 X 做手脚：取对数、`min(X, t)`（t≈100）、忽略功能词（the / he / has）、**斜坡窗口**（近的词权重高）、用相关性替代计数并把负值置 0。→ Lec2 p34

### G. GloVe 与评测（6 条）

30. 【slides】**GloVe**（Pennington, Socher, Manning, EMNLP 2014）的核心提问：**怎么把"共现概率的比值"编码成向量空间里的线性语义成分？** 模型是 log-bilinear，卖点是训练快、能扩展到超大语料。→ Lec2 p36–37
31. 【定义】**内在评测 vs 外在评测**：内在 = 在专门设计的中间子任务上评（快、能帮助理解系统，但**不确定是否对真实任务有用**）；外在 = 在真实任务上评（慢，但**换掉一个子系统后准确率提升 = 真的赢了**）。→ Lec2 p38
32. 【slides】**词向量类比**是最典型的内在评测：`man:woman :: king:?`，做法是向量加减后用余弦距离检索，并且**要把输入词从检索结果里剔除**。→ Lec2 p39
33. 【slides】类比的**已知缺陷**：如果信息在向量里但**不是线性关系**，类比就测不出来。→ Lec2 p39
34. 【slides】**WordSim353** 是另一类内在评测：拿向量距离和**人类打分**算相关性（例：tiger–cat 7.35、stock–jaguar 0.92）。→ Lec2 p41
35. 【slides】外在评测的例子：**命名实体识别**（识别人名/机构名/地名，如 "Chris Manning lives in Palo Alto"）。→ Lec2 p43

## §5 术语索引

按首次出现的篇排。`01` 篇的术语零前置，`02` 篇的是本知识点的核心概念，`04` 篇的才需要推导背景。

| 术语 | 一句话解释 | 出处 |
|------|-----------|------|
| **指称语义（denotational semantics）** | 用"词指向什么事物"定义词义 | `01` §2 |
| **WordNet** | 人工编纂的同义词集 + 上下位关系词典 | `01` §2 |
| **synset（同义词集）** | WordNet 的基本单位，一组同义词 | `01` §2 |
| **hypernym（上位词）** | "is a" 关系中的更抽象一方（panda → mammal） | `01` §2 |
| **one-hot / 局部表示** | 一个词一位，两两正交 | `01` §3 |
| **正交** | 两个向量内积为 0 | `01` §3 |
| **分布语义** | 词义 = 它常和谁一起出现 | `01` §4 |
| **词向量 / 词嵌入** | 词的稠密实数向量表示 | `02` §1 |
| **稠密向量 / 分布式表示** | 意思分散在多个维度上（与 one-hot 相对） | `02` §1 |
| **点积相似度** | $u^{\mathsf T}v$，越大越相似 | `02` §2.1 |
| **模长（norm）** | $\lVert v\rVert$，向量到原点的距离 | `02` §2.2 |
| **余弦相似度** | $u^{\mathsf T}v/(\lVert u\rVert\lVert v\rVert)$，消掉长度只比方向 | `02` §2.3 |
| **Frobenius 范数** | $\lVert A\rVert_F$，把矩阵抻成向量算长度，量重构误差用 | `02` §2.4 |
| **代理任务** | 用简单预测任务逼出好的表示，不关心预测准不准 | `02` §3 |
| **中心词 c / 上下文词 o** | 窗口中间那个词 / 窗口里的其他词 | `02` §3 |
| **窗口大小 m** | 中心词左右各看 m 个词 | `02` §3 |
| **共现矩阵 X** | 统计词与词在同一窗口出现次数的矩阵 = 带权无向图的邻接矩阵 | `02` §5 |
| **二分图** | 顶点能分成两组、组内无边、边只跨两组的图；BFS 二染色可判定 | `03` §4 |
| **名义维度 vs 有效自由度** | k 写的是几 ≠ 每个词实际用到几个坐标；后者才是余弦有没有意义的判据 | `03` §4 |
| **成对相等的奇异值** | 共现矩阵为二分图时的谱指纹（每层的两个方向各撑一组词） | `03` §4 |
| **LSA** | 对"词-文档"共现矩阵做 SVD 的经典方法 | `02` §5.2 |
| **奇异值 σ** | 数据在第 i 个新坐标轴上散开的程度 = 该轴的重要性 | `02` §7 |
| **SVD** | $X=U\Sigma V^{\mathsf T}$，换一组坐标轴用于降维 | `02` §7（直觉）、`04` §6.3（公式） |
| **秩 k 近似** | 只保留最大的 k 个奇异值，最小二乘意义下最优 | `02` §7③、`03` §5（实测） |
| **功能词（function words）** | the / he / has 这类高频虚词，语义信息少 | `02` §7 |
| **GloVe** | 直接拟合共现概率比值的 log-bilinear 模型 | `02` §8、`04` §7 |
| **静态表示 / 一词一义** | 一个词只有一个向量，不随上下文变（本代的死穴） | `02` §9 |
| **似然 / 负对数似然** | 数据出现的概率 / 取负对数后的损失函数 | `04` §2.1 |
| **softmax** | 把任意实数变成概率分布：$\exp(x_i)/\sum_j\exp(x_j)$ | `04` §2.2 |
| **SGD** | 每次用一个（小批）样本更新，不等全量梯度 | `04` §3.2 |
| **负采样（SGNS）** | 用 K+1 个二分类替代 V 分类的 softmax | `04` §4 |
| **sigmoid σ** | $1/(1+e^{-x})$，把实数压到 (0,1) | `04` §4.2 |
| **unigram 分布 U(w)** | 词频分布；负采样时取 3/4 次方 | `04` §4.3 |
| **稀疏梯度更新** | 只更新本次出现词对应的那几行 | `04` §4.5 |
| **Noise Contrastive Estimation（NCE）** | 用逻辑回归"区分真实数据与噪声"来避开归一化常数的估计；NEG 是它的简化版 | `04` §2.6 |
| **层次 softmax（Hierarchical softmax）** | 二叉树表示输出层，把 V 选 1 拆成路径上的一串二分类 | `04` §5.2 |
| **哈夫曼树（Huffman tree）** | 每次合并权重最小的两个节点；使带权路径长度最小的二叉树 | `04` §5.2 |
| **带权路径长度** | $\sum_w f(w)\cdot L(w)$；哈夫曼树最小化它 | `04` §5.2 |
| **内部节点向量 $v'_n$** | 层次 softmax 里挂在树上内部节点上的向量，共 W−1 个（**不属于任何词**） | `04` §5.3 |
| **高频词子采样（subsampling）** | 按概率丢弃高频词，加速并改善低频词表示 | `04` §2.6 |

### 本课没能验证的部分

1. **Lec1 的两份 PDF 未解析**，K01 内容主要来自 Lec2。
2. **GloVe 的损失公式、slides 第 23/24/35/40/42 页的图**都在图像层，文字提取拿不到，本课未写。
3. **`U(w)^{3/4}` 的 3/4 是原论文的经验值** —— slides 只说"让低频词被采得更频繁"，没给为什么是 3/4 的推导。
4. **"只用一套向量 helps a bit"** 是 slides 原话，没给实验数据，我未验证。
5. **WordSim353 的具体分数**是从 slides 表格抄的，我**没有下载该数据集复核**。
6. **`03` 篇里真训出来的 loss 曲线与类比结果来自 `playground/t1_word2vec/` 的实现**（那份材料是按要求生成的参考资料，不是官方 word2vec C 代码的输出）；语料是构造的小语料，**不能用来推断真实规模上的效果**。
7. **`03` §4 那组对照实验是在 7 个词 / 3–4 句话的构造语料上做的**，结论讲的是"机制"，**不能拿去推断真实语料的数值**。特别是：
   - **二分图**这种结构在真实大语料里几乎不可能整体出现（要所有词的共现关系都能二染色），它在这里出现是因为语料只有 3 句话；
   - 但第二种机制（**两个词共现行相同**）在真实语料里确实存在，主要落在**极低频词**上——它们可能全文只出现一两次，上下文完全一样。这正是 `02` §7 那批 hacks 里要 `min(X,t)`、去掉功能词的原因之一。
8. **"嵌入 = 共现行的线性函数"这条恒等式是实测验证的**（k=1..6，`max|差| = 2.2e-15`），但它成立的前提是我们用的是**原始 SVD 嵌入**。word2vec 的梯度训练不是这个形式，同一条结论能否直接搬过去，**我没有验证**。
