## §2 验证一：one-hot 里"相似度"不存在

**断言**（`02` §1、`01` §3）：任意两个不同词的 one-hot 向量正交，内积恒为 0。

**你的预期**：填一下——`hotel · motel = ?`，`hotel · cat = ?`

**【实测】** 词表 5 个词，两两内积：

```
            hotel    motel  banking  monetar      cat
  hotel         1        0        0        0        0
  motel         0        1        0        0        0
  banking       0        0        1        0        0
  monetary      0        0        0        1        0
  cat           0        0        0        0        1
```

**对账**：对角线是 1（自己跟自己），**其余全 0**。

**这一屏意味着什么**：`motel` 和 `hotel` 的关系，跟 `hotel` 和 `cat` 的关系，在数值上**完全相同**。检索系统没有任何办法知道前两个是一类东西。

## §3 验证二：3 句话也能数出一张共现矩阵

**断言**（`02` §5.1）：窗口共现矩阵对称、稀疏；`02` §5.1 的手算表是对的。

语料（**window = 1**，只看左右各 1 个词）：

```
I like deep learning
I like NLP
I enjoy flying
```

**你的预期**：`X[I][like]` 应该是几？（提示：`I` 在两句话里都挨着 `like`）

**【实测】** 行 = 中心词，列 = 上下文词：

|     | I | NLP | deep | enjoy | flying | learning | like |
|-----|---|-----|------|-------|--------|----------|------|
| **I** | 0 | 0 | 0 | 1 | 0 | 0 | **2** |
| **NLP** | 0 | 0 | 0 | 0 | 0 | 0 | 1 |
| **deep** | 0 | 0 | 0 | 0 | 0 | 1 | 1 |
| **enjoy** | 1 | 0 | 0 | 0 | 1 | 0 | 0 |
| **flying** | 0 | 0 | 0 | 1 | 0 | 0 | 0 |
| **learning** | 0 | 0 | 1 | 0 | 0 | 0 | 0 |
| **like** | 2 | 1 | 1 | 0 | 0 | 0 | 0 |

两个可验证的事实：

- **对称性**：`max|X − Xᵀ| = 0` ✅ —— 窗口口径下不分左右，这是必然的

## §4 验证三：SVD 降维之后，能算相似度了……吗

**断言**（`02` §7）：SVD 换一组坐标轴，保留前 k 个 = 有损压缩。

【实测】对 X 做 SVD，7 个奇异值：

```
[2.6404  2.6404  1.1931  1.1931  0.7775  0.7775  0.]
```

保留前 2 个（k=2），每个词得到二维坐标：

```
  I          [ 2.2023  0.    ]
  NLP        [ 0.9168  0.    ]
  deep       [ 1.0703  0.    ]
  flying     [ 0.3688  0.    ]
  enjoy      [ 0.     -0.9737]
  learning   [ 0.     -0.4053]
  like       [ 0.     -2.4206]
```

**你的预期**：现在算余弦相似度。`like` 和 `enjoy` 都是"喜欢"类动词，你猜多少？`deep` 和 `learning`（语料里是 "deep learning"）呢？

**【实测】**：

| 词对 | cos | 你的直觉会是？ |
|------|-----|--------------|
| like – enjoy | **+1.0000** | 都是"喜欢"类动词 ✅ |
| deep – learning | **+0.0000** | 实际语料里是 "deep learning" ❌ |
| I – like | **+0.0000** | 明明紧挨着出现过 ❌ |
| NLP – flying | **+1.0000** | 毫无关系 ❌ |
| deep – flying | **+1.0000** | 毫无关系 ❌ |

### ⚠️ 这一屏是本课最值得停下来想的一屏

**那三个 `1.0000` 不是"学得好"，是塌了。** 但塌的**原因**很容易说错，顺着数据看。

**第一步，看数字。** 每个词的第二维坐标**严格为 0**（留 8 位小数实打）：

```
  I          [+2.20228405  +0.00000000]   非零坐标数 = 1
  NLP        [+0.91675668  +0.00000000]   非零坐标数 = 1
  deep       [+1.07026685  +0.00000000]   非零坐标数 = 1
  flying     [+0.36877068  +0.00000000]   非零坐标数 = 1
  enjoy      [+0.00000000  -0.97371947]   非零坐标数 = 1
  learning   [+0.00000000  -0.40533547]   非零坐标数 = 1
  like       [+0.00000000  -2.42064750]   非零坐标数 = 1
```

**名字叫 2 维，实际每个词只用到 1 个坐标。** 两根轴从没被同一个词同时使用过。

**第二步，为什么。** 回到 PART 2 那张共现矩阵：按"谁和谁共现"给 7 个词分组，会得到互不重叠的两组，组内彼此从不共现，只跟对面组共现：

```
  A = { I, NLP, deep, flying }
  B = { enjoy, learning, like }
  I↔enjoy? ✓   I↔like? ✓   NLP↔like? ✓   deep↔learning? ✓   flying↔enjoy? ✓
  I↔NLP?  ✗   NLP↔deep? ✗  A 组内部任何一对都 ✗
```

这就是**二分图**——你数据结构里练过的那个"能不能二染色"判定，同一个东西。`code/k01_verify_dim.py` 里跑的就是这个 BFS 染色，输出 `是否二分图: True`。

**第三步，二分图在奇异值上的指纹。** 这种矩阵的奇异值**成对相等**：

```
[2.6404  2.6404 | 1.1931  1.1931 | 0.7775  0.7775 | 0]
 ↑同一对 ─────┘
```

成对，是因为每一层的两个方向一个专门撑起 A 组、一个专门撑起 B 组。于是 **k=2 恰好把 A 组铺到第一根轴、B 组铺到第二根轴，两组各占一根，每词实际只分到 1 个自由度**。组内坐标还同号 → 夹角 0 度 → `cos = 1`。

> **所以真正的判据不是"k 写的是几"，而是"每个词实际拿到几个线性无关的共现模式"。**
> 名义维度 ≠ 有效自由度。看到配对相等的奇异值，就该警觉。

### 换一组对照，把上面这条钉死

跑 `code/k01_verify_dim.py`（输出在 `logs/k01_verify_dim_out.txt`）：

| 实验 | 语料 | k=2 时每词非零坐标数 | `\|cos\|=1` 的词对占比 |
|------|------|------------------|-------------------|
| 1 | 原 3 句话（**是**二分图） | **1** | **9/21 = 42.9%** |
| 2 | 加一句 `I enjoy learning NLP`，打破二分图 | **2** | **1/21 = 4.8%** |
| 3 | 造两个共现行完全相同的词 | 任意 | k=2 / 50 / 300 **全是 1.000000000000** |

三条实测结论，一条都不能省：

1. **真 2 维（实验 2）确实不会"一堆词都拿 1.0"** —— 42.9% 掉到 4.8%。每个词两个坐标都用上了，角度就出来了。
2. **但实验 2 剩下的那 1 对是 `NLP` 和 `deep`**，而它们在语料里的共现行**一模一样**：都是 `[0 0 0 0 0 1 1]`（都只跟 `learning` 和 `like` 共现）。
3. **这种词维度救不了** —— 实验 3 里 k=2 / 50 / 300 全部 `1.000000000000`，两个嵌入向量 `max|差| = 2.3e-13`。

第 3 条背后是一条恒等式（脚本里 k=1..6 全部验证，`max|差| = 2.2e-15`）：

$$
\underbrace{U[:,{:}k]\,S[:k]}_{\text{词嵌入}} \;\equiv\; X \cdot V[:,{:}k]^{\mathsf T}
$$

**嵌入是共现矩阵「行」的线性函数。** 语料里长得一模一样的两个词 → 行相同 → 嵌入相同 → `cos = 1`。**这不是降维的锅，是数据的锅。**

**合起来，塌有两个不同的成因，只有第一个靠维度能救**：

| 成因 | 现象 | 怎么修 |
|------|------|--------|
| 图结构让维度虚高（本案：二分图让 k=2 只剩 1 个自由度） | 一组一组地拿 1.0 | 加 k / 换打破结构的语料 |
| 语料区分不了这两个词（共现行相同） | 无论多少维都是 1.0 | **只能换语料** |

**对账**：`02` §2.3 那条警告在这里撞上了。**看到 1.0000 先别高兴** —— 先去数一数每个词实际用到了几个坐标。

> **这条对 A1 作业有直接意义**：你在作业里画的那张二维图（`question_1.5.png`）本质就是这个效果。**看到"几个词聚成一堆"不等于模型学到了语义**，你要能说出它为什么聚。
> 真实语料要用 **25–1000 维**（`tools` Lec2 p32 的量级），但**维度只是必要条件之一** —— 语料本身得让两个词有不同的上下文分布，否则 300 维也一样是 1.0。

## §5 验证四：SVD 是"最优"的有损压缩

**断言**（`02` §7③）：保留前 k 个奇异值得到的 $X_k$，是 X 的最小二乘意义下的最优秩 k 近似。

**你的预期**：k 越大，误差应该越____？k 等于矩阵的实际秩时，误差应该是____？

【实测】重构误差 $\lVert X - X_k\rVert_F$（`02` §2.4 定义的 Frobenius 范数）随 k 的变化：

| k | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| 误差 | 3.3208 | 2.0140 | 1.6225 | 1.0996 | 0.7775 | 0.0000 | 0.0000 |

**对账**：单调下降 ✅，k = 6 时完全重建 ✅ —— 因为这个 7×7 矩阵的实际秩是 6（第 7 个奇异值是 0）。

**这就是"降维 = 有损压缩，且 SVD 是最优的有损压缩"的实测依据。**

> 顺带验证了一件事：最后一个非零奇异值后面的全是 0，**说明这个矩阵里真正独立的信息只有 6 个方向** —— 降维不是丢信息，是丢掉本来就不存在的冗余。

## §7 怎么判断"学成了"

三个信号，**从弱到强**：

| 信号 | 怎么看 | 可信度 |
|------|--------|--------|
| loss 在降 | 训练日志 | 弱 —— 降不代表学到了语义 |
| 最近邻合理 | `king` 的邻居是 `queen/prince` | 中 **—— 这是最实用的判据** |
| 类比成立 | `king − man + woman ≈ queen` | 中 —— 但**信息可能不线性**（slides p39 明说了这个缺陷） |

**最强的一个判据其实不在表里**：换到真实任务上看准确率有没有涨（外在评测）。这一步要等 K09。
