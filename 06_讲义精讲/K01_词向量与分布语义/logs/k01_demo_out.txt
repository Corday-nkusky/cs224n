PART 3 · SVD 降到 2 维，看看能不能算相似度
==============================================================
奇异值: [2.6404 2.6404 1.1931 1.1931 0.7775 0.7775 0.    ]

降到 2 维后的坐标:
  I          [2.2023 0.    ]
  NLP        [0.9168 0.    ]
  deep       [1.0703 0.    ]
  enjoy      [ 0.     -0.9737]
  flying     [0.3688 0.    ]
  learning   [ 0.     -0.4053]
  like       [ 0.     -2.4206]

余弦相似度（挑几对）:
  cos(like    , enjoy   ) = +1.0000
  cos(deep    , learning) = +0.0000
  cos(I       , like    ) = +0.0000
  cos(NLP     , flying  ) = +1.0000
  cos(deep    , flying  ) = +1.0000

>>> 第一步: 数一数每个词实际用到了几个坐标 -> [1]
>>> 名义上 k=2，但每个词只有 1 个非零坐标 —— 两根轴从没被同一个词同时使用过。
>>> 第二步: 这事儿和维度无关，先看奇异值是不是成对相等的 —— 上面那串
>>>         [2.6404 2.6404 | 1.1931 1.1931 | 0.7775 0.7775] 就是成对。
>>>         成对相等是共现矩阵为『二分图』的指纹:
>>>           分组 A = ['I', 'NLP', 'deep', 'flying']
>>>           分组 B = ['enjoy', 'learning', 'like']
>>>         A 组内部互不共现，只跟 B 组共现（反之亦然）。SVD 于是把 A 组铺到
>>>         第一根轴、B 组铺到第二根轴 —— 每组内部只剩 1 个自由度、坐标还同号，
>>>         夹角必然是 0 度 => 组内 cos 全 1.0000，跨组全 0.0000。
>>> 结论: 判据不是『k 写的是几』，而是『每个词实际拿到几个线性无关的共现模式』。
>>>      还有第二种塌法跟维度无关: 两个词在语料里的共现行一模一样时，
>>>      2 维 / 50 维 / 300 维都是 1.0 —— 那得换语料才救得回来。
>>>      完整对照实验跑 code/k01_verify_dim.py（输出见 logs/k01_verify_dim_out.txt）。

PART 4 · 保留 k 个奇异值 = 最优秩 k 近似（Lec2 p33 的结论，实测）
==============================================================
  k=1: 重构误差 ||X - X_k||_F = 3.320849
  k=2: 重构误差 ||X - X_k||_F = 2.013971
  k=3: 重构误差 ||X - X_k||_F = 1.622533
  k=4: 重构误差 ||X - X_k||_F = 1.099613
  k=5: 重构误差 ||X - X_k||_F = 0.777544
  k=6: 重构误差 ||X - X_k||_F = 0.000000
  k=7: 重构误差 ||X - X_k||_F = 0.000000

>>> k 增大误差单调下降; k=n 时完全重建。
>>> 保留前 k 个 = 在'最小二乘'意义下能做到的最好压缩（SVD 的经典结论）。
