## 1. 最容易搞混的三样东西：Lec、K、T

- **Lec（L1–L19）= 官方讲课顺序**，按年份排的，`01_Lectures/` 里一个 PDF 一讲。
- **K（K01–K12）= 按"缺陷链"重排的学习顺序**——每一代技术解决上一代的什么缺陷、又带来什么新代价（词向量→RNN→Transformer→预训练→后训练→PEFT→RAG→评测）。K 和 Lec **不是一一对应**：K01 用 L1–L2，K10 用 L12–L13。**你按 K 学，不按 Lec 学。**
- **T（T0–T6）= 阶段任务**，一个 T 通常 = 一个 K 的讲义 + 一个作业 + 我给你的验收。对应关系：

| 任务 | 学什么 | 做什么作业 | 状态看哪 |
|------|--------|-----------|---------|
| T0 | PyTorch/autograd 军训（可与 T1 并行，**必须在 T2 前过**） | playground 手写线性回归 | T0 文档 |
| T1 | K01 词向量 | A1（notebook，NumPy+gensim） | T1 文档 |
| T2 | K02 反向传播 + K03 RNN | A2（tensor 求导 + 依存句法分析器，**无 RNN 代码**） | T2 文档 |
| T3 | K04 Transformer 精读 | playground 单头 attention | T3 文档 |
| T4 | K04 动手 | A3（从零写 Transformer，8 个 pytest） | T4 文档 |
| T5 | K05–K09 前沿半程 | A4（API 评测 + red team，⚠️ 要 key） | T5 文档 |
| T6 | K10–K12 出课过桥 | 无作业，转论文阅读 | T6 文档 |

## 2. 每个 T 的标准打法：三幕循环（看懂 → 跟练 → 放手）

> 方法论全称、文献依据（PRIMM、样例渐隐、渐进责任释放、提取练习）见 `D:\code\00_学习方法论.md` §0。
> 一句话：**一次只跨一级，每跨一级有桥，过完桥桥要能撤。**

```
第一幕【看懂 I do】读 K 的 00/01/02：地图 → 为什么需要它 → 它是什么（手算级例子）
        ↓ 能力级 1：能用自己的话复述
第二幕【跟练 We do】
   ② 03 篇跑 demo：Predict 先写预期 → Run 跑 → 对不上的标出来（只看输出，别翻源码）  ……级 2
   ③ 上手桥·样例：换 toy 新例子自己手算 + 解释每一步（Investigate）                ……级 3
   ④ 上手桥·工具：脱离作业的 3–5 行语法/API 微热身（Modify 前奏）                  ……级 4
   ⑤ 做作业填空部分：按伪代码/骨架填核心，写一个函数立刻跑一个测试（Completion）   ……级 5
        ↓
第三幕【放手 You do】
   ⑥ playground / 作业扩展：关掉桥，从零写同类新程序（Make）                       ……级 6
   ⑦ 真实报错自己定位（现象→假设→验证→修复）                                      ……级 7
   ⑧ 读 04 推导（先自己推）+ 05 自测 → 找我验收：test 全绿 + 合资料口述问答         ……级 8
        ↓
   过了 → 我回填验收记录 → commit → 解锁下一个 T
   没过 → 错点登记错题本，隔几天延迟重测，"能讲清"才销账
```

**桥文档在哪**：概念到作业之间觉得跳，就去 `07_伴学/02_*`（每个配作业的 K 都会有一座；没有桥不许硬上）。
**两种卡住要分清**：有路径在慢慢推进 = 正常，继续；无路可走超 20–30 分钟 = 桥不够，来找我补，不要硬熬。
**03/04 的读法**：`03` 紧接 02 读（先猜后验，别跳猜）；`04` 的推导放在自己动手卡壳之后再翻，提前翻会把"自己写"变成"抄"。

## 3. 四条使用纪律

1. **作业是规格书，可信度 > 讲义 > 二手笔记**。我描述的作业内容都已直接核对过文件，但你开工前仍可自己扫一眼：有几个文件、测试函数叫什么、requirements 里有什么。
2. **进度只写 `05_Records/验收记录.md` 一处**。`01_当前位置.md` 只管"下一步动作"，不记验收结论，避免两份进度打架。
3. **`02_Assignments/_packages/` 永不修改**；代码写在解压后的工作目录。
4. **`playground/` 里已有的 w2v 两份脚本是 2026-09-25 生成的参考实现**：先自己写 → 卡住再看 → 关掉重写 → diff。读过 ≠ 会写。

## 4. 不知道该干什么的时候

1. 打开 `07_伴学/01_当前位置.md`，做"下一步"的第一条。
2. 卡住超 30 分钟 → 贴报错给我，我先定位根因再给修法。
3. 一个 T 做完 → 主动来找我验收（我不催进度，节奏你掌握；固定检查点：T1/T0/T2/T3/T4/T5 后）。
