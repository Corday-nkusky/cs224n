## 台阶 ①：转移系统，先手走一遍（约 25 分钟）｜级 2 · 看得准

这是 A2 的**领域知识**，不是数学。定义在 `_packages/a2_handout.pdf` 里；下面用**你代码里自带的测试**反推出精确口径（`parser_transitions.py` 的 `test_step`，第 129–138 行）。

**状态**（`PartialParse.__init__` 要你初始化的三个字段）：

| 字段 | 初始值 | 含义 |
|------|-------|------|
| `stack` | `["ROOT"]` | 顶部在**列表末尾** |
| `buffer` | 句子词列表（保持顺序，**别改原句**） | 第一个词是下一个待处理的 |
| `dependencies` | `[]` | 边表，元组形式 `(head, dependent)` |

**三个动作**（对着测试里的期望值推）：

| 动作 | 做什么 | 测试给的证据（输入→期望） |
|------|--------|--------------------------|
| **S**（shift） | `buffer` 第一个词移到 `stack` 顶部 | `S`: stack `["ROOT","the"]`, buf `["cat","sat"]` → stack `("ROOT","the","cat")`, buf `("sat",)` |
| **LA**（left-arc） | 加边 `(stack[-1] → stack[-2])`，然后**弹出 stack[-2]** | `LA`: stack `["ROOT","the","cat"]`, buf `["sat"]` → stack `("ROOT","cat")`, deps 多出 `("cat","the")` |
| **RA**（right-arc） | 加边 `(stack[-2] → stack[-1])`，然后**弹出 stack[-1]** | `RA`: stack `["ROOT","run","fast"]`, buf `[]` → stack `("ROOT","run")`, deps 多出 `("run","fast")` |

## 台阶 ②：minibatch_parse 的循环（约 15 分钟）｜级 3 · 追得透

`minibatch_parse` 是**作业里唯一有官方伪代码**的部分（handout 里给了，`parser_transitions.py` 第 94 行也提示了）。不要照抄，先用中文把这个循环讲一遍：

1. 给每个句子建一个 `PartialParse` → 得到 `partial_parses` 列表
2. 做一份**浅拷贝** `unfinished_parses`（代码注释特别警告：**不要用 `del`** 从浅拷贝里删元素，会释放 `partial_parses` 还在用的内存）
3. 循环：只要还有没完成的 parse，就
   - 把它整批喂给 `model.predict(...)`，拿到每个 parse 的下一个转移
   - 逐个 `parse_step(t)` 应用
   - 把**已完成**的（`stack` 只剩 `ROOT` 且 `buffer` 空）从 `unfinished_parses` 里**排除掉**
4. 最后按**原始顺序**返回每个句子的 `dependencies`

**先写预期再跑**：`python parser_transitions.py part_d` 里的 `DummyModel` 是**按规则**返回转移的假模型（不是神经网络）。它的两种模式（`unidirectional` / `interleave`）会走完全不同的路径。**先自己预判 `interleave` 模式下的解析结果，再跑。**

## 台阶 ③：PyTorch 微热身（约 20 分钟，放 playground 或新 cell）｜级 4 · Modify 前奏

A2 需要的新语法就这几块，先在空 cell 里玩明白（**不是答案，是通用 API**）：

```python
import torch, torch.nn as nn, torch.nn.functional as F

emb = nn.Parameter(torch.randn(10, 4))        # 可训练参数：和普通 tensor 的区别是 requires_grad=True
W = nn.Parameter(torch.empty(3, 8))
nn.init.xavier_uniform_(W)                    # A2 指定的初始化；打印一下看它的取值范围
b = nn.Parameter(torch.zeros(3))              # 偏置用 nn.init.uniform_ 默认参数

idx = torch.randint(0, 10, (2, 3))            # (batch, n_features) 的索引
x = emb[idx].view(2, -1)                      # 查表 + 展平；打印 x.shape 确认是 (2, 3*4)

h = F.relu(x @ W.t() + b)                     # 记住 K02 §1：W 的第 i 行和 x 点积 → 用转置
logits = h @ nn.Parameter(torch.randn(8, 3)).t()
loss = nn.CrossEntropyLoss()(logits, torch.tensor([0, 2]))   # target 是类别索引，不是 one-hot
loss.backward()                               # ← 这一步就是你 04 §7 手推的那整条链，autograd 替你走
print(W.grad.shape)                           # 必须与 W 同形（形状约定！）
```

**每一条都对照 K02**：
- `W.grad.shape == W.shape` → `04` §5 的**形状约定**
- `loss.backward()` → `03` §6 的**三方对账**（autograd 和你手推差 0.0）
- `F.relu` 后面接 `CrossEntropyLoss` → `02` §6 **不要再套 softmax**

> 提示：`emb[idx]` 等价于 `torch.index_select(emb, 0, idx.flatten()).view(...)`；A2 的 `embedding_lookup` **不许用 `nn.Embedding`**（作业要求你自己实现）。

**这一步最容易犯的四个错**（先记住，犯了你会认出来）：

1. **浅拷贝 + `del`**：`minibatch_parse` 里用 `del` 从 `unfinished_parses` 删元素会把 `partial_parses` 的对象弄没（代码注释专门警告了）。用**列表推导重建**。
2. **LA/RA 弹错元素**：LA 弹的是 `stack[-2]`（被依存的那个词），RA 弹的是 `stack[-1]`。反了句子结构全错，但测试会报得很清楚。
3. **`forward` 里多套 softmax**：`CrossEntropyLoss` 内部已含 softmax（`02` §6、`04` §9.2）。输出 logits 即可。
4. **`embedding_lookup` 忘了展平**：输出必须是 `(batch, n_features * embed_size)`。`--forward` 的自测用 30 维 embedding（跑得快），**全量跑是 50 维**——形状别写死。

> **`__init__` 的一个文档坑**：`ParserModel` 的 docstring 写的是 "two hidden layers"，但骨架里只有一组 `embed_to_hidden_*`——**是单隐藏层**，按骨架和 `n_features=36, hidden_size=200, n_classes=3` 来。
