函数 2/4：compute_co_occurrence_matrix —— 本章的硬骨头

3 分题。场景 3 你已经手算过它的输出——现在把手算过程翻译成循环。

输入 / 输出

入：corpus, window_size=4。出：M (n_words × n_words 对称矩阵) + word2ind dict。

M[i][j] = 词 j 作为"词 i 的邻居"出现的总次数

四条铁律（违反任何一条都对不上 M_test_ans）

① 纯计数 +1，无距离加权；② 左右两边都数；③ 边界处窗口自然截断（句首词左边没有就是没有，别环绕）；④ 词表顺序 = distinct_words 返回的顺序。

提示阶梯（compute_co_occurrence_matrix）

提示 1 · 把手算翻译成人话对每篇文档、对每个位置 i（中心词）：向左看最多 window_size 个、向右看最多 window_size 个，每个邻居在 M[中心][邻居] 加 1。
提示 2 · 骨架
words, n_words = distinct_words(corpus) # 已给 M = np.zeros((n_words, n_words)) word2ind = {w: i for i, w in enumerate(words)} for doc in corpus: for i, center in enumerate(doc): lo = ___(0, i - window_size) # 左边界：不能 < 0 hi = ___(len(doc), i + window_size + 1) # 右边界：不能越界 for j in range(lo, hi): if j == i: continue # 自己不算自己的邻居 M[___][___] += 1
提示 3 · 索引中心词和邻居都是字符串，M 的下标是整数——中间隔着 word2ind。两个空分别是 word2ind[center] 和 word2ind[doc[j]]。lo/hi 两个空是 max / min。

自检顺序（别跳步）

  1. 先跑测试 cell（M_test_ans 精确对账）。
  2. 对不上先看形状和 word2ind，再看对称性（np.allclose(M, M.T)）。
  3. 最常见 bug：只数了右边（矩阵上三角，不对称）；或 把 window 写成 range(1, window_size) 漏掉最远的邻居。

corpus = read_corpus() # 150 条影评，已给 words, n_words = distinct_words(corpus) # 你的 ① M, word2ind = compute_co_occurrence_matrix(corpus, window_size=4) # 你的 ② M_reduced = reduce_to_k_dim(M, k=2) # 你的 ③ M_reduced /= np.linalg.norm(M_reduced, axis=1, keepdims=True) # 已给：归一化到单位圆 plot_embeddings(M_reduced, word2ind, words_to_plot) # 你的 ④
