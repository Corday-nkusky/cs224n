词向量与分布语义

一个词的意思，怎么变成计算机能算的东西？
学完你将能回答：为什么 king − man + woman ≈ queen。

10 个场景 · 11 个交互实验 · 全部数字来自本机实跑
场景 01 · 问题

在词向量之前，我们试过什么？

要判断两个词"像不像"，先得有个能计算的表示。前两代方案都死在同一件事上。

第一代：人工词典（WordNet）

语言学家手工编纂"同义词集 + 上下位关系"。它有两个能用的地方，但四个硬伤：

① 语境细微差别丢失

"proficient" 被标成 "good" 的同义词——只在部分语境成立。

② 追不上新词义

wicked / badass / ninja 的"好"义，词典更新永远慢半拍。

③ 主观 + 人工维护

收录谁、怎么分层，全靠人，且无法覆盖褒贬色彩。

④ 最致命算不出相似度

词典里没有"tiger 和 cat 有多像"这个数字。而下游任务要的就是数字。

第二代：one-hot —— 一个词一位

词表里 5 个词，就给每个词一个长度 5 的向量，属于自己的那位置 1，其余 0。点两个词，看它们的内积（相似度）：

词 B —
内积 = ? 点两个不同的词试试
任意两个不同词的 one-hot 向量内积恒为 0 —— 数学上叫正交。自己和自己是 1。这里没有"有点像"这个中间状态。而且这个向量的长度等于词表大小：50 万词 = 50 万维，其中 49.9999 万维是 0。

把话说严格

one-hot 就是标准基向量：词表 V = {w₁,…,w_|V|}，词 wi 映到 ei ∈ {0,1}|V|，第 i 位为 1 其余为 0。 内积 eiᵀej = Σk [ei]k[ej]k = δij（Kronecker delta：i=j 时为 1，否则 0）。 于是 ‖ei‖ = 1，cos(ei, ej) = 0（i≠j），且两两距离 ‖ei − ej‖ = √2。

几何图像：所有词站在 |V| 根两两垂直的坐标轴上，彼此等距。这个空间对词没有任何结构——"hotel" 和 "motel" 的距离与 "hotel" 和 "cat" 完全一样。三个推论：

  • 维度 = 词表大小：50 万词就要 50 万维，每个向量 99.9998% 是 0；
  • 相似度恒为 0：内积、余弦全部失效，检索、聚类、类比全部无从谈起；
  • 泛化不可能：模型在 "motel" 上学到的任何东西，无法迁移给 "hotel"——它们的表示毫不相干。
顺带预告：word2vec 里那个 V×d 的"嵌入矩阵"，本质上就是把 one-hot 向量左乘一次矩阵的查表简写——eiᵀW = W 的第 i 行。one-hot 没有被消灭，它只是退化成了索引。

场景 02 · 直觉

不认识一个词？看它的邻居。

1957 年，语言学家 Firth 说了一句后来统治了 NLP 六十年的话：

"You shall know a word by the company it keeps." —— J. R. Firth, 1957 · 一个词的意思，由经常出现在它附近的词给出

亲自验证一下

假设你不认识高亮的这个词。读几句它出现的句子——读完你大概就懂了：

你刚才做的事，就是分布语义：没查字典，只看上下文，就还原出了词义。剩下的问题只有一个——怎么把"看邻居"变成计算机能做的算术。

从直觉到可计算对象

把"邻居"写成数学对象：对词 w，定义它的上下文分布为

P(c | w) = count(w, c)Σc′ count(w, c′) ，c ∈ V

count(w, c) = 全语料里 c 出现在 w 的窗口内的次数。分布假说的操作化版本就是：词 w 的意思 ≈ 这个 |V| 维的概率分布向量。两个词意思近 ⟺ 它们的上下文分布接近（而不是字面接近）。

注意这个向量是什么——它就是下一场景共现矩阵归一化后的一行。所以场景 3 的"数数"不是拍脑袋的工程手段，它是分布假说最直接的数学化身。后面 word2vec 换的只是得到这个向量的方法（训练代替数数），假说本身没变。

这条假说为什么可信？【直觉】语言里可替换性决定功能：能在相同语境里互换的词，语法和语义角色必然相近（"delicious" 和 "tasty" 能互换的语境远多于 "delicious" 和 "bicycle"）。这不是定理，是语言学经验法则——但它撑起了整个词向量工业。

严格定义与三个性质

Xij = ∑t=1..T ∑0<|Δ|≤m ⟦wt = i⟧ · ⟦wt+Δ = j⟧

⟦·⟧ 是指示函数（成立为 1 否则 0）。一行式读法：遍历每个位置 t，中心词 i 的 ±m 窗口里每出现一个 j，Xij 加 1。

  • 对称性（可证）：窗口不分左右（+Δ 和 −Δ 都计入），每个词轮流当中心。词对 (i,j) 的每次共现，在"i 当中心"时记入 Xij，在"j 当中心"时记入 Xji，两次枚举覆盖同样的物理事件 ⇒ X = Xᵀ。上面实测 max|X − Xᵀ| = 0，不是巧合是定理。
  • 图论视角：X 是一个带权无向图的邻接矩阵——词是顶点，共现次数是边权。（这个词和词之间的图，后面讲降维时还会用到一次。）
  • 稀疏度的量级：V = 10⁵ ⇒ X 有 10¹⁰ 个格子；就算语料有 10⁹ 个 token、每个位置贡献 2m=8 次计数，总计数 ≈ 8×10⁹，密度上限也只有 ~10⁻³ 量级。99.9% 以上的格子恒为 0。

原始计数的补救：PPMI（slides 的 hacks 清单的数学核心）

原始计数被 "the" 这种词污染：the 跟谁都共现，但什么也说明不了。要看的是"超出随机期望的共现"——点互信息 PMI：

PMI(i,j) = log P(i,j)P(i)·P(j) = log Xij · DXi· · X·j， PPMI = max(0, PMI)

其中 D = ΣX，Xi· 是第 i 行和。PMI > 0 = 比随机更常一起出现；PMI < 0 时样本噪声主导（罕见对），直接截成 0——这就是 slides 那句"use correlation, set negative to 0"的精确含义。配套补丁还有：取对数压计数、min(X, t≈100) 截爆头、删功能词、斜坡窗口（近的词权重高）。

就算补完，这张表仍有两个结构性的麻烦：维度随词表增长（10 万词 = 10 万×10 万），本质稀疏。直接当词向量用，下游模型被稀疏性拖垮。所以需要压缩——这就是下一场景。
场景 04 · 机制

10 万维的稀疏表，压到几维才不亏？

上一场景留下两个麻烦：每个词的维度等于词表大小（10 万），其中 99.9% 以上是 0，下游模型没法直接吃。压缩的意思很朴素——用更少的坐标轴去近似原矩阵。判据先说死：把丢掉的元素各自平方、全部加起来、再开根号，得到的那个数叫损失，越小越好；这一场景说的最优只有一个意思——在所有"只许用 k 根轴"的做法里，让这个损失最小的那一个。做到这件事的方法叫奇异值分解（SVD）。本场景只回答一句：k 取几、损失多少。

k 越大误差越小，k = 7 时完美重建。降维的本质：扔掉不重要的坐标轴，换取稠密、短小、抗噪的表示。这就是"每个词一行稠密向量"的第一种来源——纯数数，不训练。
为什么"留前 k 根轴"就是损失最小的那一个？——严格陈述（主线不需要，可跳过）

定理（奇异值分解）：任意实矩阵 X ∈ Rm×n 都能写成

X = UΣVᵀ ， UᵀU = I， VᵀV = I， Σ = diag(σ₁ ≥ σ₂ ≥ … ≥ 0)

U 的列是 XᵀX 的特征向量方向（新坐标轴），σi 量度数据沿第 i 根轴"散开的程度"。截断：只留前 k 个奇异值，得 Xk = UkΣkVkᵀ。

Eckart–Young 定理：在所有秩 ≤ k 的矩阵 B 中，Xk 使 ‖X − B‖F 最小，且误差有闭式：

‖X − Xk‖F² = ∑i>k σi²

用上面的实测数验一遍（k=2）：√(1.1931² + 1.1931² + 0.7775² + 0.7775² + 0²) = √(2×1.4235 + 2×0.6045) = √4.056 = 2.014 —— 和滑块读数逐位一致。这就是"保留前 k 个 = 最优秩 k 近似"的精确内容。

对称矩阵的特例（我们的 X 就是）：X 对称 ⇒ 特征分解 X = QΛQᵀ，σi = |λi|，U、V 的列同为特征向量（至多差符号）。所以共现矩阵的 SVD 实质是谱分解。

⚠ 实测翻车现场：k 写的是 2，每个词却只用到 1 个坐标

把这张表压到 k=2 之后，量一量词与词之间的夹角——夹角越小，两个词在图上指的方向越接近。结果极端得可疑：

like 与 enjoy 的夹角 = 0° deep 与 learning 的夹角 = 90° I 与 like 的夹角 = 90°

谜底写在奇异值里：[2.6404, 2.6404 | 1.1931, 1.1931 | 0.7775, 0.7775] 成对相等。这是共现矩阵为二分图的指纹——词分成两组 {I, NLP, deep, flying} 和 {enjoy, learning, like}，组内从不共现。SVD 把两组各铺到一根轴上，组内所有词共线，夹角恒为 0°。

为什么成对？二分图的邻接矩阵能重排成反对角块 [[0, B], [Bᵀ, 0]]。这种矩阵的特征值以 ±λ 成对出现（若 (x,y) 是 λ 的特征向量，(x,−y) 就是 −λ 的）。σi = |λi|，所以奇异值成对相等——[2.6404, 2.6404 | 1.1931, 1.1931 | 0.7775, 0.7775] 三对，正好对应三组"层"。每对奇异值只撑起一根有效语义轴，同组词全被压到同一射线上，夹角恒为 0°。

教训：判据不是"k 写的是几"，而是每个词实际拿到几个线性无关的共现模式。玩具语料能演示机制，不能推断真实效果。

场景 05 · 动手

点积会被长度骗，余弦只看方向

向量有了，"像不像"怎么量化？拖动两个向量，盯着三个读数看。

—
点积 u·v（受长度影响）
—
余弦相似度 cos θ（只看方向）
—
夹角 θ
同一个方向，把向量拉长 10 倍，点积涨 10 倍，余弦不变。词向量比相似度时，几乎总是用余弦——词频会改变长度，但不应该改变"意思"。

三个量的严格关系

u·v = ∑i uivi ， ‖u‖ = √(u·u) ， cos θ = u·v‖u‖·‖v‖
  • Cauchy–Schwarz 不等式：|u·v| ≤ ‖u‖·‖v‖，等号 ⟺ 两向量共线。两边同除 ‖u‖‖v‖ 得 cos ∈ [−1, 1] —— 余弦的值域不是约定，是定理。
  • 等价视角：cos θ = û·v̂（归一化后的点积）。先除掉长度再比，所以"只看方向"。
  • 几何来源：由余弦定理 ‖u−v‖² = ‖u‖²+‖v‖²−2‖u‖‖v‖cosθ 反解即得——"cos 是夹角的余弦"不是定义套定义。
  • 词向量场景为什么必须归一化：高频词的向量范数往往更大（更多更新机会），若用点积，"常见"会冒充"相似"。余弦把这个混杂因素除掉。
场景 06 · 概念

word2vec：不数数了，让模型自己学

第二条路：设一个代理任务——用中心词预测它旁边的词。预测准不准不重要，为了预测而被迫学出来的向量，才是我们要的。

窗口滑过语料，每个位置都是一道题

↑ 给定中心词（金色）后，模型对整个词表算 P(上下文词 | 中心词)。理想状态：真实邻居的概率被推高。（此处为示意分布）

P(o|c) = exp( uoᵀ vc )∑w∈V exp( uwᵀ vc )
J(θ) = −1T ∑t=1..T ∑−m≤j≤m, j≠0 log P( wt+j | wt ; θ )

每个词有两套向量

当中心词时用 v，当上下文词时用 u。分开两套优化更容易；最后可以平均。参数量 = 2 × d × V，全部塞进一个长向量 θ 一起梯度下降。

最小化 J ⟺ 最大化预测准确率

J 是"平均负对数似然"。log 把乘概率变成加损失，负号把"越大越好"翻成"越小越好"——梯度下降的标准形状。

从似然到 J(θ)：四步变形

  1. 似然：窗口滑过语料，每个中心词 wt 预测窗口内每个 wt+j。假设各预测独立，整段语料的似然是连乘 L(θ) = ∏t ∏−m≤j≤m, j≠0 P(wt+j|wt; θ)。
  2. 取 log：连乘变连加（数值上防下溢，解析上拆开乘积）。
  3. 加负号：最大化似然 ⟺ 最小化负对数似然——梯度下降要"越小越好"。
  4. 除 T：取平均，让损失尺度不随语料长度变。得页面顶部那个 J(θ)。

本课最重要推导：∂J/∂vc（点击逐步展开，建议先拿纸自己推）

  1. 只看一个窗口的损失：Jt = −log P(o|c) = −uoᵀvc + log Σw∈V exp(uwᵀvc)。两项分工：第一项拉高分母外真实邻居的分数，第二项（log-sum-exp）压制全体。
  2. 第一项对 vc 求导：∇(−uoᵀvc) = −uo。（线性函数，梯度就是系数。）
  3. 第二项是 log-sum-exp。对 vc 求导用链式法则：外层 d/dx log x = 1/x，内层每个 exp(uwᵀvc) 贡献 exp(uwᵀvc)·uw。合起来 = Σw [exp(uwᵀvc) / Σw′ exp(uw′ᵀvc)] · uw = Σw P(w|c) · uw。
  4. 合并：
    ∂Jt/∂vc = ∑w∈V P(w|c)·uw − uo = Ew~P(·|c)[uw] − uo
    "期望"减"现实"：模型当前认为的平均上下文，减去真正出现的那个词。
  5. 梯度下降更新 vc ← vc − η·∂J/∂vc = vc + η(uo − Σw P(w|c)uw)：把中心词向量拉向真实邻居、推离全表概率加权平均。P(w|c) 大的词被推得最狠——模型对自己的高置信错误纠正最用力。
  6. 对上下文向量的梯度（同法可得）：∂Jt/∂uo = (P(o|c) − 1)·vc；∂Jt/∂uw≠o = P(w|c)·vc。注意第二个式子对全部 V−1 个词都非零——记住它，场景 7 的灾难就从这里来。

手算一遍（3 词词表，全部数字可对账）

取 V = {o, x, y}，当前参数 vc = (1, 0.5)，uo = (1, 0)，ux = (0, 1)，uy = (1, 1)。真实上下文是 o。

为什么必须 SGD

J(θ) 是对全体窗口求和：T 个位置 × 2m 个上下文。真实语料 T ~ 10⁹，一次全量梯度要扫几十亿个窗口才算一步——不可行。SGD：每（小批）窗口立刻更新一次，用噪声换速度，噪声本身还有正则化效果。另外 slides 明说：这个目标可能非凸（"our objectives may not be convex... But life turns out to be okay"）——没有最优性保证，但实践中足够好。参数量回忆一下：θ ∈ R2dV（d 维 × V 词 × 2 套）。

场景 07 · 问题

softmax 的分母，贵得离谱

词表 10 万、向量 300 维时，每一个训练对的代价（实测推算）：

naive softmax：每个训练对要算 V×d 次乘加。两种优化把它打低 4~5 个数量级。（V=100000, d=300, K=5）

分母其实制造了三类问题，别混为一谈

① 前向算得慢

每个训练对的分母要算 V 个点积 + V 次 exp：O(V·d)。全语料 T·2m 个训练对 ⇒ O(T·m·V·d)。V=10⁵、d=300 时，单对 3×10⁷ 次乘加，比一次前向本该有的代价贵 5 个数量级。

② 更致命反向梯度变稠密

场景 6 推过：∂J/∂uw = P(w|c)·vc，对所有 w≠o 都非零 ⇒ 每个训练对要回写整张 V×d 的 u 矩阵。原论文卖点 "does not involve dense matrix multiplications" 被这一条直接毁掉——① 只是慢，② 把"稀疏更新"的系统结构破坏了。

③ 目标错配

softmax 强制 V 个词概率互斥竞争——这是为了得到合法分布。但我们不要概率，只要向量。为一个不需要的性质付了 ①② 两笔账。

第③条恰恰是合法化的来源。原论文：skip-gram "只关心学到高质量向量表示，所以我们可以随意简化目标函数"。于是——把"V 选 1"的多选题，换成 K+1 道"是不是真邻居"的判断题（负采样）；或者把词挂到二叉树叶子，沿路径做一串二分类（层次 softmax）。

三种方案的单训练对代价（V=10⁵, d=300, K=5）

方案代价公式乘加次数相对 naive产出是合法概率？
naive softmaxO(V·d)30,000,0001×是
层次 softmaxO(L·d)，L≈log₂V5,1001.7×10⁻⁴×是（关键优势）

层次 softmax 的 L 是叶子深度：平衡树 L=log₂V≈16.6，哈夫曼树按词频加权的期望深度更短（下一场景实测 8.49）。

场景 08 · 动手

负样本怎么采？树怎么建？

两个工程细节，都有实测数字。

实验一：噪声分布 Pn(w) ∝ U(w)α —— α 取多少？

IMDB 50k 语料、词表 2000 上实测。切 α，看 8 个词被采为负样本的概率怎么变：

分布熵 — nats 最高频词 the 占比 —
α=1（纯词频）：the 一家独大，模型只要学会"见到 the 就说不是邻居"就能拿分，学不到细粒度。α=0（均匀）：常见但无关的词又见不到。α=0.75 是折中——把词频开个 3/4 次方，压扁头部、抬起尾部。

采样分布的数学形状

Pn(w) = U(w)αΣv∈V U(v)α

U(w) 是词频（unigram）分布。α 是一个温度旋钮：α=1 就是原词频；α→0 趋向均匀分布；0<α<1 把分布"压扁"——高频相对低频的优势被开根号式削弱。上表实测：α 从 1 调到 0.75，the 的采样概率从 6.88% 压到 2.72%，queen 从 0.008% 抬到 0.017%（2 倍）。为什么正好 3/4：原论文的经验值，没有推导——这是本课"未能验证清单"的一员。

实验二：层次 softmax 为什么用哈夫曼树

同样 V=2000 真实词频建树，比较"平均每词的查询路径长度"（按词频加权）：

the（6.88%）：深度 4，编码 1011 morning（0.005%）：深度 14 哈夫曼 vs 平衡树：省 22.8%
哈夫曼树让高频词走短路——这就是它的全部意义。树形只由词频决定，不含任何语义信息。另外注意：内部节点的向量 v′n 属于节点（W−1 个），不属于任何词。
Jneg = −log σ( uoᵀ vc ) − ∑k∈采样 log σ( −ukᵀ vc ) ， σ(x) = 1 / (1+e−x)

负采样梯度：干净得不像话

sigmoid 有两个法宝性质：σ(−x) = 1 − σ(x) 和 σ′(x) = σ(x)(1−σ(x))。用它们对 Jneg 求导（记 sw = uwᵀvc）：

∂Jneg/∂vc = (σ(so) − 1)·uo + ∑k∈采样 σ(sk)·uk
  • 结构跟 naive 版一样优雅："(预测−目标)×方向"。σ(so)−1 ≤ 0，把 vc 拉向真实邻居；σ(sk) ≥ 0，把 vc 推离负样本。
  • 稀疏性一目了然：只有 {o} ∪ {k 个负样本} 出现在公式里——每步只更新 (1+K)·d 个数，其余 V−K−1 行碰都不碰。这就是对场景 7 问题②的正面回答。
  • 代价：输出不再是概率（softmax 的归一化被扔了）。要概率的任务请用层次 softmax。

层次 softmax 的路径概率公式（严格版）

p(w | wI) = ∏j=1..L(w)−1 σ( ⟦n(w,j+1) = ch(n(w,j))⟧ · v′n(w,j)ᵀ vwI )
  • n(w, j) = 从根到叶子 w 路径上第 j 个节点；⟦·⟧ 是方向指示：下一步是左孩子取 +1，右孩子取 −1。每个内部节点做一道"往左还是往右"的二分类。
  • 参数归属要记死：vw 属于词（V 个）；v′n 属于内部节点（W−1 个，不属于任何词）。输出层总参数 (V + W − 1)·d ≈ 2Vd——省的不是参数量，是每步计算量。
  • 可验证：对随机向量，Σw p(w|wI) = 1 精确成立（本机实测误差 ~2×10⁻¹⁶）——它是合法概率分布，负采样不是。
  • 哈夫曼最优性：哈夫曼树在所有二叉树中最小化带权路径长 Σw f(w)·L(w)。期望查询代价 ∝ 这个加权和，所以按词频建哈夫曼树 = 数学上最优的期望步数（实测 8.49 vs 平衡树 11，省 22.8%）。

场景 09 · 兑现

真训一遍，然后做那道著名的算术

纯 numpy 手写的 skip-gram + 负采样，7540 token 小语料，11 万次更新（本机实跑）：

loss 曲线（实测）

每次更新乘加次数：负采样 192 vs 全量 softmax 2208（V=69） 若 V=10 万：3.2×10⁶ vs 192 → 差 1.7 万倍

读图基准：均匀乱猜的 loss = ln V = ln 69 ≈ 4.23；训练后 1.65。负采样下 loss 没有 0 这个下界参照——它度量的是"把真实邻居和 5 个噪声词区分开"的难易，所以看趋势不看绝对值：前 2 万步陡降（高频模式先学到），后面缓降收敛。

向量算术：king − man + woman = ?

训练完，用词向量做加减，再按余弦找最近的词（剔除输入词本身）：

king − man + woman = ?
结果前三名：queen / prince / princess。这就是"词的意思被编码成了方向"的直接证据。已知缺陷：如果信息在向量里但不是线性关系，类比就测不出来。

严格写法：类比 a : a* :: b : ? 的求解是 w* = argmaxw∉{a,a*,b} cos( xw , xb − xa + xa* )。三个细节：① 用余弦不用点积（场景 5 的理由）；② 必须剔除输入词——否则余弦最近邻永远是输入自己，题目作废；③ 这个式子成立的前提是"性别"这类属性被编码成一个固定方向，使得所有 (a, a*) 对的位移向量近似平行。这是词向量空间结构里相当不平凡的经验事实，不是设计出来的。

两条路对账

计数派：共现矩阵 + SVD预测派：word2vec
做什么数邻居 → 压缩设代理任务 → 梯度下降
优点快、可解释、一次遍历效果好、可扩展、A1 主线
缺点稀疏敏感、大矩阵 SVD 贵目标非凸、要调超参
合流GloVe（2014）：直接拟合"共现概率的比值"——用预测派的目标函数，吃计数派的全局统计。

GloVe 的出发点：比值比绝对值更有信息量

考察 P(k|ice) / P(k|steam)：k=solid 时比值很大（跟冰共现远多于蒸汽）；k=gas 时很小；k=water 时 ≈1（两者都常见）；k=fashion 时 ≈1（两者都无关）。大/小/≈1 三档把"相关方向"和"无关噪声"分开了，而单独的概率值做不到。GloVe 于是让向量直接拟合这个比值的对数：wiᵀw̃j ≈ log Xij 的加权最小二乘。一句话：计数派的全局统计 + 预测派的训练目标。

内在评测

外在评测

在真实任务上评：命名实体识别（"Chris Manning lives in Palo Alto" → 人名/地名）。慢，但换掉词向量后准确率提升 = 真的赢了。

内在评测的数学：Spearman 等级相关

WordSim353 给 353 对词的人工相似度打分（tiger–cat 7.35，stock–jaguar 0.92）。把每对词的 cos 与人工分各自换成名次，算名次的 Pearson 相关——这就是 Spearman's ρ。用名次而不用原值，因为我们只要求"单调一致"：向量觉得更像的对，人也觉得更像，数值尺度不需要对齐。这正是"内在评测只看排序能力"的精确含义。
