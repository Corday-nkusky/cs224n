### A 组 · 定位与直觉（`02`）

| # | 你学到了什么 | 出处 |
|---|---|---|

| A2 | **one-hot 是"座位号"，embedding 是"坐标"**：前者两两正交算不了远近，后者能算距离/加减 | `02 §1.2` |
| A3 | **"嵌入"的含义**：把离散稀疏编号嵌进连续稠密空间 | `02 §1.2` |

| A8 | **演进链条 8 代**：BoW → LSA/SVD → NNLM → **W2V** → GloVe → fastText → ELMo/BERT → 句向量 | `02 §3` |

### B 组 · 模型结构（`01` `02`）

| # | 你学到了什么 | 出处 |
|---|---|---|
| B1 | **Skip-gram**：中心词 → 上下文（一射多），贵但罕见词好、小语料好 | `02 §2.1` `04 Q1` |
| B2 | **CBOW**：上下文 → 中心词（多射一），快数倍但罕见词被平均稀释 | `02 §2.2` `04 Q1` |
| B3 | **两套矩阵 `W_in` / `W_out`**：打分是双线性的，共用会强制对称、损表达力 | `03 §5.7` `04 Q4` |

| B5 | **训练对的构造**：窗口半长 C → 每个位置拆约 2C 个 (中心, 上下文) 对 | `01 §3.2` |

### C 组 · 数学与推导（`03`）

| # | 你学到了什么 | 出处 |
|---|---|---|
| C1 | **原始目标**：$\frac1T\sum_t\sum_j \log p(w_{t+j}\mid w_t)$，softmax 定义条件概率 | `03 §1` |
| C2 | **痛点在分母**：梯度含 $\sum_{w=1}^V p(w\mid w_I)u_w$，每样本 O(V·D) | `03 §1` |
| C3 | **NEG 目标函数**：$-\log\sigma(u_o^\top v_c)-\sum_k\log\sigma(-u_{n_k}^\top v_c)$ | `03 §2.1` |
| C4 | ★ **梯度统一形式**：$\nabla = (\sigma(s)-y)\cdot$对面向量，$y\in\{0,1\}$ → 反向只有 3 行 | `03 §2.3` |
| C5 | **噪声分布 $U(w)^{3/4}/Z$**：0.75 是实验调的，无理论推导 | `03 §2.2` `04 Q3` |
| C6 | **稀疏更新**：一次只动 `W_in` 1 行 + `W_out` (1+K) 行 | `03 §2.4` |
| C7 | **维度变换表**：numpy 在线版 / torch batch 版（含 bmm 的 `(B,K,D)×(B,D,1)`） | `03 §3` |
| C8 | **复杂度账**：softmax ~1.8e8 vs HS ~5.1e3 vs **NEG ~1.8e3**（V=1e5, D=300） | `03 §7` |
| C9 | **Hierarchical Softmax**：Huffman 树，$\log_2 V$ 次判断，无需采样 | `03 §6` |
| C10 | **类比为何成立**（深层）：比值才编码语义；SG+NS 隐式分解 shifted PMI ⚠️【第三方未核】 | `03 §8` |

### D 组 · 原版工程 trick（`03 §5`，全部逐字核对过源码）

| # | 你学到了什么 | 出处 |
|---|---|---|
| D1 | ★ **子采样：论文公式 ≠ 源码实现**（$1-\sqrt{t/f}$ vs $\sqrt{t/p}+t/p$，差 27 个百分点） | `03 §5.1` |
| D2 | **负采样表** `table_size = 1e8`，`power = 0.75` | `03 §5.2` |
| D3 | **动态窗口** `b = next_random % window`：隐式对距离衰减 | `03 §5.3` |
| D4 | **α 衰减到 `starting_alpha × 1e-4`**（相对值，不是绝对 1e-4） | `03 §5.4` |
| D5 | **`min_count = 5`**：低频词直接扔 | `03 §5.5` |
| D6 | ★ **`syn1neg` 全零初始化能训**：全零时 σ(0)=0.5 残差非零；实测全零 vs 随机 loss 2.683 vs 2.655 | `03 §5.6` |

## 2. 能力自检：三档 checklist

### 第一档 · 能讲清楚（面试口述，不看笔记）

- [ ] 用一句话说清 Word2Vec 的核心贡献，并说出**三个数字**（K=5、3/4 次方、α=0.025/0.05）
- [ ] 说清 CBOW 和 Skip-gram 方向相反，以及各自的适用场景
- [ ] 说清为什么需要负采样：softmax 的分母每样本要算 V 次 → 改成 K+1 个二分类
- [ ] 说清有两套矩阵、训练完用哪个
- [ ] 说清 `king-man+woman=queen` 的表层（语义方向）和深层（共现概率比值 / PMI）
- [ ] 说清它**不是**语言模型，以及为什么算不了 perplexity
- [ ] 说清它的三个局限：静态向量（一词多义）、OOV、依赖共现统计
- [ ] 说清 2018 年之后"embedding"这个词的含义变在哪（词级静态 → 句级动态）

### 第二档 · 能手写（白板写代码 / 推公式）

- [ ] 默写出 NEG 的目标函数（两行）
- [ ] 默写出三条梯度，并写出统一形式 $(\sigma(s)-y)\cdot$ 对面向量
- [ ] 手写一次更新的伪代码（8 行，见 `01 §0`）
- [ ] 标出 numpy 版每个量的 shape：`v_c (D,)`、`U_n (K,D)`、`s_neg (K,)`、`outer(g_neg, v_c) (K,D)`
- [ ] 标出 torch 版：`v_c (B,D)`、`U_n (B,K,D)`、`bmm` 出来 `(B,K)`
- [ ] 写出稳定的 `log σ(x)`（logaddexp 形式）
- [ ] 说出初始化：`W_in` uniform(−0.5/D, 0.5/D)，`W_out` **全零**，以及为什么全零能训

### 第三档 · 能排查（看到症状能定位病因）

- [ ] loss 一直是 4.1589 不动 → batch 版 lr 被 /B 了
- [ ] loss 越训越大、‖W‖ 指数涨 → lr 太大 / epoch 太多
- [ ] loss 突然 nan → 查 `log(sigmoid())` 是不是 naive 写法
- [ ] `Adam does not support sparse gradients` → sparse 梯度换 SGD/SparseAdam
- [ ] 相似词全是 0.99 → 先怀疑语料太小太规整，不是模型太强
- [ ] 点积排序被高频词霸榜 → 忘了归一化，该用 cosine
- [ ] `most_similar` 返回自己 → 没 mask
- [ ] 中文效果诡异 → 没分词

## 5. 下一步学什么

按"离你最近、最有用"排序：

1. **手写一个 CBOW**（对照 Skip-gram，体会"取平均"带来的差异）→ 直接补上本节第 4 项缺口。
2. **在真实语料上跑一次**：下载中文维基或 `text8`，用 gensim 训，亲眼看相似度从 0.99 掉到 0.6~0.8。
3. **GloVe 论文精读**（Pennington 2014）：把 03 §8 那条我没核实的论证自己核一遍。
4. **fastText**：子词怎么解决 OOV——对你关心的"低数据领域适配"直接相关。
5. **从静态到动态**：ELMo → BERT，理解"同一个词不同向量"是怎么做到的。
6. **回到你的主业**：LLM 的 embedding 层（查表 + 位置编码）在数学上就是 word2vec 的那一套，
   区别只在它与整个模型联合训练、粒度是 BPE subword。
